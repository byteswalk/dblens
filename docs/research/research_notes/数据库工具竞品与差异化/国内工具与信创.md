# 国内数据库管理工具、SQL 治理平台与信创环境（截至 2026-10）

> 调研日期：2026-10-25。GitHub 数据于 2026-10-25 通过 `gh api` 实时获取。“推断”一律放在 Inferences 小节。厂商博客、推广软文已在条目中注明可信度。

## 一、国产/国内通用客户端（Chat2DB、SQLynx、NineData/CloudDM、SQLark、云厂商 DMS/DAS/DMC）

### Takeaway
国内通用客户端基本都是 Java/Web 技术栈，并按“开源或免费社区版 + 收费 Pro/团队/企业版（AI、协作、审批、脱敏）”分层。达梦、金仓已经成为国产客户端的标配卖点，但覆盖深度参差不齐。2025–2026 年最明显的变化有三点：Chat2DB 从 5.3.0 起改为 source-available 许可证；NineData 社区版迭代很快，在审批、脱敏方面卷得厉害；达梦自己推出了免费的现代化客户端 SQLark。

### Cited Findings

- LICENSE 原文：“Chat2DB Community version 5.3.0 and later is licensed under a modified version of the Apache License 2.0, with the additional conditions”。5.3.0 之前的版本仍为 Apache 2.0。即新版已不再是 OSI 意义上的开源，而是 source-available — [Chat2DB LICENSE](https://github.com/OtterMind/Chat2DB/blob/main/LICENSE)

### Inferences
- 云厂商工具（DMS、DAS、DMC）本质上是给自家云锁客的工具：对自家库支持深，对他家国产库只做到“能连能查”。私有化部署的信创客户基本用不上，这块空间留给了独立工具。
- Chat2DB 改为 source-available 后，“真开源、许可宽松、多国产库”的定位出现了空位。
- 这些产品几乎都是 Java 后端加 Electron 或 Web 前端。Rust 单二进制在体积、启动速度、内存，以及 ARM64/LoongArch 交叉编译方面有可讲的差异点（推断，需实测对比）。

## 二、SQL 审核/审批/工单平台（Bytebase、Archery、Yearning、goInception、SQLE、ODC）

### Takeaway
开源审核平台里只有 Bytebase 和 SQLE 在持续活跃迭代。goInception 自 2022 年后基本停更，Archery 依赖它做 MySQL 审核。国产库审核能力几乎都锁在企业版里（SQLE 企业版、DMS 安全协同）。OceanBase ODC 已于 2025 年停止开源。

### Cited Findings
- GitHub 实时数据（2026-10-25）：bytebase 14,638★，最新 3.24.0（2026-10-22）；Archery 7,069★，Apache-2.0，最新 v1.14.0（2026-03-07）；Yearning 8,969★，AGPL-3.0，最新 v3.1.9.1（2024-11-10）；goInception 1,744★，GPL-3.0，最新 release v1.3.0（2022-06），最后 push 2024-11；actiontech/sqle 1,502★，MPL-2.0，最后 push 2026-09-30 — [bytebase](https://github.com/bytebase/bytebase)；[Archery](https://github.com/hhyo/Archery)；[Yearning](https://github.com/cookieY/Yearning)；[goInception](https://github.com/hanchuanchuan/goInception)；[SQLE](https://github.com/actiontech/sqle)
- Bytebase 定价：Community 免费（≤20 用户、10 个实例）；Pro $20/用户/月（10 个实例，审计日志保留 7 天）；Enterprise 需询价，按年订阅，提供自定义审批、动态数据脱敏、无限期审计、LDAP/OIDC。SQL 审核 200+ 规则所有版本都有，自定义审批流和脱敏仅 Enterprise 提供 — [bytebase.com/pricing](https://www.bytebase.com/pricing)
- Bytebase 支持的 RDBMS：MySQL、PG、Oracle、SQL Server、MariaDB、TiDB、OceanBase、CockroachDB、Spanner 等，未见达梦、金仓、openGauss — [Bytebase supported databases](https://bytebase.com/docs/introduction/supported-databases)
- Archery 默认使用 goInception 做 MySQL 审核和执行（Inception 已停维护）；README 中支持 MySQL、MsSQL、Redis、PgSQL、Oracle、MongoDB、Phoenix、ODPS、ClickHouse，未见国产库 — [Archery 文档 SQL 审核](https://archerydms.com/modules/sql_check/)；[Docker Hub hhyo/archery](https://hub.docker.com/r/hhyo/archery/)
- Yearning 聚焦 MySQL，许可证 AGPL；有测评认为其规则偏重 DDL、规则闭源，二次开发比较被动（Bytebase 方撰文，存在利益相关）— [墨天轮 Yearning vs Archery](https://www.modb.pro/db/1723876620107849728)；[墨天轮 开源产品 SQL 上线能力测评](https://www.modb.pro/db/655552)
- SQLE（爱可生）：官方称深度适配 OceanBase、达梦、TDSQL、GoldenDB 等国产库，但功能对比表写明“除 MySQL 为社区版，其他均为企业版”。2025 年按月发版，版本号形如 4.25xx：4.2505 下放企业级权限管理，4.2507 上线性能洞察，4.2509 社区版 SQL 工作台焕新；4.2601（2026-01）企业版支持 Oracle、达梦工单自动备份 — [SQLE 社区页](https://opensource.actionsky.com/sqle/)；[SQLE 功能对比](https://actiontech.github.io/sqle-docs/docs/support/compare/)；[4.2601 发布](https://opensource.actionsky.com/sqle-4-2601-ga/)；[4.2509](https://opensource.actionsky.com/sqle-4-2509-0-ga/)；[4.2507](https://www.oschina.net/news/363629/sqle-4-2507-0)
- OceanBase ODC：GitHub 仓库已 archived。公告原文：“ODC 4.3.4_bp2 is the final open-source release … Subsequent versions will no longer be released as open source”，最终开源版发布于 2025-06-06。ODC 为 Web 架构，提供项目协作、变更审批、SQL 规则、风险等级、PL 调试、数据归档 — [GitHub oceanbase/odc](https://github.com/oceanbase/odc)

### Inferences
- 中小团队“轻量审核加审批”的选择要么只支持 MySQL（Yearning、Archery），要么国产库需要付费（SQLE 企业版、Bytebase 不支持达梦和金仓）。“开源或低价 + 达梦/金仓/OceanBase/openGauss 的 SQL 规则审核 + 审批”是一个明显空档。
- goInception 停更意味着 Archery 系用户在 MySQL 8.x/9.x 新语法上存在风险（推断）。

### Gaps
- 各平台国产库审核规则的具体数量与质量没有可靠的第三方测评。
- Bytebase 中文区（bytebase.cc）的人民币价格或私有化报价未查到。

## 三、国产数据库厂商自带工具及用户评价

### Takeaway
厂商工具的普遍画像是“功能深、只支持自家库、界面老旧或文档弱、跨平台差”。达梦用 SQLark 补了现代化客户端，OceanBase 收回了 ODC 的开源，openGauss 官方把 DBeaver 当作推荐客户端。金仓工具缺少独立评测。

### Cited Findings
- 达梦社区 2025-06-18 发布的对比测评（DM Manager、SQLark、DBeaver）结论：DM Manager 与达梦集成深、对象可视化全，但界面老旧拥挤、弹窗多、文档简单、无更新说明，且只支持达梦；SQLark 界面现代、报错清晰，但部分对象不能可视化设计、只有中文；DBeaver 对达梦可做基础开发，但可视化对象最少，复杂脚本报错难定位，集群管理等仍需官方工具 — [达梦社区 DM 数据库管理工具对比测试](https://eco.dameng.com/community/article/20b152e3ada50d938fa02afd6a0b4a62)
- 达梦官方 FAQ 记录的工具问题：manager 先用 root 打开后再用 dmdba 打开会报错；IPv6 下连接出现网络通信异常 — [达梦 FAQ 数据库工具](https://eco.dameng.com/document/dm/zh-cn/faq/FAQ_TOOL.html)
- 有博客称 DM Manager 不支持 Mac — [CSDN](https://blog.csdn.net/qq_35570434/article/details/130060185)
- 金仓官方技术博客（2026-06-27，文末声明内容由大模型生成）描述，通用工具在金仓上的痛点有：无法解析 `sys_` 系统视图、存储过程和触发器方言问题、监控数据失真、200+ 并发时 UI 卡死、开源工具加金仓插件存在元数据和方言问题。文章推荐 KStudio，提效数据未经核实 — [金仓博客 通用数据库管理工具替换](https://www.kingbase.com.cn/explore/tech-blog/%E9%80%9A%E7%94%A8%E6%95%B0%E6%8D%AE%E5%BA%93%E7%AE%A1%E7%90%86%E5%B7%A5%E5%85%B7%E6%9B%BF%E6%8D%A2%EF%BC%8C%E6%88%91%E7%9A%84%E6%93%8D%E4%BD%9C%E6%97%A5%E5%BF%97%E4%B8%8E%E9%81%BF%E5%9D%91%E5%AE%9E/)
- openGauss：DataKit 是官方可视化 Web 运维平台（安装、监控、管理）；工具页同时列出 Data Studio 和 DBeaver；6.0.5 LTS 维护到 2027-09-30 — [openGauss Toolset](https://opengauss.org/en/tools/)；[DataKit 文档](https://docs.opengauss.org/en/docs/latest/datakit/datakit.html)；[openGauss 下载](https://opengauss.org/en/download/)
- 华为云 GaussDB 文档（2026-07 更新）给出 DBeaver 24.1.4 加 GaussDB JDBC 驱动的连接步骤 — [GaussDB 使用 DBeaver 连接](https://support.huaweicloud.com/usermanual-gaussdb/gaussdb_01_504.html)
- `opengauss-mirror/DataStudio` 在 GitHub 上只有 1★（镜像仓库，活跃度很低）— [GitHub](https://github.com/opengauss-mirror/DataStudio)
- TiDB Dashboard：Apache-2.0，204★，2026-10-23 仍在活跃 push — [GitHub pingcap/tidb-dashboard](https://github.com/pingcap/tidb-dashboard)

### Inferences
- 达梦已有官方免费的现代客户端 SQLark，DBLens 在达梦上要靠“多库统一 + 治理 + 跨平台轻量”取胜，而不是单库体验。金仓、GaussDB/openGauss 的第三方客户端最弱（DBeaver 加 JDBC 驱动是主流方案），是更大的空档。
- ODC 闭源后，OceanBase 用户失去了开源的 Web 协同工具。

### Gaps
- KStudio、KDTS、PolarDB 工具的独立用户评价没有找到（公开资料几乎都是金仓或阿里自宣）。
- V2EX、知乎上针对厂商工具的集中吐槽帖本次未检索到。

## 四、信创要求：国产 OS/CPU、认证与采购

### Takeaway
官方硬性名录（中国信息安全测评中心“安全可靠测评”）覆盖的是 CPU、操作系统、数据库等基础软件，没有找到把“数据库管理工具”单列的官方名录。工具类软件在实际采购中通常靠与麒麟、统信、鲲鹏、海光、飞腾、龙芯以及国产数据库厂商的“兼容性互认证”证书来证明信创适配。

### Cited Findings
- 安全可靠测评结果有效期 3 年，分Ⅰ级、Ⅱ级。2026-01-16 发布了《安全可靠测评结果公告（2026 年第 1 号）》；入围数据库包括达梦 V8.4、金仓 V9、GaussDB、OceanBase V4、TiDB（平凯）V7.1、TDSQL 等；操作系统包括银河麒麟、统信等。以上为第三方整理，需以官方公告核对 — [博客园 2026 信创目录汇总](https://www.cnblogs.com/Magiclala/p/19913570)；[墨天轮 2025 信创数据库名单](https://www.modb.pro/db/1889247688898654208)；[搜狐 2026 信创适配清单](https://www.sohu.com/a/994743423_122411481)
- 标准化软件产品的常规做法是与主流国产 CPU、OS 厂商做兼容性互认证测试并取得互认证证书（个人博客，可信度一般）— [CSDN 信创产品合规认证流程](https://blog.csdn.net/weixin_44894601/article/details/148652136)
- 同类数据工具的互认证案例：DataPipeline 与麒麟软件互认证；万里数据库与麒麟（飞腾版、鲲鹏版）V10 互认证 — [DataPipeline](https://www.datapipeline.com/News&Insights/20211015)；[GreatDB](https://www.greatdb.com/Home/news/news_1/id/837.html)
- DB 工具厂商也在做与数据库厂商的互认证，例如 CloudDM 与达梦（约 2025-09）— [cdmgr.com](https://www.cdmgr.com/)
