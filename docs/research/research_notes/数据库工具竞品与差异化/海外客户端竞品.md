# 海外数据库客户端 / GUI 工具竞品画像（2025–2026）

> 调研日期：2026-10-25。每条事实标注来源与事实日期；"[第三方]"表示非厂商一手来源，可信度较低；"[旧]"表示 2025 年 6 月以前的信息。GitHub 数据为 2026-10-25/26 通过 `gh api` 实时查询。

## 问题1：各产品最新版本、定价/许可、部署形态、数据库支持（含国产库）

### Takeaway
海外市场分成三类：①全能型桌面 IDE（DBeaver、DataGrip、Navicat），已普遍把 AI 助手和团队治理放进付费版；②轻量/颜值型桌面客户端（TablePlus、Beekeeper Studio），定价低，治理弱；③Web/自托管型（CloudBeaver、DbGate Team、SQLynx、Supabase Studio、Outerbase），偏团队和云端。在国产库方面，只有 Navicat（达梦、KingbaseES、openGauss、GaussDB(DWS)、TiDB、PolarDB、OceanBase 兼容）和 SQLynx（第三方称支持达梦、金仓）有明确支持。DBeaver、DataGrip、TablePlus、Beekeeper、DbGate 的官方页面都没有点名国产库（Beekeeper 只列了 TiDB）。

## 问题2：AI 功能（能力、模型、BYOK/本地模型、隐私）

### Takeaway
2025–2026 年 AI 已成为标配，主流形态是 AI Chat 侧栏 + 编辑器内 "Ask AI"。DBeaver 和 Navicat 都支持多模型 BYOK（含 DeepSeek/Ollama 或企业网关）；DataGrip 依托 JetBrains AI（Free/Pro 档）并支持自带 Key 或订阅；DbGate、Beekeeper 把 AI 放在付费档。新趋势包括：MCP Server 对外暴露数据库给 Agent、用 ChatGPT/Grok 订阅代替 API Key、把 AI 嵌入表设计器和数据编辑器。

### Cited Findings
- **DBeaver**：26.1 移除了 AI smart completion，改为统一使用 AI Chat — [GitHub Wiki](https://github.com/dbeaver/dbeaver/wiki/AI-Smart-Assistance-in-DBeaver-Community)。26.2（2026-09-09）的变化：命名模型配置，Community 支持 OpenAI 和 GitHub Copilot；新增 Grok 引擎（PRO）；OpenAI 和 Grok 可用订阅代替 API Key；Anthropic Claude 支持自定义 URL，可走企业内部网关；AI 请求含义模糊时会追问并给出选项（PRO 默认开启）；AI 可在 Multi-Source 跨库场景下写查询。该发布说明未提到 Ollama/本地模型 — [DBeaver 26.2](https://dbeaver.com/2026/09/09/dbeaver-26-2/)。官方比较表显示 Lite、Enterprise、Ultimate、CloudBeaver、Team 五个版本都含 "AI capabilities" — [dbeaver.com/edition](https://dbeaver.com/edition/)
- **DataGrip**：[第三方] 每个许可都含 AI Free 档，AI Pro 附加 $10/月；Agent 可使用自带 API Key、现有订阅或 JetBrains AI；2026.2 引入三个面向数据库的 AI agent skills — [julius.ai](https://julius.ai/articles/datagrip-pricing)；[ai2sql 2026 比较](https://builder.ai2sql.io/blog/best-ai-sql-tools-2026)（第三方，细节待官方核实）
- **Navicat**：AI Assistant 于 17.2.2（2025-03-13）加入；17.3.0（2025-07-21）把 Ask AI 集成进 Query；17.3.7（2025-12-03）支持把标签页内容附给 AI，并可切换 Ask AI 回答语言；18.0.2（2026-09-16）新增 Fill with AI、AI 生成表结构、AI 填写注释 — [Release Note](https://www.navicat.com/en/products/navicat-premium-release-note)。App Store 描述了 AI Chat 的多聊天室、附加库结构、对比多模型答案 — [App Store](https://apps.apple.com/us/app/navicat-premium-17/id1594061654?mt=12)。帮助中心列出的提供商为 OpenAI ChatGPT、Google Gemini、DeepSeek、Ollama — [Navicat Help Center](https://help.navicat.com/hc/en-us/articles/46708511378713-What-AI-features-are-available-in-Navicat-and-how-can-they-help-me-with-database-development)（经搜索摘要获取，页面直抓 403）；On-Prem Server 3.1 博客称支持 Anthropic Claude、Gemini、DeepSeek、Grok 等 — [Navicat Blog](https://www.navicat.com/company/aboutus/blog/3575-getting-started-with-ai-assistants-in-navicat-on-prem-server-3-1)；[第三方] 17.3 增加了 Grok、Claude、Qwen — [CSDN](https://damodev.csdn.net/6a4321ae662f9a54cb85fd5b.html)
- **DbGate**：AI 工具在 Premium 档，包括 Database Chat（自然语言提问，生成并执行 SQL，执行前须用户明确许可）、错误解释、AI 生成主题。官网未说明 BYOK 和所用模型 — [dbgate.io](https://www.dbgate.io/)
- **Beekeeper Studio**：AI Shell 列在 Power Tools 中，比较表显示 Professional/Business 可用；未说明 BYOK 和本地模型 — [beekeeperstudio.io/pricing](https://www.beekeeperstudio.io/pricing)

### Inferences
- 隐私控制已是竞争点：DBeaver 支持企业网关自定义 URL，Navicat 支持 Ollama，QoreDB 支持完全本地，DbGate 执行前需确认。DBLens 面向国内政企，应把"国产大模型（DeepSeek/Qwen 等）+ 私有化/本地模型 + 发送内容可控（仅 schema 或含数据）+ 执行前确认"作为默认设计。
- 海外工具的 AI 对国产库方言（达梦 PL/SQL 兼容、金仓 Oracle/MySQL 模式）没有专门优化，这一点是推断，未见反例来源。

### Gaps
- DataGrip AI Assistant/Junie 在 DataGrip 中的具体能力、离线/本地模型支持和数据隐私选项，没有拿到官方一手页面。
- Supabase Studio AI 助手的模型和隐私开关（本次抓取的文档页不相关）。
- Navicat 是否把 schema 或数据发送给模型、是否有开关，官方帮助页未直接抓到。

## 问题3：治理功能（访问控制、审计、审批、团队共享、SSO）

### Takeaway
海外客户端的治理能力集中在团队/Web 版：DBeaver Team Edition（RBAC、全员查询历史、SAML/Azure AD SSO）、CloudBeaver、DbGate Team Premium（用户/角色管理、外部 IdP）、Beekeeper Business（SSO 云库认证、气隙部署）、Navicat On-Prem Server（团队共享）。本次没有发现任何一款原生提供 SQL 变更审批/工单流程。这是国内 Bytebase/Archery/Yearning 类工具的强项，海外 GUI 客户端基本空白。

### Cited Findings
- **DBeaver**：Advanced Role Management 仅 Team Edition 提供；"All users query history" 由 CloudBeaver 和 Team Edition 提供；SAML/Azure AD/SSO 统一访问由 CloudBeaver 和 Team Edition 提供；实时协作和共享脚本/连接由 CloudBeaver 和 Team 提供；页面未提到 LDAP 和审批流 — [dbeaver.com/edition](https://dbeaver.com/edition/)。26.2 支持 GCP Secret Manager / Azure Key Vault 托管凭据 — [DBeaver 26.2](https://dbeaver.com/2026/09/09/dbeaver-26-2/)
- **DbGate Team Premium**：用户、连接和角色管理界面，外部身份提供商，Azure Managed Identity；官网未提到审计日志 — [dbgate.io](https://www.dbgate.io/)
- **Beekeeper Studio**：Professional/Business 提供 Cloud workspaces 共享连接和查询；Business 提供 SSO 云库认证、气隙系统支持、Amazon IAM/Azure EntraID 连接；Professional 起支持 Kerberos/Windows 认证 — [beekeeperstudio.io/pricing](https://www.beekeeperstudio.io/pricing)
- **TablePlus**：只有 Team 许可的 License Manager，没有提到治理功能 — [tableplus.com/pricing](https://tableplus.com/pricing)
- **Navicat**：Navicat 18 数据脱敏（属于开发/测试数据安全）— [Navicat Blog](https://www.navicat.com/company/aboutus/blog/4008-data-masking-in-navicat-18-safer-dev-and-test-environments)；On-Prem Server 是私有化团队协作服务器 — [Navicat Blog](https://www.navicat.com/company/aboutus/blog/3575-getting-started-with-ai-assistants-in-navicat-on-prem-server-3-1)
- **SQLynx**：[第三方] 企业版支持多用户权限管理 — [DEV Community](https://dev.to/concerate/sqlynx-best-web-based-sql-editor-for-developers-and-data-analysts-1p0f)

### Inferences
- "客户端 + 轻量治理（细粒度权限、审计、敏感数据脱敏、高危 SQL 审批）"在海外 GUI 中只做到一半。DBLens 可以在 Web 团队版中补上审批和审计，用来区隔 DBeaver Team 和 DbGate。

### Gaps
- Navicat On-Prem Server 的权限模型和审计能力细节未抓取。
- DataGrip 没有团队治理能力（推断：它是纯个人 IDE），未找到官方说明。
- 各产品是否支持 LDAP、审计日志导出，均未见官方明确说明。
