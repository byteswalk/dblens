DBLens（数洞）首个预览版。

- 数据库：MySQL / MariaDB、PostgreSQL、Oracle、达梦、SQL Server，以及 TiDB、OceanBase、openGauss、人大金仓。
- 查询工作台：对象树、SQL 编辑器（高亮、补全、格式化）、多语句执行与取消、事务、结果导出、历史与收藏。
- 数据：表数据编辑，CSV、Excel、SQL 文件的导入和导出。
- 结构：表设计器、模型文件、结构比对与同步、ER 图、数据字典和设计文档导出。
- 迁移：库到库的结构和数据迁移，支持断点续传和校验。
- 形态：桌面程序（Windows、macOS、Linux）和浏览器模式，支持自动更新。

这是预览版，安装包没有代码签名，首次运行时系统会提示未知发布者。
