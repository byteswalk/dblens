# 麒麟 ARM64 实机验证

2026-11-06 在用户提供的国产化机器上验证 ARM64 版本。机器平时有人用：东西都放在 `/tmp/dblens-arm` 一个目录里，不装系统包、不用 sudo、不改系统配置，测完删除。

## 环境

- 银河麒麟桌面操作系统 V10 SP1，内核 5.4.18，aarch64，8 核、7G 内存，glibc 2.31。
- 系统带 OpenJDK 11 和 Zulu 18；审计版控制面要 21，用免安装的 Temurin 21.0.13（哈希和 Adoptium 官方一致）放在测试目录里。
- 测试库在 VM .106 上，223 访问不到：从本机开 SSH 隧道，端口只绑 223 的 127.0.0.1（用户同意后）。

## 构建

在 VM .106 的 `rust:1.99-bookworm` 容器里用 zig 和 cargo-zigbuild 交叉编译，目标 `aarch64-unknown-linux-gnu.2.28`：浏览器版服务端、工作区全部测试程序、审计版引擎。二进制只依赖 libc、libm、libpthread、libdl，最高引用 GLIBC_2.28。

- 依赖用 `cargo vendor` 打包上传（工作区和审计版引擎一起：`-s` 要写引擎 `Cargo.toml` 的绝对路径，否则 Windows 上路径比对失败）。
- 仓库的 `rust-toolchain.toml` 锁定工具链：`rustup target add` 要在仓库目录里执行，否则目标装到容器的默认工具链上，编译报找不到 `std`。
- 测试程序运行时按编译时的路径找夹具和快照：容器里把源码挂到和 223 上相同的路径（`/tmp/dblens-arm/src`）。223 上没有 cargo，快照测试要设 `INSTA_WORKSPACE_ROOT`。

## 结果

- 不连库：1174 个测试里 1169 个通过。剩下 3 个是 `dblens-server` 的 `cli` 测试，按编译时的路径启动服务端，223 上没有这个路径；另 2 个是测试的时序假设，已修（见下）。
- 连库（经隧道）：PG、MySQL 全部通过；达梦走 JDBC 桥接（ARM 上的 JDK 21）全部通过；Oracle 19c 走 JDBC 和原生客户端（Instant Client 23.26 ARM64）各 74 个都通过。
- 浏览器版：服务端只听本机回环，经 SSH 本地转发用真实鼠标测了 SQLite 文件连接、浏览、编辑写回（写回后在 223 上直接读文件确认）。
- 审计版：控制面跑在 223 的 JDK 21 上，ARM64 引擎，元库是 VM 上 PG 的独立库。真实鼠标走完：申请人在工作台查询 → 生产库 DDL 被拦 → 提交工单 → 审批人通过 → 申请人执行成功（到 PG 上确认表已建）；`--verify-backup` 退出码 0。

## 发现并修了的

| 问题 | 处理 |
|---|---|
| 没有可用系统钥匙串的机器（这台麒麟、服务器上的浏览器版）上，没存密码的 SQLite 连接也被“密码库已锁定”挡住 | 密码库先看有没有存过密码，没存过不需要解锁 |
| SQL 文件取消测试只等 50 毫秒就取消，慢机器上第一条还没执行 | 改为等第一条执行完再取消 |
| 导入测试的等待上限 2 分钟，这台机器每次刷盘约 270 毫秒，SQLite 逐行提交要几分钟 | 放宽到 10 分钟 |
| Linux 上只在连接设置里指定 Instant Client 目录，报找不到 `libnnz.so`：`libclntsh.so` 的依赖按系统库搜索路径找；`libnnz.so` 没有 SONAME，预加载也不管用 | 报错时提示要设 `LD_LIBRARY_PATH` 或用 ldconfig 注册，再重启 DBLENS |
| 审计版 `--verify-backup` 也会占服务端口、启动引擎，实例运行时校验报端口占用 | 校验模式用随机本机端口、不启动引擎（审计版仓库） |

## 限制

- 桌面版（Tauri 2）要 WebKitGTK 4.1，麒麟 V10 SP1 的源里只有 4.0，桌面版在这版麒麟上跑不了。2026-11-06 用户决定：老系统不做桌面版（不自带 WebKitGTK 打包），这类机器用浏览器版。
- 这台机器刷盘很慢（SQLite 每次提交约 270 毫秒，主目录里有安全软件，可能相关）。导入的“跳过出错行”原来逐行提交，2026-11-06 改为一个事务里用保存点逐行重试、整批提交一次（GoldenDB、GBase 8s 仍逐行提交）。
- 没验证：审计版 `install.sh`、systemd（会改系统），统信 UOS，龙芯。
