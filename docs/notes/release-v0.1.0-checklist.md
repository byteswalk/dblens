## 发布步骤

流程见 `m0-4d-release.md`，全部在本机完成，不使用 GitHub Actions。v0.1.0 先发 Windows。

1. 确认私钥和密码的备份能读出。
2. 跑完本地检查和实库测试。
3. 设置签名环境变量后打包，写 `latest.json`。
4. 打标签 `v0.1.0` 并推送，建草稿 Release，上传安装包和 `latest.json`。
5. 检查后点 Publish。
