## 结构

```text
web/src/
  main.tsx                 取令牌，挂载 App
  app/
    App.tsx                读取设置后按主题配置 antd，挂上外壳和全局对话框
    Shell.tsx              布局：标题栏；活动栏 + 可拖动可折叠的侧栏 + 工作区；状态栏
    TitleBar.tsx           自绘标题栏：菜单、标题、置顶、窗口按钮；空白处拖动、双击最大化
    menus.ts               菜单数据（按状态生成，单独测试）
    StatusBar.tsx · SettingsDialog.tsx · useShellInfo.ts · ui.ts（界面状态）· context.ts（接口客户端）· shell.css
  features/
    connections/           form.ts（表单与连接配置互转、校验）· vault.ts（密码库锁定时解锁后重试）
                           ConnectionDialog.tsx · VaultDialog.tsx
    tree/                  nodes.ts（节点键、分类、过滤）· ObjectTree.tsx
  shared/                  api · ws 协议（exec）· token · theme · settings · shell（桌面原生能力）
crates/dblens-desktop/src/shell.rs  页面可调用的三个命令和状态事件
crates/dblens-desktop/capabilities/main.json  只放行这三个命令和事件监听，只对 http://127.0.0.1:* 生效
```

## 要点

- **设置接口**：
  - `GET /api/settings`、`PUT /api/settings/{key}`，**只读写 `ui.` 开头的键**。
  - 同一张表里还有服务层自己的设置，如已确认的原生库目录 `native.*`。如果允许经设置接口读写它们，就能绕过确认库目录时"必须是绝对路径"的校验（实测中发现）。
- **面板布局**：react-resizable-panels 的 `useDefaultLayout` 接受任意 `getItem/setItem` 存储。传入 `shared/settings.ts` 的 `layoutStorage`，侧栏宽度就存进 `ui.layout.*`。
- **自绘标题栏**：
  - Windows、Linux 去掉系统标题栏（`decorations(false)`），系统菜单只在 macOS 上创建。
  - 页面经三个命令调用原生能力：
    - `shell_info`：读取状态；
    - `window_action`：最小化、最大化或还原、关闭、拖动、置顶、恢复默认位置、检查更新、关于、退出；
    - `set_auto_check_update`：开关启动时的自动检查。
  - 状态变化（最大化、置顶、自动检查）经事件 `dblens://shell` 推给页面。
  - Ctrl+Shift+T 仍是系统热键，切换后同样推送事件，标题栏按钮跟着变。
- **权限**：
  - `build.rs` 用 `AppManifest::commands` 为三个命令生成 `allow-*` 权限，`capabilities/main.json` 引用它们。
  - `local: false`、`remote.urls: ["http://127.0.0.1:*"]`：只有进程内接口服务提供的页面能调用。
  - 构建时 Tauri 会生成 `crates/dblens-desktop/permissions/autogenerated/`，已加入 `.gitignore`（计划中未写，执行时补上）。
- **浏览器模式**：没有 `__TAURI_INTERNALS__`，`shared/shell.ts` 的 `desktop` 为 null。
  - 标题栏只有菜单和标题；
  - 没有"窗口"菜单，"帮助"只有"关于"。
- **密码库**：任何接口返回 `locked` 时，`withVault` 先请用户设置或输入主密码，成功后重试一次。
- **对象树**：
  - 分类与各方言的元数据模板对应：MySQL 系没有物化视图和序列；Oracle、达梦有同义词。
  - 系统 schema 收在"系统"分组里。
  - "刷新"会先清后端缓存，再丢掉节点下面已加载和已展开的内容。

## 实测（Windows 11；浏览器模式 + 桌面版；5 个测试库）

> 涉及数据库的各项在写计划时的预构建副本中验证。正式执行时测试虚拟机不可达，只重新验证了不依赖数据库的部分（界面、桌面窗口控制、全部单元测试），连库各项待虚拟机恢复后补测。

- **浏览器模式**：
  - 新建 PG 连接：测试连接成功，保存后出现在树中，环境标记和颜色正确。
  - 编辑连接时正确带出已保存的配置，密码留空。
  - 对象树：
    - PG：schema → 表（注释、数量）→ 列（类型、非空、注释，主键标钥匙）；
    - MySQL：表、函数和过程；
    - Oracle：schema、同义词（含 db link）；
    - 达梦：schema 列表。
  - 过滤"员工"只留下匹配的表。
  - 主题和侧栏宽度保存后，刷新页面恢复。
  - 右键菜单项齐全。
- **桌面版**：
  - 没有系统标题栏，页面能调用三个命令；
  - 置顶按钮、菜单"窗口 → 窗口置顶"、Ctrl+Shift+T 都能切换，标题栏按钮随之变色；
  - 最大化 / 还原按钮、双击标题栏、拖动标题栏（移动 120×60 像素）、最小化、"恢复默认窗口位置和大小"都正常；
  - 点关闭后保存了窗口状态。

## 遗留

- 侧栏的"历史 / 收藏 / 运维查询"目前是占位，由 M1c 实现。右键菜单的"查看 DDL / 生成 SQL / 查看数据"同样在 M1c 加入。
- 工作区目前是欢迎页。编辑器标签页、结果面板、状态栏中执行相关的信息由 M1b 实现。
- 编辑连接时，密码留空表示沿用已保存的密码。但"测试连接"接口不会读取已保存的密码，所以测试时要重新输入。以后可以让测试接口接受连接配置的 id。
- 选择原生库目录、CA 证书文件目前要手填路径。桌面版可以在 M1c 接入系统文件对话框，与导出共用。
- 分类后面的数量是已加载对象的总数，过滤时不随过滤结果变化。
- 测试时注意：Windows 上保存的密码存在系统凭据管理器中（目标名 `profile:<id>.DBLens`）。删除连接会一并删除它。
