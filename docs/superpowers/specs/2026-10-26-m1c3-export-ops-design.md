# M1c3 导出与运维查询 设计

日期：2026-10-26。上级设计：`docs/superpowers/specs/2026-10-25-m1-workbench-design.md`（1 节侧栏、2.2 节 Tauri 边界、3 节后端新增）；总设计文档 `docs/superpowers/specs/2026-10-22-dblens-design.md` 中"导出由后端重新执行查询，边取边写文件"和"按方言内置一组常用运维查询"两条。M1c 的第三份（M1c1 历史与收藏、M1c2 对象操作已完成）。

## 1. 目标与范围

- **导出查询结果**：
  - 结果面板中某个结果集对应的语句；
  - 数据标签当前的对象、过滤和排序。

  导出时后端重新执行查询，边读边写文件，不受界面 10 万行显示上限的限制。格式为 CSV、xlsx、INSERT 语句、JSON。
- **运维查询**：新增侧栏，按当前连接的方言列出会话、锁、存储、慢 SQL 等常用查询。点击后在新标签中执行；结束会话的语句只生成，不执行。

不做：
- 对象树中"导出整表"、CSV/Excel 导入（M2）；
- 只导出选中的列、导出前预览；
- 结果表格的行右键菜单。

## 2. 已定的决策（2026-10-26 与用户确认）

| 问题 | 结论 |
|---|---|
| 导出入口 | 结果面板（导出那条语句的完整结果）和数据标签（当前对象、过滤、排序） |
| 导出选项 | 对话框：选格式，每种格式给必要的选项（见 3.4）；显示进度，可以取消；桌面版完成后可打开所在文件夹 |
| 导出用哪个会话 | 另开新会话，不占用标签的会话。标签有未提交的事务时提示看不到未提交的修改 |
| 结束会话语句 | 会话、锁查询的结果中多一列"结束会话语句"，用户复制后自己执行 |
| 导出的传输方式 | 导出任务：后端在后台执行，前端轮询进度；桌面版直接写到用户选的路径，浏览器模式写临时文件后下载 |

## 3. 导出：后端

### 3.1 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/exports` | 提交任务，返回 201 和 `{id}` |
| GET | `/api/exports/{id}` | `{state, rows, warnings, error, file_name}`；`state` 为 `running` / `done` / `failed` / `cancelled` |
| DELETE | `/api/exports/{id}` | 进行中时取消；已结束时删除任务记录和临时文件 |
| GET | `/api/exports/{id}/file` | 浏览器模式下载文件（`Content-Disposition` 带文件名）；下载完成后删除临时文件 |

`POST` 的请求体：

```json
{
  "profile_id": "…",
  "source": { "sql": "SELECT …" },
  "format": "csv",
  "options": { "delimiter": ",", "header": true, "bom": true, "null_text": "" },
  "path": "D:\\exports\\orders.csv",
  "file_name": "orders.csv"
}
```

- `source` 二选一：
  - `{ "sql": "…" }`：结果面板导出的语句；
  - `{ "data": { "schema", "object", "filter", "order" } }`：数据标签，由后端用已有的 `data_sql` 生成 SELECT。
- `path`：桌面版由系统"另存为"对话框选出，后端直接写到这里（服务和界面在同一台机器上）。浏览器模式不给 `path`，后端写到数据目录下的 `exports/` 临时文件中。
  - 给出 `path` 时，后端只接受绝对路径，父目录必须存在。
  - 只有桌面程序的本机服务接受 `path`：`dblens-server` 的浏览器模式下，界面可能在另一台机器上，拒绝 `path`（`invalid`）。
- 同时进行的导出任务最多 4 个，超出时返回 `busy`。
- 服务退出时，进行中的任务取消，临时目录清空。已结束的任务记录在内存中保留 1 小时。

### 3.2 执行

- 只接受单条查询语句：用已有的语句分析判断（SELECT、WITH、SHOW、VALUES 等返回结果的语句）。其他类型返回 `invalid`，避免重复执行修改语句。
- 每个任务另开一个会话（经 `SessionManager`，不出现在界面的标签中）：
  - 执行、按批读取（每批 1000 行）、写文件，结束后关闭会话；
  - 取消时取消语句，并照 M1c2 的做法读完剩下的行后丢弃；
  - 照常记入执行历史。
- 生产环境不需要确认：只执行查询。
- 失败（连接失败、SQL 错误、写文件失败）：任务为 `failed`，错误文字按当前界面语言给出；已写出的部分文件删除。

### 3.3 大字段

现在 4 个驱动读大字段时都只取前 64 KB 做预览（`DEFAULT_LOB_PREVIEW_BYTES`），直接导出会悄悄截断。

- 驱动的连接增加大字段读取上限的设置：
  - 界面会话保持 64 KB；
  - 导出会话放宽到每个值 256 MB。
- 仍然超出的值照样截断，任务的 `warnings` 中报出截断的值的个数。
- 驱动的一致性测试增加：放宽上限后读出完整的大字段。

### 3.4 格式

| 格式 | 写法 | 选项（默认值） |
|---|---|---|
| CSV | `csv` 库（新增依赖），RFC 4180 转义 | 分隔符：逗号 / 制表符 / 分号（逗号）；表头（是）；UTF-8 BOM（是，Excel 直接打开中文不乱码）；NULL 写作：空 / `NULL`（空） |
| xlsx | `rust_xlsxwriter` 的低内存模式，边写边落盘 | 无。第一行为加粗的表头；数字、日期按原类型写入；单个工作表到 1048575 行后续到下一个工作表（Sheet1、Sheet2…） |
| INSERT | 值用方言已有的字面量生成 | 目标表名（数据标签默认为对象的限定名，查询结果默认为 `table_name`）；每条语句的行数：1 / 多行合并（100） |
| JSON | `serde_json`，流式写出对象数组 | 无。每行一个对象，键为列名；数字写成 JSON 数字，其余写成字符串 |

- **NULL**：CSV 按选项写；xlsx 留空；INSERT 写 `NULL`；JSON 写 `null`。
- **二进制值**：CSV、JSON 写成 base64；INSERT 用该方言的十六进制写法；xlsx 写成"二进制 N 字节"文字。
- **超长文本**：xlsx 单元格最多 32767 个字符，超出时截断，计入警告。
- **列名重复时**（如 `SELECT a.id, b.id`）：JSON 的键依次加后缀 `_2`、`_3`；INSERT 的列名用原名（数据库会报错，由用户改表名或列名）。

## 4. 导出：前端

### 4.1 入口

- 结果面板：每个结果集标签右侧有"导出"按钮。导出的是这个结果集所属语句的原文（从执行时的全文中取）。
  - 执行计划的结果、非查询语句不显示按钮。
- 数据标签：工具栏加"导出"按钮，导出当前对象、过滤和排序。

### 4.2 流程

1. 点"导出"，弹出导出对话框：选格式和选项。
2. 标签有未提交的事务时，对话框顶部提示"导出用新会话执行，看不到当前标签中未提交的修改"。
3. 点"导出"：
   - 桌面版：弹出系统"另存为"对话框，默认文件名为对象名或 `export`，加日期时间和扩展名；
   - 浏览器模式：直接提交。
4. 导出进行中：右下角的通知显示已写行数和"取消"按钮，可以继续其他操作。前端每秒查询一次进度。
5. 完成：
   - 桌面版：通知显示行数和警告，"打开所在文件夹"按钮；
   - 浏览器模式：自动下载文件。
   - 有警告时（大字段截断、xlsx 单元格截断）列出数量。
6. 失败：通知中显示错误。

### 4.3 原生能力

`shared/shell.ts` 增加：
- `saveDialog(defaultName, filters) -> path | null`：系统"另存为"对话框（Tauri 的 dialog 插件，已在依赖中）；
- `revealInFolder(path)`：在文件管理器中显示文件。

Tauri 权限只开放这两项。浏览器模式没有这两个函数，界面走下载流程。

## 5. 运维查询

### 5.1 模板

放在 `dblens-dialect/sql/ops/<方言>.sql`，按 `-- [键]` 分段，写法与元数据模板相同。每段开头用注释写明名称（中、英）和分类，例如：

```sql
-- [sessions]
-- name.zh-CN: 会话列表
-- name.en: Sessions
-- category: session
SELECT …
```

- 方言：mysql、mariadb、postgres、oracle、dameng。
- 兼容库（TiDB、OceanBase、PolarDB、金仓、openGauss、GaussDB、HighGo 等）没有专门的模板时，用所属系列的模板。
- 分类：`session`（会话）、`lock`（锁）、`storage`（存储）、`sql`（SQL 统计）。

每种数据库的查询：

| 键 | 名称 | 说明 |
|---|---|---|
| `sessions` | 会话列表 | 用户、主机、状态、当前语句、已运行时长；附"结束会话语句"列 |
| `running` | 正在执行的语句 | 只列执行中的，按已运行时长倒序；附"结束会话语句"列 |
| `locks` | 锁等待 | 等待方、阻塞方、对象、等待时长；附结束阻塞方会话的语句 |
| `storage` | 存储使用 | Oracle、达梦：表空间的总量、已用、使用率；MySQL、PG：各库大小 |
| `largest_tables` | 占用最大的表 | 前 20，含索引 |
| `slow_sql` | 慢 SQL | MySQL：`performance_schema.events_statements_summary_by_digest`；PG：`pg_stat_statements`；Oracle：`V$SQL`；达梦：`V$LONG_EXEC_SQLS`。按平均耗时倒序，前 20 |

结束会话语句：

| 方言 | 语句 |
|---|---|
| MySQL 系 | `KILL <id>` |
| PG 系 | `SELECT pg_terminate_backend(<pid>)` |
| Oracle | `ALTER SYSTEM KILL SESSION '<sid>,<serial#>' IMMEDIATE` |
| 达梦 | `SP_CLOSE_SESSION(<sess_id>)` |

缺权限或缺插件时（如 PG 没有安装 pg_stat_statements、Oracle 用户不能读 V$ 视图），直接显示数据库的报错，不另做判断。

### 5.2 接口

`GET /api/profiles/{id}/ops` → `[{key, name, category, sql}]`：
- 按连接已识别出的变体选模板；没连接过时按驱动选；
- `name` 按当前界面语言给出。

### 5.3 侧栏

- 活动栏的"运维查询"图标打开侧栏，侧栏按分类列出查询。
- 用哪个连接：对象树中选中的连接，否则当前标签的连接；顶部显示连接名，可以从下拉框换。
- 操作：
  - 点击：用该连接新开查询标签，填入 SQL 并执行；
  - 右键："在新标签中打开（不执行）"、"复制 SQL"。
- 没有连接时显示提示，引导新建连接。

## 6. 依赖

计划的第一个任务是依赖复查（`node scripts/check-deps.mjs`）。新增依赖：
- `csv`（Rust，MIT / Unlicense）：CSV 写入；
- `rust_xlsxwriter`（MIT / Apache-2.0）：xlsx 写入，上级设计已指定。

两者都按依赖原则取发布满 7 天的最新正式版。前端不新增依赖（`@tauri-apps/plugin-dialog` 的前端调用经已有的 Tauri 命令封装，见 4.3）。

## 7. 错误处理

- 导出提交时的错误（不是查询语句、路径不可写、任务过多）：对话框中显示。
- 导出执行中的错误：通知中显示，任务为 `failed`，已写的部分文件删除。
- 运维查询的错误：沿用查询标签的显示方式（数据库的报错原文）。

## 8. 测试

- **单元测试**：
  - 四种格式的写入：转义、NULL、二进制、中文、超长截断、xlsx 分表、JSON 重复列名；
  - 运维模板的解析：每种方言都有全部 6 个键；变体回退到系列模板；
  - 前端：导出对话框的默认选项和文件名；运维侧栏的分组。
- **接口测试**（假驱动）：提交、进度、取消、下载、非查询语句被拒绝、浏览器模式拒绝 `path`、任务数上限。
- **实库测试**（5 个库）：
  - 导出一个含大字段（超过 64 KB）和中文的查询，四种格式各一次，核对行数和内容完整；
  - 逐个执行全部运维查询：测试账号权限不够的，记下数据库的报错，在说明文档中注明。
- **浏览器实测**：5 个库，中英文界面。桌面版的"另存为"和"打开所在文件夹"在桌面程序中验证（系统对话框需要用户点击一次）。
