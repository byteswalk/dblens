# M8a GBase 8s：JDBC 桥接、浏览、查询 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通过 Java 桥接进程和官方 JDBC 驱动支持 GBase 8s：连接、库 → 属主 → 对象浏览、SQL 和过程脚本、结果编辑、运维、危险语句确认；M8b 的功能后端报 `gbase.later`、前端置灰。

**Architecture:** 新 crate `dblens-driver-jdbc` 经 stdin/stdout 的二进制帧与全应用唯一的 Java 进程通信，用 `dblens_driver::blocking::into_async` 接入现有 `Connection`。Java 工程 `bridge/` 无第三方依赖，打包时生成 jar 和 jlink 精简 JRE。方言层新增 `Family::Informix`、`Variant::Gbase8s`，元数据和运维查系统表，服务层沿用 SQL Server 的"连接 + 库"范围。

**Tech Stack:** Rust（tokio、libstd 进程和管道）、Java 11 语法级别（JDK 自带类）、官方 `gbasedbtjdbc_3.6.5_2L1_13.jar`、minijinja 模板、insta、React 19 + antd 6、sql-formatter。

**Spec:** `docs/superpowers/specs/2026-10-30-m8a-gbase8s-design.md`

```text

值：u8 标记 + 内容

请求类型：1 connect | 2 execute | 3 fetch | 4 cancel | 5 commit | 6 rollback | 7 set_autocommit | 8 ping | 9 close | 10 server_info | 11 set_lob_limit | 12 end_exec
响应类型：128 ok | 129 connected(u64 连接号) | 130 result(列) | 131 affected(u64) | 132 rows(u8 done, u32 行数, 值…) | 133 error(i32 code, 字符串 sqlstate, 字符串 message) | 134 server_info(字符串 product, 字符串 version)
```

```rust
//! Java 桥接进程的线上格式。Java 端见 bridge/src/dblens/bridge/Frame.java，两边必须同时改。

use std::io::{self, Read, Write};

use chrono::{NaiveDate, NaiveDateTime, NaiveTime};
use dblens_core::{Error, LobPreview, Result, Row, Value, msg};

/// 单帧上限：防止协议错位时按乱码长度分配内存。
const MAX_FRAME: usize = 256 * 1024 * 1024;

#[derive(Debug, Clone, PartialEq)]
pub enum Req {
    Connect { driver_class: String, url: String, user: String, password: String, jar_dir: String, timeout_secs: u32 },
    Execute { conn: u64, sql: String, params: Vec<Value> },
    Fetch { conn: u64, max_rows: u32 },
    Cancel { conn: u64 },
    Commit { conn: u64 },
    Rollback { conn: u64 },
    SetAutocommit { conn: u64, on: bool },
    Ping { conn: u64 },
    Close { conn: u64 },
    ServerInfo { conn: u64 },
    SetLobLimit { conn: u64, bytes: u64 },
    EndExec { conn: u64 },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Column {
    pub name: String,
    pub type_name: String,
    pub nullable: Option<bool>,
    pub precision: Option<u32>,
    pub scale: Option<i32>,
}

#[derive(Debug, Clone, PartialEq)]
pub enum Resp {
    Ok,
    Connected(u64),
    Result(Vec<Column>),
    Affected(u64),
    Rows { done: bool, rows: Vec<Row> },
    Error { code: i32, sqlstate: String, message: String },
    ServerInfo { product: String, version: String },
}

fn put_str(out: &mut Vec<u8>, s: &str) {
    out.extend((s.len() as u32).to_be_bytes());
    out.extend(s.as_bytes());
}

fn put_value(out: &mut Vec<u8>, v: &Value) -> Result<()> {
    match v {
        Value::Null => out.push(0),
        Value::Bool(b) => out.extend([1, u8::from(*b)]),
        Value::Int(i) => {
            out.push(2);
            out.extend(i.to_be_bytes());
        }
        Value::Float(f) => {
            out.push(3);
            out.extend(f.to_be_bytes());
        }
        Value::Decimal(s) => {
            out.push(4);
            put_str(out, s);
        }
        Value::String(s) => {
            out.push(5);
            put_str(out, s);
        }
        Value::Bytes(b) => {
            out.push(6);
            out.extend((b.len() as u32).to_be_bytes());
            out.extend(b);
        }
        Value::Date(d) => {
            out.push(7);
            put_str(out, &d.format("%Y-%m-%d").to_string());
        }
        Value::Time(t) => {
            out.push(8);
            put_str(out, &t.format("%H:%M:%S%.6f").to_string());
        }
        Value::DateTime(t) => {
            out.push(9);
            put_str(out, &t.format("%Y-%m-%dT%H:%M:%S%.6f").to_string());
        }
        other => return Err(Error::invalid(msg!("jdbc.unsupported_param", value = format!("{other:?}")))),
    }
    Ok(())
}

/// 编码一条请求，含帧头。
pub fn encode_req(id: u64, req: &Req) -> Result<Vec<u8>> {
    let mut b = Vec::new();
    let (kind, conn) = match req {
        Req::Connect { driver_class, url, user, password, jar_dir, timeout_secs } => {
            for s in [driver_class, url, user, password, jar_dir] {
                put_str(&mut b, s);
            }
            b.extend(timeout_secs.to_be_bytes());
            (1u8, None)
        }
        Req::Execute { conn, sql, params } => {
            b.extend(conn.to_be_bytes());
            put_str(&mut b, sql);
            b.extend((params.len() as u32).to_be_bytes());
            for p in params {
                put_value(&mut b, p)?;
            }
            (2, None)
        }
        Req::Fetch { conn, max_rows } => {
            b.extend(conn.to_be_bytes());
            b.extend(max_rows.to_be_bytes());
            (3, None)
        }
        Req::Cancel { conn } => (4, Some(*conn)),
        Req::Commit { conn } => (5, Some(*conn)),
        Req::Rollback { conn } => (6, Some(*conn)),
        Req::SetAutocommit { conn, on } => {
            b.extend(conn.to_be_bytes());
            b.push(u8::from(*on));
            (7, None)
        }
        Req::Ping { conn } => (8, Some(*conn)),
        Req::Close { conn } => (9, Some(*conn)),
        Req::ServerInfo { conn } => (10, Some(*conn)),
        Req::SetLobLimit { conn, bytes } => {
            b.extend(conn.to_be_bytes());
            b.extend(bytes.to_be_bytes());
            (11, None)
        }
        Req::EndExec { conn } => (12, Some(*conn)),
    };
    if let Some(c) = conn {
        b.extend(c.to_be_bytes());
    }
    let mut out = Vec::with_capacity(b.len() + 13);
    out.extend(((b.len() + 9) as u32).to_be_bytes());
    out.extend(id.to_be_bytes());
    out.push(kind);
    out.extend(b);
    Ok(out)
}

struct Cur<'a>(&'a [u8]);

impl Cur<'_> {
    fn take(&mut self, n: usize) -> Result<&[u8]> {
        if self.0.len() < n {
            return Err(Error::connect(msg!("jdbc.bad_frame")));
        }
        let (a, b) = self.0.split_at(n);
        self.0 = b;
        Ok(a)
    }
    fn u8(&mut self) -> Result<u8> {
        Ok(self.take(1)?[0])
    }
    fn u32(&mut self) -> Result<u32> {
        Ok(u32::from_be_bytes(self.take(4)?.try_into().expect("长度已检查")))
    }
    fn u64(&mut self) -> Result<u64> {
        Ok(u64::from_be_bytes(self.take(8)?.try_into().expect("长度已检查")))
    }
    fn string(&mut self) -> Result<String> {
        let n = self.u32()? as usize;
        String::from_utf8(self.take(n)?.to_vec()).map_err(|_| Error::connect(msg!("jdbc.bad_frame")))
    }
    fn opt_u32(&mut self) -> Result<Option<u32>> {
        Ok(if self.u8()? == 1 { Some(self.u32()?) } else { None })
    }
    fn value(&mut self) -> Result<Value> {
        let bad = || Error::connect(msg!("jdbc.bad_frame"));
        Ok(match self.u8()? {
            0 => Value::Null,
            1 => Value::Bool(self.u8()? != 0),
            2 => Value::Int(self.u64()? as i64),
            3 => Value::Float(f64::from_bits(self.u64()?)),
            4 => Value::Decimal(self.string()?),
            5 => Value::String(self.string()?),
            6 => {
                let n = self.u32()? as usize;
                Value::Bytes(self.take(n)?.to_vec())
            }
            7 => Value::Date(NaiveDate::parse_from_str(&self.string()?, "%Y-%m-%d").map_err(|_| bad())?),
            8 => Value::Time(NaiveTime::parse_from_str(&self.string()?, "%H:%M:%S%.f").map_err(|_| bad())?),
            9 => Value::DateTime(
                NaiveDateTime::parse_from_str(&self.string()?, "%Y-%m-%dT%H:%M:%S%.f").map_err(|_| bad())?,
            ),
            10 => Value::Lob(LobPreview {
                binary: self.u8()? != 0,
                preview: self.string()?,
                total_len: self.u64()?,
                truncated: self.u8()? != 0,
            }),
            11 => Value::Other { type_name: self.string()?, text: self.string()? },
            _ => return Err(bad()),
        })
    }
}

/// 解码响应内容。`columns` 是当前结果集的列数，只有 rows 用到。
pub fn decode_resp(kind: u8, body: &[u8], columns: usize) -> Result<Resp> {
    let mut c = Cur(body);
    Ok(match kind {
        128 => Resp::Ok,
        129 => Resp::Connected(c.u64()?),
        130 => {
            let n = c.u32()? as usize;
            let mut cols = Vec::with_capacity(n);
            for _ in 0..n {
                cols.push(Column {
                    name: c.string()?,
                    type_name: c.string()?,
                    nullable: match c.u8()? {
                        0 => Some(false),
                        1 => Some(true),
                        _ => None,
                    },
                    precision: c.opt_u32()?,
                    scale: c.opt_u32()?.map(|v| v as i32),
                });
            }
            Resp::Result(cols)
        }
        131 => Resp::Affected(c.u64()?),
        132 => {
            let done = c.u8()? != 0;
            let total = c.u32()? as usize;
            let mut values = Vec::with_capacity(total);
            for _ in 0..total {
                values.push(c.value()?);
            }
            let rows = if columns == 0 { Vec::new() } else { values.chunks(columns).map(<[Value]>::to_vec).collect() };
            Resp::Rows { done, rows }
        }
        133 => Resp::Error { code: c.u32()? as i32, sqlstate: c.string()?, message: c.string()? },
        134 => Resp::ServerInfo { product: c.string()?, version: c.string()? },
        _ => return Err(Error::connect(msg!("jdbc.bad_frame"))),
    })
}

/// 读一帧，返回（请求号，类型，内容）。
pub fn read_frame(r: &mut impl Read) -> io::Result<(u64, u8, Vec<u8>)> {
    let mut head = [0u8; 13];
    r.read_exact(&mut head)?;
    let len = u32::from_be_bytes(head[..4].try_into().expect("定长")) as usize;
    if !(9..=MAX_FRAME).contains(&len) {
        return Err(io::Error::new(io::ErrorKind::InvalidData, "帧长度异常"));
    }
    let mut body = vec![0; len - 9];
    r.read_exact(&mut body)?;
    Ok((u64::from_be_bytes(head[4..12].try_into().expect("定长")), head[12], body))
}

pub fn write_frame(w: &mut impl Write, frame: &[u8]) -> io::Result<()> {
    w.write_all(frame)?;
    w.flush()
}
```

```java
package dblens.bridge;

import java.io.*;
import java.nio.charset.StandardCharsets;

/** 线上格式，Rust 端见 crates/dblens-driver-jdbc/src/frame.rs，两边必须同时改。 */
final class Frame {
    static final int MAX = 256 * 1024 * 1024;
    final long id;
    final int kind;
    final DataInputStream in;

    private Frame(long id, int kind, byte[] body) {
        this.id = id;
        this.kind = kind;
        this.in = new DataInputStream(new ByteArrayInputStream(body));
    }

    /** 读一帧；对端关闭时返回 null。 */
    static Frame read(DataInputStream s) throws IOException {
        int len;
        try {
            len = s.readInt();
        } catch (EOFException e) {
            return null;
        }
        if (len < 9 || len > MAX) throw new IOException("bad frame length " + len);
        long id = s.readLong();
        int kind = s.readUnsignedByte();
        byte[] body = new byte[len - 9];
        s.readFully(body);
        return new Frame(id, kind, body);
    }

    static String str(DataInputStream in) throws IOException {
        byte[] b = new byte[in.readInt()];
        in.readFully(b);
        return new String(b, StandardCharsets.UTF_8);
    }

    /** 响应构造器。 */
    static final class Out {
        final ByteArrayOutputStream buf = new ByteArrayOutputStream();
        final DataOutputStream d = new DataOutputStream(buf);

        void str(String s) throws IOException {
            byte[] b = s.getBytes(StandardCharsets.UTF_8);
            d.writeInt(b.length);
            d.write(b);
        }

        /** 整帧写出；stdout 由多个线程共用，必须持锁。 */
        void send(DataOutputStream out, long id, int kind) throws IOException {
            byte[] b = buf.toByteArray();
            synchronized (out) {
                out.writeInt(b.length + 9);
                out.writeLong(id);
                out.writeByte(kind);
                out.write(b);
                out.flush();
            }
        }
    }
}
```

```java
package dblens.bridge;

import java.io.*;
import java.math.BigDecimal;
import java.nio.charset.StandardCharsets;
import java.sql.*;
import java.time.format.DateTimeFormatter;

/** JDBC 值与线上值的转换。值的标记见 Frame。 */
final class Values {
    private static final DateTimeFormatter TS = DateTimeFormatter.ofPattern("yyyy-MM-dd'T'HH:mm:ss.SSSSSS");

    static void bind(PreparedStatement p, int i, DataInputStream in) throws Exception {
        switch (in.readUnsignedByte()) {
            case 0: p.setObject(i, null); break;
            case 1: p.setBoolean(i, in.readBoolean()); break;
            case 2: p.setLong(i, in.readLong()); break;
            case 3: p.setDouble(i, in.readDouble()); break;
            case 4: p.setBigDecimal(i, new BigDecimal(Frame.str(in))); break;
            case 5: p.setString(i, Frame.str(in)); break;
            case 6: { byte[] b = new byte[in.readInt()]; in.readFully(b); p.setBytes(i, b); break; }
            case 7: p.setDate(i, Date.valueOf(Frame.str(in))); break;
            case 8: p.setTime(i, Time.valueOf(Frame.str(in).substring(0, 8))); break;
            case 9: p.setTimestamp(i, Timestamp.valueOf(Frame.str(in).replace('T', ' '))); break;
            default: throw new IOException("bad param tag");
        }
    }

    static void write(ResultSet r, int i, int type, String typeName, long lobLimit, Frame.Out o) throws Exception {
        DataOutputStream d = o.d;
        switch (type) {
            case Types.BOOLEAN: case Types.BIT: {
                boolean v = r.getBoolean(i);
                if (r.wasNull()) { d.writeByte(0); return; }
                d.writeByte(1); d.writeBoolean(v); return;
            }
            case Types.SMALLINT: case Types.INTEGER: case Types.BIGINT: {
                long v = r.getLong(i);
                if (r.wasNull()) { d.writeByte(0); return; }
                d.writeByte(2); d.writeLong(v); return;
            }
            case Types.REAL: case Types.FLOAT: case Types.DOUBLE: {
                double v = r.getDouble(i);
                if (r.wasNull()) { d.writeByte(0); return; }
                d.writeByte(3); d.writeDouble(v); return;
            }
            case Types.DECIMAL: case Types.NUMERIC: {
                BigDecimal v = r.getBigDecimal(i);
                if (v == null) { d.writeByte(0); return; }
                d.writeByte(4); o.str(v.toPlainString()); return;
            }
            case Types.DATE: {
                Date v = r.getDate(i);
                if (v == null) { d.writeByte(0); return; }
                d.writeByte(7); o.str(v.toString()); return;
            }
            case Types.TIMESTAMP: {
                // 精度不完整的 DATETIME 取回的是拼出来的日期，按文本返回才不失真
                if (!typeName.toLowerCase().contains("year to")) break;
                Timestamp v = r.getTimestamp(i);
                if (v == null) { d.writeByte(0); return; }
                d.writeByte(9); o.str(v.toLocalDateTime().format(TS)); return;
            }
            case Types.BLOB: case Types.BINARY: case Types.VARBINARY: case Types.LONGVARBINARY: {
                try (InputStream s = r.getBinaryStream(i)) {
                    if (s == null) { d.writeByte(0); return; }
                    writeBytes(s, lobLimit, o);
                }
                return;
            }
            case Types.CLOB: case Types.LONGVARCHAR: {
                try (InputStream s = r.getBinaryStream(i)) {
                    if (s == null) { d.writeByte(0); return; }
                    writeText(s, lobLimit, o);
                }
                return;
            }
            default:
        }
        String v = r.getString(i);
        if (v == null) { d.writeByte(0); return; }
        d.writeByte(5); o.str(v);
    }

    private static byte[] readUpTo(InputStream s, long limit, long[] total) throws IOException {
        ByteArrayOutputStream head = new ByteArrayOutputStream();
        byte[] b = new byte[8192];
        for (int n; (n = s.read(b)) > 0; ) {
            total[0] += n;
            long room = limit - head.size();
            if (room > 0) head.write(b, 0, (int) Math.min(room, n));
        }
        return head.toByteArray();
    }

    private static void writeBytes(InputStream s, long limit, Frame.Out o) throws IOException {
        long[] total = {0};
        byte[] head = readUpTo(s, limit, total);
        if (total[0] <= limit) {
            o.d.writeByte(6); o.d.writeInt(head.length); o.d.write(head); return;
        }
        StringBuilder hex = new StringBuilder();
        for (byte x : head) hex.append(String.format("%02x", x));
        o.d.writeByte(10); o.d.writeBoolean(true); o.str(hex.toString()); o.d.writeLong(total[0]); o.d.writeBoolean(true);
    }

    private static void writeText(InputStream s, long limit, Frame.Out o) throws IOException {
        long[] total = {0};
        byte[] head = readUpTo(s, limit, total);
        String text = new String(head, StandardCharsets.UTF_8);
        if (total[0] <= limit) { o.d.writeByte(5); o.str(text); return; }
        // 截断点可能落在多字节字符中间，去掉末尾的替换符
        if (text.endsWith("\uFFFD")) text = text.substring(0, text.length() - 1);
        o.d.writeByte(10); o.d.writeBoolean(false); o.str(text); o.d.writeLong(total[0]); o.d.writeBoolean(true);
    }

    private Values() {}
}
```

```java
package dblens.bridge;

import java.io.*;
import java.sql.*;
import java.util.concurrent.*;

/** 一条数据库连接：请求在自己的线程上串行执行；取消由读帧线程直接调用，不排队。 */
final class Session {
    final long id;
    final Connection conn;
    final DataOutputStream out;
    final ExecutorService worker;
    volatile Statement current;
    private ResultSet rs;
    private int[] types;
    private String[] typeNames;
    private long lobLimit = 256 * 1024;

    Session(long id, Connection conn, DataOutputStream out) {
        this.id = id;
        this.conn = conn;
        this.out = out;
        this.worker = Executors.newSingleThreadExecutor(r -> {
            Thread t = new Thread(r, "session-" + id);
            t.setDaemon(true);
            return t;
        });
    }

    void execute(long req, DataInputStream in) throws Exception {
        endExec();
        String sql = Frame.str(in);
        int n = in.readInt();
        PreparedStatement p = conn.prepareStatement(sql);
        current = p;
        for (int i = 1; i <= n; i++) Values.bind(p, i, in);
        boolean hasRs = p.execute();
        Frame.Out o = new Frame.Out();
        if (!hasRs) {
            o.d.writeLong(Math.max(p.getUpdateCount(), 0));
            current = null;
            p.close();
            o.send(out, req, 131);
            return;
        }
        rs = p.getResultSet();
        ResultSetMetaData m = rs.getMetaData();
        int c = m.getColumnCount();
        types = new int[c];
        typeNames = new String[c];
        o.d.writeInt(c);
        for (int i = 1; i <= c; i++) {
            types[i - 1] = m.getColumnType(i);
            typeNames[i - 1] = m.getColumnTypeName(i);
            o.str(m.getColumnLabel(i));
            o.str(typeNames[i - 1]);
            int nullable = m.isNullable(i);
            o.d.writeByte(nullable == ResultSetMetaData.columnNoNulls ? 0 : nullable == ResultSetMetaData.columnNullable ? 1 : 2);
            o.d.writeByte(1); o.d.writeInt(m.getPrecision(i));
            o.d.writeByte(1); o.d.writeInt(m.getScale(i));
        }
        o.send(out, req, 130);
    }

    void fetch(long req, int maxRows) throws Exception {
        Frame.Out o = new Frame.Out();
        if (rs == null) {
            o.d.writeBoolean(true); o.d.writeInt(0);
            o.send(out, req, 132);
            return;
        }
        ByteArrayOutputStream ignored = null;
        Frame.Out vals = new Frame.Out();
        int count = 0;
        boolean done = false;
        for (int row = 0; row < maxRows; row++) {
            if (!rs.next()) { done = true; break; }
            for (int i = 0; i < types.length; i++) {
                Values.write(rs, i + 1, types[i], typeNames[i], lobLimit, vals);
                count++;
            }
        }
        o.d.writeBoolean(done);
        o.d.writeInt(count);
        o.d.write(vals.buf.toByteArray());
        if (done) endExec();
        o.send(out, req, 132);
    }

    void endExec() {
        try { if (rs != null) rs.close(); } catch (SQLException ignored) { }
        try { if (current != null) current.close(); } catch (SQLException ignored) { }
        rs = null;
        current = null;
    }

    void setLobLimit(long bytes) { lobLimit = bytes; }

    void cancel() throws SQLException {
        Statement s = current;
        if (s != null) s.cancel();
    }

    void close() throws SQLException {
        endExec();
        conn.close();
        worker.shutdown();
    }
}
```

```java
package dblens.bridge;

import java.io.*;
import java.net.*;
import java.nio.file.*;
import java.sql.*;
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;

/** 读帧线程：取消和分发在这里，耗时操作都到各连接自己的线程。stdin 关闭即退出。 */
public final class Main {
    private static final Map<Long, Session> sessions = new ConcurrentHashMap<>();
    private static final Map<String, java.sql.Driver> drivers = new ConcurrentHashMap<>();
    private static final AtomicLong nextId = new AtomicLong(1);
    private static final ExecutorService connector = Executors.newCachedThreadPool(r -> {
        Thread t = new Thread(r, "connect");
        t.setDaemon(true);
        return t;
    });

    public static void main(String[] args) throws Exception {
        DataInputStream in = new DataInputStream(new BufferedInputStream(System.in));
        DataOutputStream out = new DataOutputStream(new BufferedOutputStream(System.out));
        // 驱动的日志不能混进协议流
        System.setOut(System.err);
        for (Frame f; (f = Frame.read(in)) != null; ) dispatch(f, out);
        System.exit(0);
    }

    private static void dispatch(Frame f, DataOutputStream out) throws IOException {
        if (f.kind == 1) {
            connector.submit(() -> guarded(f, out, () -> connect(f, out)));
            return;
        }
        long conn = f.in.readLong();
        Session s = sessions.get(conn);
        if (s == null) {
            error(out, f.id, new SQLException("connection closed"));
            return;
        }
        if (f.kind == 4) {
            guarded(f, out, () -> { s.cancel(); ok(out, f.id); });
            return;
        }
        s.worker.submit(() -> guarded(f, out, () -> handle(f, s, out)));
    }

    private static void handle(Frame f, Session s, DataOutputStream out) throws Exception {
        switch (f.kind) {
            case 2: s.execute(f.id, f.in); return;
            case 3: s.fetch(f.id, f.in.readInt()); return;
            case 5: s.conn.commit(); break;
            case 6: s.conn.rollback(); break;
            case 7: s.conn.setAutoCommit(f.in.readBoolean()); break;
            case 8: if (!s.conn.isValid(5)) throw new SQLException("connection lost"); break;
            case 9: sessions.remove(s.id); s.close(); break;
            case 10: {
                DatabaseMetaData m = s.conn.getMetaData();
                Frame.Out o = new Frame.Out();
                o.str(m.getDatabaseProductName());
                o.str(m.getDatabaseProductVersion());
                o.send(out, f.id, 134);
                return;
            }
            case 11: s.setLobLimit(f.in.readLong()); break;
            case 12: s.endExec(); break;
            default: throw new IOException("bad request " + f.kind);
        }
        ok(out, f.id);
    }

    private static void connect(Frame f, DataOutputStream out) throws Exception {
        String cls = Frame.str(f.in), url = Frame.str(f.in), user = Frame.str(f.in), pw = Frame.str(f.in);
        String jarDir = Frame.str(f.in);
        int timeout = f.in.readInt();
        java.sql.Driver d = drivers.computeIfAbsent(jarDir + "|" + cls, k -> load(jarDir, cls));
        Properties p = new Properties();
        p.setProperty("user", user);
        p.setProperty("password", pw);
        DriverManager.setLoginTimeout(timeout);
        Connection c = d.connect(url, p);
        long id = nextId.getAndIncrement();
        sessions.put(id, new Session(id, c, out));
        Frame.Out o = new Frame.Out();
        o.d.writeLong(id);
        o.send(out, f.id, 129);
    }

    /** 驱动 jar 用独立的类加载器，这样不同版本的驱动互不影响。 */
    private static java.sql.Driver load(String jarDir, String cls) {
        try (DirectoryStream<Path> jars = Files.newDirectoryStream(Paths.get(jarDir), "*.jar")) {
            List<URL> urls = new ArrayList<>();
            for (Path j : jars) urls.add(j.toUri().toURL());
            ClassLoader cl = new URLClassLoader(urls.toArray(new URL[0]), Main.class.getClassLoader());
            return (java.sql.Driver) Class.forName(cls, true, cl).getDeclaredConstructor().newInstance();
        } catch (Exception e) {
            throw new IllegalStateException("cannot load " + cls + " from " + jarDir + ": " + e, e);
        }
    }

    private interface Body { void run() throws Exception; }

    private static void guarded(Frame f, DataOutputStream out, Body b) {
        try {
            b.run();
        } catch (Throwable t) {
            try { error(out, f.id, t); } catch (IOException e) { System.exit(1); }
        }
    }

    private static void ok(DataOutputStream out, long id) throws IOException {
        new Frame.Out().send(out, id, 128);
    }

    private static void error(DataOutputStream out, long id, Throwable t) throws IOException {
        Frame.Out o = new Frame.Out();
        SQLException s = t instanceof SQLException ? (SQLException) t : null;
        o.d.writeInt(s == null ? 0 : s.getErrorCode());
        o.str(s == null || s.getSQLState() == null ? "" : s.getSQLState());
        o.str(String.valueOf(t.getMessage()));
        o.send(out, id, 133);
    }
}
```

```rust
//! 全应用唯一的 Java 进程：第一次连接时启动，退出后下一次连接重新启动。
//! 主程序退出时 stdin 关闭，Java 端随之退出，不留孤儿进程。

use std::collections::HashMap;
use std::io::{BufReader, BufWriter};
use std::path::PathBuf;
use std::process::{ChildStdin, Command, Stdio};
use std::sync::mpsc::{SyncSender, sync_channel};
use std::sync::{Arc, Mutex};
use std::sync::atomic::{AtomicU64, Ordering};

use dblens_core::{Error, Result, msg};

use crate::frame::{Req, encode_req, read_frame, write_frame};

type Pending = Arc<Mutex<HashMap<u64, SyncSender<(u8, Vec<u8>)>>>>;

pub(crate) struct Bridge {
    stdin: Mutex<BufWriter<ChildStdin>>,
    pending: Pending,
    next: AtomicU64,
}

impl Bridge {
    fn start(java: &PathBuf, jar: &PathBuf) -> Result<Arc<Bridge>> {
        let mut cmd = Command::new(java);
        cmd.args(["-Xss512k", "-XX:+UseSerialGC", "-Dfile.encoding=UTF-8", "-jar"])
            .arg(jar)
            .stdin(Stdio::piped())
            .stdout(Stdio::piped())
            .stderr(Stdio::piped());
        #[cfg(windows)]
        {
            use std::os::windows::process::CommandExt;
            // 桌面版没有控制台，不要弹黑窗
            cmd.creation_flags(0x0800_0000);
        }
        let mut child = cmd
            .spawn()
            .map_err(|e| Error::DriverUnavailable { hint: msg!("jdbc.start_failed", path = java.display(), error = e) })?;
        let stdin = child.stdin.take().expect("已设置 piped");
        let stdout = child.stdout.take().expect("已设置 piped");
        let stderr = child.stderr.take().expect("已设置 piped");
        let pending: Pending = Arc::default();
        let bridge = Arc::new(Bridge { stdin: Mutex::new(BufWriter::new(stdin)), pending: pending.clone(), next: AtomicU64::new(1) });
        std::thread::Builder::new()
            .name("dblens-bridge-log".into())
            .spawn(move || {
                use std::io::BufRead;
                for line in BufReader::new(stderr).lines().map_while(std::result::Result::ok) {
                    tracing::warn!(target: "bridge", "{line}");
                }
            })
            .map_err(|e| Error::internal(msg!("driver.worker_spawn_failed", error = e)))?;
        std::thread::Builder::new()
            .name("dblens-bridge-read".into())
            .spawn(move || {
                let mut r = BufReader::new(stdout);
                while let Ok((id, kind, body)) = read_frame(&mut r) {
                    if let Some(tx) = pending.lock().expect("pending 锁").remove(&id) {
                        let _ = tx.send((kind, body));
                    }
                }
                // 丢弃发送端，所有等待者收到断开
                pending.lock().expect("pending 锁").clear();
                let _ = child.wait();
            })
            .map_err(|e| Error::internal(msg!("driver.worker_spawn_failed", error = e)))?;
        Ok(bridge)
    }

    /// 发一条请求并等响应，返回（类型，内容）。在连接的专用线程上调用。
    pub(crate) fn call(&self, req: &Req) -> Result<(u8, Vec<u8>)> {
        let id = self.next.fetch_add(1, Ordering::Relaxed);
        let frame = encode_req(id, req)?;
        let (tx, rx) = sync_channel(1);
        self.pending.lock().expect("pending 锁").insert(id, tx);
        let sent = {
            let mut w = self.stdin.lock().expect("stdin 锁");
            write_frame(&mut *w, &frame)
        };
        if sent.is_err() {
            self.pending.lock().expect("pending 锁").remove(&id);
            return Err(Error::connect(msg!("jdbc.bridge_exited")));
        }
        rx.recv().map_err(|_| Error::connect(msg!("jdbc.bridge_exited")))
    }

    fn alive(&self) -> bool {
        self.stdin.lock().map(|mut w| { use std::io::Write; w.flush().is_ok() }).unwrap_or(false)
    }
}

static BRIDGE: Mutex<Option<Arc<Bridge>>> = Mutex::new(None);

/// 取得运行中的进程，没有或已退出时启动。
pub(crate) fn bridge(java: &PathBuf, jar: &PathBuf) -> Result<Arc<Bridge>> {
    let mut slot = BRIDGE.lock().map_err(|_| Error::internal(msg!("internal.lock_poisoned", lock = "bridge")))?;
    if let Some(b) = slot.as_ref().filter(|b| b.alive()) {
        return Ok(b.clone());
    }
    let b = Bridge::start(java, jar)?;
    *slot = Some(b.clone());
    Ok(b)
}
```

`alive` 在进程刚退出时 flush 空缓冲区也会成功。为此读线程退出时要把状态置位：给 `Bridge` 加 `dead: AtomicBool`，读线程结束时 `store(true)`，`alive` 改为 `!dead.load()`，并让读线程持有 `Arc<AtomicBool>`，不持有 `Bridge`。

```rust
use std::sync::Arc;

use dblens_core::{Result, Value};
use dblens_driver::blocking::{BlockingConnection, BlockingExec};
use dblens_driver::{CancelHandle, ColumnMeta, ExecEvent, ServerInfo};

use crate::error::{expect, protocol};
use crate::frame::{Column, Req, Resp};
use crate::process::Bridge;

pub(crate) struct JdbcConnection {
    pub(crate) bridge: Arc<Bridge>,
    pub(crate) id: u64,
}

impl JdbcConnection {
    fn simple(&self, req: Req) -> Result<()> {
        let (k, b) = self.bridge.call(&req)?;
        match expect(k, &b, 0)? {
            Resp::Ok => Ok(()),
            _ => Err(protocol()),
        }
    }

    pub(crate) fn cancel_handle(&self) -> CancelHandle {
        let (bridge, id) = (self.bridge.clone(), self.id);
        CancelHandle::new(move || {
            let bridge = bridge.clone();
            async move {
                tokio::task::spawn_blocking(move || {
                    let (k, b) = bridge.call(&Req::Cancel { conn: id })?;
                    expect(k, &b, 0).map(|_| ())
                })
                .await
                .map_err(|e| dblens_core::Error::internal(e.to_string()))?
            }
        })
    }
}

fn meta(c: Column) -> ColumnMeta {
    ColumnMeta { nullable: c.nullable, precision: c.precision, scale: c.scale, ..ColumnMeta::new(c.name, c.type_name) }
}

enum Stage {
    Start(Vec<ColumnMeta>),
    Rows(usize),
    End,
    Affected(u64),
    Done,
}

struct Exec<'a> {
    conn: &'a JdbcConnection,
    stage: Stage,
}

impl BlockingExec for Exec<'_> {
    fn next(&mut self, max_rows: usize) -> Result<Option<ExecEvent>> {
        match std::mem::replace(&mut self.stage, Stage::Done) {
            Stage::Start(columns) => {
                self.stage = Stage::Rows(columns.len());
                Ok(Some(ExecEvent::ResultStart { columns }))
            }
            Stage::Rows(n) => {
                let (k, b) = self.conn.bridge.call(&Req::Fetch { conn: self.conn.id, max_rows: max_rows as u32 })?;
                let Resp::Rows { done, rows } = expect(k, &b, n)? else { return Err(protocol()) };
                self.stage = if done { Stage::End } else { Stage::Rows(n) };
                if rows.is_empty() {
                    self.stage = Stage::Done;
                    return Ok(Some(ExecEvent::ResultEnd));
                }
                Ok(Some(ExecEvent::Rows(rows)))
            }
            Stage::End => Ok(Some(ExecEvent::ResultEnd)),
            Stage::Affected(n) => Ok(Some(ExecEvent::Affected(n))),
            Stage::Done => Ok(None),
        }
    }
}

impl Drop for Exec<'_> {
    fn drop(&mut self) {
        // 提前丢弃时关掉游标，下一条语句才能执行
        if matches!(self.stage, Stage::Start(_) | Stage::Rows(_)) {
            let _ = self.conn.bridge.call(&Req::EndExec { conn: self.conn.id });
        }
    }
}

impl BlockingConnection for JdbcConnection {
    fn execute<'a>(&'a mut self, sql: &'a str, params: &'a [Value]) -> Result<Box<dyn BlockingExec + 'a>> {
        let (k, b) = self.bridge.call(&Req::Execute { conn: self.id, sql: sql.into(), params: params.to_vec() })?;
        let stage = match expect(k, &b, 0)? {
            Resp::Result(cols) => Stage::Start(cols.into_iter().map(meta).collect()),
            Resp::Affected(n) => Stage::Affected(n),
            _ => return Err(protocol()),
        };
        Ok(Box::new(Exec { conn: self, stage }))
    }

    fn set_lob_limit(&mut self, bytes: usize) {
        let _ = self.simple(Req::SetLobLimit { conn: self.id, bytes: bytes as u64 });
    }

    fn set_autocommit(&mut self, on: bool) -> Result<()> {
        self.simple(Req::SetAutocommit { conn: self.id, on })
    }

    fn commit(&mut self) -> Result<()> {
        self.simple(Req::Commit { conn: self.id })
    }

    fn rollback(&mut self) -> Result<()> {
        self.simple(Req::Rollback { conn: self.id })
    }

    fn ping(&mut self) -> Result<()> {
        self.simple(Req::Ping { conn: self.id })
    }

    fn server_info(&mut self) -> Result<ServerInfo> {
        let (k, b) = self.bridge.call(&Req::ServerInfo { conn: self.id })?;
        match expect(k, &b, 0)? {
            Resp::ServerInfo { product, version } => Ok(ServerInfo { product, version }),
            _ => Err(protocol()),
        }
    }

    fn close(self: Box<Self>) -> Result<()> {
        self.simple(Req::Close { conn: self.id })
    }
}
```

```rust
/// 这些值拼进 URL，分隔符会变成新的设置项，所以只收普通名字。
fn plain(v: &str, field: &str) -> Result<String> {
    if v.is_empty() || !v.chars().all(|c| c.is_alphanumeric() || "._-".contains(c)) {
        return Err(Error::invalid(msg!("gbase.bad_option", field = field, value = v)));
    }
    Ok(v.to_string())
}

pub(crate) fn jdbc_url(p: &ConnectParams) -> Result<String> {
    let server = p.options.get("server_name").map(String::as_str).unwrap_or("");
    if server.is_empty() {
        return Err(Error::invalid(msg!("gbase.server_name_required")));
    }
    let server = plain(server, "server_name")?;
    let locale = plain(p.options.get("db_locale").map_or("zh_CN.utf8", String::as_str), "db_locale")?;
    let db = p.database.as_deref().unwrap_or("sysmaster");
    let db = plain(db, "database")?;
    Ok(format!(
        "jdbc:gbasedbt-sqli://{}:{}/{db}:GBASEDBTSERVER={server};CLIENT_LOCALE=zh_CN.utf8;DB_LOCALE={locale};SQLMODE=gbase;DELIMIDENT=y",
        p.host, p.port
    ))
}

pub(crate) fn login_error(code: i32, message: String) -> Error {
    match code {
        -951 | -952 => Error::Auth { message: Msg::raw(format!("[{code}] {message}")) },
        _ => Error::connect(format!("[{code}] {message}")),
    }
}

/// 程序自带的目录：`<程序目录>/clients`。Linux 的 deb 和 macOS 的 app 由打包任务放到同样的相对位置。
fn bundled() -> Option<PathBuf> {
    Some(std::env::current_exe().ok()?.parent()?.join("clients"))
}

struct Parts {
    java: PathBuf,
    jar: PathBuf,
    jdbc_dir: PathBuf,
}

fn locate(p: &ConnectParams) -> Result<Parts> {
    let base = bundled();
    let java_name = if cfg!(windows) { "java.exe" } else { "java" };
    let env_path = |k: &str| std::env::var_os(k).map(PathBuf::from);
    let java = env_path("DBLENS_JAVA")
        .or_else(|| base.as_ref().map(|b| b.join("jre/bin").join(java_name)))
        .filter(|f| f.is_file())
        .ok_or_else(|| Error::DriverUnavailable { hint: msg!("jdbc.runtime_missing") })?;
    let jar = env_path("DBLENS_BRIDGE_JAR")
        .or_else(|| base.as_ref().map(|b| b.join("bridge/dblens-bridge.jar")))
        .filter(|f| f.is_file())
        .ok_or_else(|| Error::DriverUnavailable { hint: msg!("jdbc.runtime_missing") })?;
    // 指定目录后只查这一处，和原生客户端的规则相同
    let jdbc_dir = match p.options.get("jdbc_dir").filter(|d| !d.is_empty()) {
        Some(d) if Path::new(d).is_absolute() => PathBuf::from(d),
        Some(d) => return Err(Error::DriverUnavailable { hint: msg!("native.dir_not_absolute", lib = "JDBC", dir = d) }),
        None => base.map(|b| b.join("jdbc")).unwrap_or_default(),
    };
    if !jdbc_dir.join(JDBC_JAR).is_file() {
        return Err(Error::DriverUnavailable { hint: msg!("gbase.jar_missing", dir = jdbc_dir.display()) });
    }
    Ok(Parts { java, jar, jdbc_dir })
}

fn connect_blocking(p: &ConnectParams) -> Result<JdbcConnection> {
    p.reject_tls("GBase 8s")?;
    let url = jdbc_url(p)?;
    let parts = locate(p)?;
    let bridge = bridge(&parts.java, &parts.jar)?;
    let (k, b) = bridge.call(&Req::Connect {
        driver_class: DRIVER_CLASS.into(),
        url,
        user: p.user.clone(),
        password: p.password.clone(),
        jar_dir: parts.jdbc_dir.display().to_string(),
        timeout_secs: p.connect_timeout.as_secs() as u32,
    })?;
    match expect(k, &b, 0) {
        Ok(Resp::Connected(id)) => Ok(JdbcConnection { bridge, id }),
        Ok(_) => Err(protocol()),
        Err(Error::Sql { code, message, .. }) => Err(login_error(code.parse().unwrap_or(0), message)),
        Err(e) => Err(e),
    }
}

pub struct GbaseDriver;

#[async_trait]
impl Driver for GbaseDriver {

    }
```

```rust
//! `syscolumns` 的 coltype、collength 解码。

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Decoded {
    pub type_name: String,
    pub nullable: bool,
    pub length: Option<i64>,
    pub precision: Option<i64>,
    pub scale: Option<i64>,
}

const UNITS: [&str; 16] = [
    "YEAR", "", "MONTH", "", "DAY", "", "HOUR", "", "MINUTE", "", "SECOND", "FRACTION(1)", "FRACTION(2)",
    "FRACTION(3)", "FRACTION(4)", "FRACTION(5)",
];

fn qualifier(len: i64) -> String {
    let (start, end) = (((len >> 4) & 0xf) as usize, (len & 0xf) as usize);
    let first = if UNITS[start].is_empty() { "FRACTION" } else { UNITS[start] };
    format!("{first} TO {}", UNITS[end])
}

pub fn decode(coltype: i64, collength: i64, extended: Option<&str>) -> Decoded {
    let nullable = coltype & 256 == 0;
    let base = coltype & 0xff;
    let mut d = Decoded { type_name: String::new(), nullable, length: None, precision: None, scale: None };
    if let Some(name) = extended.filter(|n| !n.is_empty()) {
        d.type_name = name.to_ascii_uppercase();
        return d;
    }
    let sized = |n: &str, l: i64| format!("{n}({l})");
    d.type_name = match base {
        0 | 15 => {
            d.length = Some(collength);
            sized(if base == 0 { "CHAR" } else { "NCHAR" }, collength)
        }
        1 => "SMALLINT".into(),
        2 => "INTEGER".into(),
        3 => "FLOAT".into(),
        4 => "SMALLFLOAT".into(),
        5 | 8 => {
            let (p, s) = (collength >> 8, collength & 0xff);
            let name = if base == 5 { "DECIMAL" } else { "MONEY" };
            d.precision = Some(p);
            if s == 255 {
                sized(name, p)
            } else {
                d.scale = Some(s);
                format!("{name}({p},{s})")
            }
        }
        6 => "SERIAL".into(),
        7 => "DATE".into(),
        10 => format!("DATETIME {}", qualifier(collength)),
        11 => "BYTE".into(),
        12 => "TEXT".into(),
        13 | 16 => {
            let (max, min) = (collength & 0xff, collength >> 8);
            let name = if base == 13 { "VARCHAR" } else { "NVARCHAR" };
            d.length = Some(max);
            if min > 0 { format!("{name}({max},{min})") } else { sized(name, max) }
        }
        14 => format!("INTERVAL {}", qualifier(collength)),
        17 => "INT8".into(),
        18 => "SERIAL8".into(),
        41 => "BLOB".into(),
        43 => {
            d.length = Some(collength);
            sized("LVARCHAR", collength)
        }
        45 => "BOOLEAN".into(),
        52 => "BIGINT".into(),
        53 => "BIGSERIAL".into(),
        other => format!("TYPE{other}"),
    };
    d
}
```

```sql
ORDER BY l.owner

-- [storage]
SELECT TRIM(d.name) AS name, SUM(c.chksize * c.pagesize) AS total_bytes,
       SUM(c.nfree * c.pagesize) AS free_bytes
FROM sysmaster:sysdbspaces d
JOIN sysmaster:syschunks c ON c.dbsnum = d.dbsnum
GROUP BY d.name
ORDER BY 1

-- [largest_tables]
SELECT FIRST 50 TRIM(n.dbsname) AS database, TRIM(n.owner) AS schema_name, TRIM(n.tabname) AS table_name,
       p.nptotal * p.pagesize AS bytes, p.nrows AS row_count
FROM sysmaster:sysptnhdr p
JOIN sysmaster:systabnames n ON n.partnum = p.partnum
WHERE n.dbsname NOT IN ('sysmaster', 'sysadmin', 'sysuser', 'sysutils')
ORDER BY p.nptotal * p.pagesize DESC
```

列别名对照 `sql/ops/sqlserver.sql` 和 `ops.rs` 的读取约定调整；`ops.rs` 加 `const INFORMIX` 并接入 `Family::Informix`。`policy.rs:105` 那类 SQL Server 专属扫描不用动。

```js
// 生成 clients-staging/：桥接 jar、jlink 精简 JRE，以及清单里列出的 JDBC 驱动（来自 DBLENS_CLIENTS_DIR）。
// 第三方文件不进仓库。清单里的文件缺失时失败，不产出残缺的包。
import { execFileSync } from 'node:child_process'
import { copyFileSync, existsSync, mkdirSync, readFileSync, rmSync } from 'node:fs'
import { createHash } from 'node:crypto'
import { join } from 'node:path'

const root = new URL('..', import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, '$1')
const manifest = JSON.parse(readFileSync(join(root, 'scripts/clients.manifest.json'), 'utf8'))
const stage = join(root, 'clients-staging')
const bridge = join(root, 'bridge/build/dblens-bridge.jar')
if (!existsSync(bridge)) throw new Error('先运行 node scripts/build-bridge.mjs')
rmSync(stage, { recursive: true, force: true })
mkdirSync(join(stage, 'bridge'), { recursive: true })
mkdirSync(join(stage, 'jdbc'), { recursive: true })
copyFileSync(bridge, join(stage, 'bridge/dblens-bridge.jar'))
execFileSync('jlink', [
  '--add-modules', manifest.modules.join(','),
  '--strip-debug', '--no-header-files', '--no-man-pages', '--compress', 'zip-6',
  '--output', join(stage, 'jre'),
], { stdio: 'inherit' })
for (const j of manifest.jdbc) {
  const dir = process.env.DBLENS_CLIENTS_DIR
  if (!dir) throw new Error('清单里有 JDBC 驱动，需要设置 DBLENS_CLIENTS_DIR')
  const from = join(dir, j.file)
  const sha = createHash('sha256').update(readFileSync(from)).digest('hex')
  if (sha !== j.sha256) throw new Error(`${j.file} 的校验和不符`)
  copyFileSync(from, join(stage, 'jdbc', j.file))
}
```
