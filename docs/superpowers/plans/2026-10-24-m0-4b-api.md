# M0-4b 接口与服务器 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 本计划分三部分。
- PG 和 MySQL 系驱动支持 TLS 连接。
- 新建 `dblens-api`：REST 接口和会话的 WebSocket 执行协议，带令牌与 Origin 校验。
- 新建 `dblens-server`：浏览器模式的服务入口。

**架构：**
- `dblens-api` 用 axum 实现，只调用 M0-4a 的 `Service`，桌面模式和浏览器模式共用。
- REST 处理函数都很薄：解析参数，调用 `Service`，把 `dblens_core::Error` 映射成 HTTP 状态码，响应体是错误的 JSON。
- WebSocket 把会话的拉取式执行变成背压：每发出装满的一批行，就等客户端的 `fetch_more`。
- `dblens-server` 负责：解析命令行参数，打开数据目录，生成本次运行的访问令牌并打印出来，然后提供服务。

**技术栈：** axum 0.8.9（启用 ws）、rustls 0.23.46（aws-lc-rs，MySQL 驱动已经在用）、tokio-postgres-rustls 0.14、webpki-roots 1.0.11、tracing-subscriber 0.3.23。测试另用 tokio-tungstenite 0.30、tower 0.5（util）、http-body-util 0.1.5。

**Spec：** `docs/superpowers/specs/2026-10-22-dblens-design.md`。重点是 4.1 通信方式、4.2 Cargo 工作区、8 错误处理、9 测试（`dblens-api` 用真实的 MySQL 和 PG 做集成测试）。

## 设计决定

| 问题 | 决定 | 理由 |
|---|---|---|
| TLS 选项 | 连接选项 `tls`：`disable`（默认）、`require`（加密，不校验证书）、`verify`（校验证书链和主机名）；`tls_ca` 指定额外信任的 CA 证书（PEM） | 内网数据库多用自签名证书，所以需要 `require`；默认不加密，与以前的行为一致 |
| Oracle、达梦的 TLS | 暂不支持；配置了 `tls` 时连接直接报 `Invalid` | 测试库没有配置 TCPS 和达梦 SSL，无法验证。报错是为了不让用户以为连接已经加密 |
| PG 的 TLS | 用 rustls（aws-lc-rs，与 MySQL 驱动共用）；`require` 用一个只校验握手签名、不校验证书的校验器；取消请求也用同一个连接器 | 服务器只接受加密连接时，明文的取消请求会失败 |
| HTTP 状态码 | 400 Invalid、404 NotFound、409 Busy/Cancelled、423 Locked、403 Denied、422 数据库一侧的错误（连接、认证、SQL、超时、驱动不可用）、500 Internal、401 缺少或错误的令牌 | 前端按状态码分大类，细节看响应体中的 `kind`。数据库认证失败用 422，不用 401，以免和访问令牌失效混淆 |
| 令牌 | `Authorization: Bearer`，或查询参数 `token=`（浏览器的 WebSocket 不能设请求头）；比较时耗时与内容无关 | — |
| Origin | 带 Origin 头的请求必须同源（Origin 的主机部分与 Host 一致），或在 `allowed_origins` 中；不带 Origin 的请求只看令牌 | 防止其他网页借用户的浏览器调用本服务 |
| WebSocket 背压 | 发出装满 `max_rows` 的 `rows` 后等待 `fetch_more`；不满一批时接着发后面的事件 | 测试中发现：如果每批都等，最后一批之后双方会互相等待，因为客户端不知道那已是最后一批 |
| 语句位置 | WebSocket 事件中的 `start`/`end` 换算成 UTF-16 偏移 | 与 Monaco 一致，中文和 emoji 的位置才能对上（M0-3a 遗留事项） |
| 连接断开 | WebSocket 断开时取消正在执行的语句，取完剩余事件，让会话回到空闲 | M0-2 遗留事项：丢弃执行流时要主动取消 |
| 假驱动 | 服务层的 `fake` 模块在 feature `testing` 下公开，供 `dblens-api` 的测试使用 | 接口测试不依赖真实数据库 |

```rust
/// 连接的加密方式，来自连接选项 `tls`：
/// - `disable`（默认）：不加密；
/// - `require`：加密，但不校验服务器证书（适合自签名证书的内网库）；
/// - `verify`：加密并校验证书链和主机名；可用选项 `tls_ca` 指定额外信任的 CA 证书文件（PEM）。
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum TlsMode {
    Disable,
    Require,
    Verify { ca_file: Option<PathBuf> },
}

impl ConnectParams {
    pub fn tls_mode(&self) -> Result<TlsMode> {
        let ca_file = self.options.get("tls_ca").filter(|v| !v.is_empty()).map(PathBuf::from);
        match self.options.get("tls").map(|v| v.trim().to_ascii_lowercase()).as_deref() {
            None | Some("" | "disable" | "off" | "false") => Ok(TlsMode::Disable),
            Some("require") => Ok(TlsMode::Require),
            Some("verify") => Ok(TlsMode::Verify { ca_file }),
            Some(other) => Err(Error::invalid(format!("tls 选项只能是 disable、require 或 verify：{other}"))),
        }
    }

    /// 不支持 TLS 的驱动调用：要求了加密时报错，而不是悄悄用明文连接。
    pub fn reject_tls(&self, driver: &str) -> Result<()> {
        match self.tls_mode()? {
            TlsMode::Disable => Ok(()),
            _ => Err(Error::invalid(format!("{driver} 驱动暂不支持 TLS，请去掉连接选项 tls"))),
        }
    }
}
```

`lib.rs` 的导出改为：`pub use params::{Capabilities, ConnectParams, DriverId, ServerInfo, TlsMode};`。

Oracle 的 `connect` 中，`let p = p.clone();` 之前加一行 `p.reject_tls("Oracle")?;`。
达梦的 `connect_blocking` 第一行加 `p.reject_tls("达梦")?;`。

//! TLS 连接器（rustls）。`require` 只加密不校验证书；`verify` 用内置的公共根证书和 `tls_ca` 指定的证书校验。

use std::sync::Arc;

use dblens_core::{Error, Result};
use dblens_driver::TlsMode;
use rustls::client::danger::{HandshakeSignatureValid, ServerCertVerified, ServerCertVerifier};
use rustls::crypto::WebPkiSupportedAlgorithms;
use rustls::pki_types::pem::PemObject;
use rustls::pki_types::{CertificateDer, ServerName, UnixTime};
use rustls::{ClientConfig, DigitallySignedStruct, RootCertStore, SignatureScheme};
use tokio_postgres_rustls::MakeRustlsConnect;

/// 接受任何证书的校验器，只用于 `tls=require`：仍然校验握手签名，只是不校验证书链和主机名。
#[derive(Debug)]
struct AcceptAnyCert(WebPkiSupportedAlgorithms);

impl ServerCertVerifier for AcceptAnyCert {
    fn verify_server_cert(
        &self,
        _end_entity: &CertificateDer<'_>,
        _intermediates: &[CertificateDer<'_>],
        _server_name: &ServerName<'_>,
        _ocsp: &[u8],
        _now: UnixTime,
    ) -> std::result::Result<ServerCertVerified, rustls::Error> {
        Ok(ServerCertVerified::assertion())
    }

    fn verify_tls12_signature(
        &self,
        message: &[u8],
        cert: &CertificateDer<'_>,
        dss: &DigitallySignedStruct,
    ) -> std::result::Result<HandshakeSignatureValid, rustls::Error> {
        rustls::crypto::verify_tls12_signature(message, cert, dss, &self.0)
    }

    fn verify_tls13_signature(
        &self,
        message: &[u8],
        cert: &CertificateDer<'_>,
        dss: &DigitallySignedStruct,
    ) -> std::result::Result<HandshakeSignatureValid, rustls::Error> {
        rustls::crypto::verify_tls13_signature(message, cert, dss, &self.0)
    }

    fn supported_verify_schemes(&self) -> Vec<SignatureScheme> {
        self.0.supported_schemes()
    }
}

fn tls_err(e: impl std::fmt::Display) -> Error {
    Error::connect(format!("TLS 配置错误：{e}"))
}

/// 按 TLS 方式生成连接器；`disable` 时返回 None。
pub(crate) fn connector(mode: &TlsMode) -> Result<Option<MakeRustlsConnect>> {
    let provider = Arc::new(rustls::crypto::aws_lc_rs::default_provider());
    let builder = ClientConfig::builder_with_provider(provider.clone())
        .with_safe_default_protocol_versions()
        .map_err(tls_err)?;
    let config = match mode {
        TlsMode::Disable => return Ok(None),
        TlsMode::Require => builder
            .dangerous()
            .with_custom_certificate_verifier(Arc::new(AcceptAnyCert(
                provider.signature_verification_algorithms,
            )))
            .with_no_client_auth(),
        TlsMode::Verify { ca_file } => {
            let mut roots = RootCertStore::empty();
            roots.extend(webpki_roots::TLS_SERVER_ROOTS.iter().cloned());
            if let Some(path) = ca_file {
                let certs = CertificateDer::pem_file_iter(path)
                    .map_err(|e| Error::invalid(format!("无法读取 CA 证书文件 {}：{e}", path.display())))?;
                for cert in certs {
                    let cert = cert.map_err(|e| {
                        Error::invalid(format!("CA 证书文件 {} 格式错误：{e}", path.display()))
                    })?;
                    roots.add(cert).map_err(tls_err)?;
                }
            }
            builder.with_root_certificates(roots).with_no_client_auth()
        }
    };
    Ok(Some(MakeRustlsConnect::new(config)))
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn builds_connectors() {
        assert!(connector(&TlsMode::Disable).unwrap().is_none());
        assert!(connector(&TlsMode::Require).unwrap().is_some());
        assert!(connector(&TlsMode::Verify { ca_file: None }).unwrap().is_some());
        let missing = TlsMode::Verify { ca_file: Some("no/such/ca.pem".into()) };
        assert!(matches!(connector(&missing), Err(Error::Invalid { .. })));
    }
}

//! PostgreSQL 系驱动（PostgreSQL，以及兼容 PG 协议的人大金仓、openGauss、瀚高等）。

mod conn;
mod error;
mod exec;
mod tls;
mod types;

use async_trait::async_trait;
use dblens_core::Result;
use dblens_driver::{Capabilities, ConnectParams, Connection, Driver, DriverId};
use futures::StreamExt;
use tokio::io::{AsyncRead, AsyncWrite};
use tokio::sync::mpsc::{self, UnboundedReceiver};
use tokio::task::JoinHandle;
use tokio_postgres::config::SslMode;
use tokio_postgres::{AsyncMessage, NoTls};

pub use conn::PgConnection;

use crate::error::map_err;

pub struct PgDriver;

/// 驱动连接任务，同时把服务器发来的 notice 转发给执行流。加密与否时连接的类型不同，所以写成泛型。
fn spawn_connection<S, T>(
    mut connection: tokio_postgres::Connection<S, T>,
) -> (UnboundedReceiver<String>, JoinHandle<()>)
where
    S: AsyncRead + AsyncWrite + Unpin + Send + 'static,
    T: AsyncRead + AsyncWrite + Unpin + Send + 'static,
{
    let (tx, notices) = mpsc::unbounded_channel();
    let conn_task = tokio::spawn(async move {
        let mut messages = futures::stream::poll_fn(move |cx| connection.poll_message(cx));
        while let Some(message) = messages.next().await {
            match message {
                Ok(AsyncMessage::Notice(n)) => {
                    let _ = tx.send(format!("{}: {}", n.severity(), n.message()));
                }
                Ok(_) => {}
                Err(_) => break,
            }
        }
    });
    (notices, conn_task)
}

#[async_trait]
impl Driver for PgDriver {
    fn id(&self) -> DriverId {
        DriverId::Postgres
    }

    fn capabilities(&self) -> Capabilities {
        Capabilities {
            catalogs: true,
            schemas: true,
            transactional_ddl: true,
            cancel: true,
            explain: true,
            multiple_result_sets: false,
        }
    }

    async fn connect(&self, p: &ConnectParams) -> Result<Box<dyn Connection>> {
        let mut cfg = tokio_postgres::Config::new();
        cfg.host(&p.host)
            .port(p.port)
            .user(&p.user)
            .password(&p.password)
            .dbname(p.database.as_deref().unwrap_or("postgres"))
            .connect_timeout(p.connect_timeout)
            .application_name("DBLens");
        let tls = tls::connector(&p.tls_mode()?)?;

//! 错误到 HTTP 响应的映射：响应体就是 `dblens_core::Error` 的 JSON（`{"kind": …, …}`），前端按 `kind` 处理。

use axum::Json;
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use dblens_core::Error;

/// 处理函数的错误类型。
#[derive(Debug)]
pub struct ApiError(pub Error);

impl From<Error> for ApiError {
    fn from(e: Error) -> Self {
        Self(e)
    }
}

pub type ApiResult<T> = std::result::Result<T, ApiError>;

/// 状态码只用来区分大类，细节看响应体的 `kind`：
/// - 400 输入不合法；404 对象不存在；409 会话正忙或已取消；423 密码库已锁定；403 被执行策略拒绝；
/// - 422 数据库一侧的问题（连接、认证、SQL 错误、超时、驱动不可用）；500 程序内部错误。
pub fn status_of(e: &Error) -> StatusCode {
    match e {
        Error::Invalid { .. } => StatusCode::BAD_REQUEST,
        Error::NotFound { .. } => StatusCode::NOT_FOUND,
        Error::Busy { .. } | Error::Cancelled => StatusCode::CONFLICT,
        Error::Locked => StatusCode::LOCKED,
        Error::Denied { .. } => StatusCode::FORBIDDEN,
        Error::Connect { .. }
        | Error::Auth { .. }
        | Error::Sql { .. }
        | Error::Timeout
        | Error::DriverUnavailable { .. } => StatusCode::UNPROCESSABLE_ENTITY,
        Error::Internal { .. } => StatusCode::INTERNAL_SERVER_ERROR,
    }
}

impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let status = status_of(&self.0);
        if status == StatusCode::INTERNAL_SERVER_ERROR {
            tracing::error!("{}", self.0);
        }
        (status, Json(self.0)).into_response()
    }
}

//! 令牌与 Origin 校验（设计文档 4.1 节）。
//!
//! - 每个请求都要带令牌：`Authorization: Bearer <令牌>`；浏览器的 WebSocket 不能设置请求头，
//!   所以也接受查询参数 `token=<令牌>`。
//! - 带 `Origin` 头的请求（即浏览器发出的请求），Origin 必须与服务同源，或在允许列表中，防止其他网页借用户的浏览器访问本服务。
//!   不带 Origin 的请求（命令行工具等）只校验令牌。

use axum::extract::{Request, State};
use axum::http::{HeaderMap, header};
use axum::middleware::Next;
use axum::response::{IntoResponse, Response};
use dblens_core::Error;

use crate::AppState;
use crate::error::ApiError;

/// 逐字节比较且耗时与内容无关，避免按响应时间猜出令牌。
fn same_token(a: &str, b: &str) -> bool {
    a.len() == b.len() && a.bytes().zip(b.bytes()).fold(0u8, |acc, (x, y)| acc | (x ^ y)) == 0
}

fn token_from(headers: &HeaderMap, query: Option<&str>) -> Option<String> {
    if let Some(v) = headers.get(header::AUTHORIZATION).and_then(|v| v.to_str().ok())
        && let Some(t) = v.strip_prefix("Bearer ")
    {
        return Some(t.trim().to_string());
    }
    query?.split('&').find_map(|kv| kv.strip_prefix("token=")).map(str::to_string)
}

fn origin_allowed(headers: &HeaderMap, allowed: &[String]) -> bool {
    let Some(origin) = headers.get(header::ORIGIN).and_then(|v| v.to_str().ok()) else { return true };
    if allowed.iter().any(|a| a == origin) {
        return true;
    }
    // 同源：Origin 的主机部分与 Host 头一致
    let host = headers.get(header::HOST).and_then(|v| v.to_str().ok()).unwrap_or("");
    let origin_host = origin.split_once("://").map_or("", |(_, rest)| rest);
    !host.is_empty() && origin_host == host
}

pub async fn guard(State(state): State<AppState>, request: Request, next: Next) -> Response {
    let headers = request.headers();
    if !origin_allowed(headers, &state.config.allowed_origins) {
        return ApiError(Error::Denied { reason: "不允许的来源（Origin）".into() }).into_response();
    }
    match token_from(headers, request.uri().query()) {
        Some(t) if same_token(&t, &state.config.token) => next.run(request).await,
        _ => (
            axum::http::StatusCode::UNAUTHORIZED,
            axum::Json(Error::Auth { message: "缺少或错误的访问令牌".into() }),
        )
            .into_response(),
    }
}

#[cfg(test)]
mod tests {
    use axum::http::HeaderValue;

    use super::*;

    #[test]
    fn token_from_header_or_query() {
        let mut h = HeaderMap::new();
        assert_eq!(token_from(&h, Some("a=1&token=abc")), Some("abc".into()));
        h.insert(header::AUTHORIZATION, HeaderValue::from_static("Bearer xyz"));
        assert_eq!(token_from(&h, Some("token=abc")), Some("xyz".into()), "请求头优先");
        assert_eq!(token_from(&HeaderMap::new(), None), None);

type Ws = tokio_tungstenite::WebSocketStream<tokio_tungstenite::MaybeTlsStream<tokio::net::TcpStream>>;

/// 启动真实的服务，打开一个会话并连上它的 WebSocket。
async fn ws_session() -> (Ws, Arc<Service>, u64) {
    let (app, service) = app();
    let profile =
        service.create_profile(serde_json::from_value(profile_json("p")).unwrap(), Some("pw")).unwrap();
    let mut input = profile.input.clone();
    input.environment = dblens_service::Environment::Dev;
    service.update_profile(&profile.id, input).await.unwrap();
    let sid = service.open_session(&profile.id).await.unwrap().id;
    let listener = tokio::net::TcpListener::bind("127.0.0.1:0").await.unwrap();
    let addr = listener.local_addr().unwrap();
    tokio::spawn(async move { dblens_api::serve(listener, app).await.unwrap() });
    let url = format!("ws://{addr}/api/sessions/{sid}/ws?token={TOKEN}");
    let (ws, _) = tokio_tungstenite::connect_async(url).await.unwrap();
    (ws, service, sid)
}

async fn send(ws: &mut Ws, v: Value) {
    ws.send(Message::Text(v.to_string().into())).await.unwrap();
}

async fn recv(ws: &mut Ws) -> Value {
    loop {
        let msg = tokio::time::timeout(Duration::from_secs(5), ws.next())
            .await
            .expect("5 秒内没有消息")
            .unwrap()
            .unwrap();
        if let Message::Text(t) = msg {
            return serde_json::from_str(&t).unwrap();
        }
    }
}

async fn quiet(ws: &mut Ws) -> bool {
    tokio::time::timeout(Duration::from_millis(300), ws.next()).await.is_err()
}

    assert_eq!(recv(&mut ws).await["type"], "statement_start");

//! 会话的 WebSocket 执行协议：`GET /api/sessions/{id}/ws`。
//!
//! 客户端发送（JSON，按 `type` 区分）：
//! - `{"type":"exec","sql":"…","confirmed":false,"max_rows":500}`：执行一段 SQL（可以多条语句）；
//! - `{"type":"fetch_more","max_rows":500}`：取下一批行；
//! - `{"type":"cancel"}`：取消正在执行的语句。
//!
//! 服务端发送 `SessionEvent`（`statement_start`、`result_start`、`rows`、`result_end`、`affected`、`message`、
//! `statement_end`、`confirm_required`、`failed`、`done`），协议层面的错误发 `{"type":"error","error":{…}}`。
//! 每发出一个装满 `max_rows` 行的 `rows` 事件就停下，等客户端 `fetch_more` 后再取下一批（背压）；
//! 不满一批说明结果集已取完，接着发后面的事件。其他事件不受限制。
//! 事件中的 `start`/`end` 是 UTF-16 代码单元偏移（与 Monaco 编辑器一致），不是字节偏移。
//! 连接断开时，正在执行的语句会被取消，剩余事件被丢弃，会话恢复空闲。

use std::sync::Arc;

use axum::extract::ws::{Message, WebSocket, WebSocketUpgrade};
use axum::extract::{Path, State};
use axum::response::Response;
use dblens_core::Error;
use dblens_service::{Service, SessionEvent, SessionId};
use futures::{SinkExt, StreamExt};
use serde::Deserialize;
use tokio::sync::mpsc;

use crate::AppState;
use crate::error::ApiResult;

/// 未指定时每批最多的行数。
pub const DEFAULT_MAX_ROWS: usize = 500;

fn default_rows() -> usize {
    DEFAULT_MAX_ROWS
}

#[derive(Debug, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
enum ClientMsg {
    Exec {
        sql: String,
        #[serde(default)]
        confirmed: bool,
        #[serde(default = "default_rows")]
        max_rows: usize,
    },
    FetchMore {
        #[serde(default = "default_rows")]
        max_rows: usize,
    },
    Cancel,
}

/// 字节偏移换算成 UTF-16 偏移。
pub fn utf16_offset(text: &str, byte: usize) -> usize {
    text.get(..byte.min(text.len())).map_or(0, |s| s.encode_utf16().count())
}

/// 把事件中的字节偏移换成 UTF-16 偏移后序列化。
fn encode(event: SessionEvent, sql: &str) -> String {
    let event = match event {
        SessionEvent::StatementStart { index, start, end, info } => SessionEvent::StatementStart {
            index,
            start: utf16_offset(sql, start),
            end: utf16_offset(sql, end),
            info,
        },
        SessionEvent::ConfirmRequired { index, start, reason } => {
            SessionEvent::ConfirmRequired { index, start: utf16_offset(sql, start), reason }
        }
        other => other,
    };
    serde_json::to_string(&event).unwrap_or_else(|e| error_message(&Error::internal(e.to_string())))
}

fn error_message(e: &Error) -> String {
    serde_json::json!({"type": "error", "error": e}).to_string()
}

pub async fn upgrade(
    State(s): State<AppState>,
    Path(id): Path<SessionId>,
    ws: WebSocketUpgrade,
) -> ApiResult<Response> {
    s.service.sessions.info(id)?;
    let service = s.service.clone();
    Ok(ws.on_upgrade(move |socket| run(socket, service, id)))
}

/// 从会话取事件发给客户端；每发出装满的一批行就等一次 `fetch_more`。
async fn pump(
    service: Arc<Service>,
    id: SessionId,
    sql: String,
    mut max_rows: usize,
    out: mpsc::Sender<String>,
    mut credit: mpsc::Receiver<usize>,
) {
    loop {
        match service.sessions.next(id, max_rows).await {
            Ok(Some(event)) => {
                // 装满一批才等 fetch_more：不满说明结果集已经取完，接着发后面的事件
                let full = matches!(&event, SessionEvent::Rows { rows } if rows.len() >= max_rows);
                let done = event == SessionEvent::Done;
                let _ = out.send(encode(event, &sql)).await;
                if done {
                    return;
                }
                if full {
                    match credit.recv().await {
                        Some(n) => max_rows = n.max(1),
                        None => break,
                    }
                }
            }
            Ok(None) => return,
            Err(e) => {
                let _ = out.send(error_message(&e)).await;
                return;
            }
        }
    }
    // 客户端已断开：取消并取完剩余事件，让会话回到空闲
    let _ = service.sessions.cancel(id).await;
    while let Ok(Some(event)) = service.sessions.next(id, 1000).await {
        if event == SessionEvent::Done {
            break;
        }
    }
}

async fn run(socket: WebSocket, service: Arc<Service>, id: SessionId) {
    let (mut sink, mut stream) = socket.split();
    let (out, mut outbox) = mpsc::channel::<String>(64);
    let writer = tokio::spawn(async move {
        while let Some(text) = outbox.recv().await {
            if sink.send(Message::Text(text.into())).await.is_err() {
                break;
            }
        }
    });
    let mut credit: Option<mpsc::Sender<usize>> = None;
    let mut running: Option<tokio::task::JoinHandle<()>> = None;

    while let Some(Ok(msg)) = stream.next().await {
        let text = match msg {
            Message::Text(t) => t,
            Message::Close(_) => break,
            _ => continue,
        };
        let msg: ClientMsg = match serde_json::from_str(&text) {
            Ok(m) => m,
            Err(e) => {
                let _ = out.send(error_message(&Error::invalid(format!("无法解析的消息：{e}")))).await;
                continue;
            }
        };
        match msg {
            ClientMsg::Exec { sql, confirmed, max_rows } => {
                if running.as_ref().is_some_and(|h| !h.is_finished()) {
                    let busy = Error::Busy { message: "上一段 SQL 还没有执行完".into() };
                    let _ = out.send(error_message(&busy)).await;
                    continue;
                }
                if let Err(e) = service.sessions.execute(id, &sql, confirmed).await {
                    let _ = out.send(error_message(&e)).await;
                    continue;
                }
                let (tx, rx) = mpsc::channel(1);
                credit = Some(tx);
                running =
                    Some(tokio::spawn(pump(service.clone(), id, sql, max_rows.max(1), out.clone(), rx)));
            }
            ClientMsg::FetchMore { max_rows } => {
                if let Some(c) = &credit {
                    let _ = c.try_send(max_rows);
                }
            }
            ClientMsg::Cancel => {
                if let Err(e) = service.sessions.cancel(id).await {
                    let _ = out.send(error_message(&e)).await;
                }
            }
        }
    }

    // 连接断开：还在执行就取消（pump 会取完剩余事件）
    if running.as_ref().is_some_and(|h| !h.is_finished()) {
        let _ = service.sessions.cancel(id).await;
    }
    drop(credit);
    if let Some(h) = running {
        let _ = h.await;
    }
    drop(out);
    let _ = writer.await;
}

//! 浏览器模式的服务入口（设计文档 4.1 节）。
//!
//! ```text
//! dblens-server [--listen 127.0.0.1:8742] [--data-dir 目录] [--allow-origin 来源]...
//! ```
//!
//! 启动时生成一次访问令牌并打印出来，本次运行期间有效。首期只供单用户使用，多用户鉴权留给团队版。

use std::net::SocketAddr;
use std::path::PathBuf;
use std::sync::Arc;

use dblens_api::{ApiConfig, new_token, router, serve};
use dblens_service::{Service, default_data_dir};

const DEFAULT_LISTEN: &str = "127.0.0.1:8742";

#[derive(Debug, PartialEq, Eq)]
struct Args {
    listen: SocketAddr,
    data_dir: Option<PathBuf>,
    allowed_origins: Vec<String>,
}

const USAGE: &str = "用法：dblens-server [--listen 地址:端口] [--data-dir 目录] [--allow-origin 来源]...";

fn parse_args(args: impl IntoIterator<Item = String>) -> Result<Args, String> {
    let mut out =
        Args { listen: DEFAULT_LISTEN.parse().unwrap(), data_dir: None, allowed_origins: Vec::new() };
    let mut it = args.into_iter();
    while let Some(a) = it.next() {
        let mut value = |name: &str| it.next().ok_or_else(|| format!("{name} 后面缺少参数\n{USAGE}"));
        match a.as_str() {
            "--listen" => {
                let v = value("--listen")?;
                out.listen = v.parse().map_err(|_| format!("无效的监听地址：{v}"))?;
            }
            "--data-dir" => out.data_dir = Some(PathBuf::from(value("--data-dir")?)),
            "--allow-origin" => out.allowed_origins.push(value("--allow-origin")?),
            "-h" | "--help" => return Err(USAGE.to_string()),
            other => return Err(format!("未知参数：{other}\n{USAGE}")),
        }
    }
    Ok(out)
}

#[tokio::main]
async fn main() {
    tracing_subscriber::fmt().with_writer(std::io::stderr).init();
    let args = match parse_args(std::env::args().skip(1)) {
        Ok(a) => a,
        Err(msg) => {
            eprintln!("{msg}");
            std::process::exit(2);
        }
    };
    if let Err(msg) = run(args).await {
        eprintln!("启动失败：{msg}");
        std::process::exit(1);
    }
}

async fn run(args: Args) -> Result<(), String> {
    let data_dir = match args.data_dir {
        Some(d) => d,
        None => default_data_dir().map_err(|e| e.to_string())?,
    };
    let service = Arc::new(Service::open(&data_dir).map_err(|e| e.to_string())?);
    let token = new_token();
    let listener = tokio::net::TcpListener::bind(args.listen)
        .await
        .map_err(|e| format!("无法监听 {}：{e}", args.listen))?;
    let addr = listener.local_addr().map_err(|e| e.to_string())?;
    if !addr.ip().is_loopback() {
        tracing::warn!("正在监听非本机地址 {addr}：同一网络中的其他人只要拿到访问令牌就能访问");
    }
    // 第一行是地址、第二行是令牌，便于脚本读取
    println!("DBLens 服务已启动：http://{addr}");
    println!("访问令牌：{token}");
    println!("数据目录：{}", data_dir.display());
    let app = router(service, ApiConfig { token, allowed_origins: args.allowed_origins });
    serve(listener, app).await.map_err(|e| e.to_string())
}

#[cfg(test)]

//! 启动真实的 dblens-server 进程，读出它打印的地址和令牌，再用 HTTP 请求验证令牌校验。

use std::io::{BufRead, BufReader, Read, Write};
use std::net::TcpStream;
use std::process::{Command, Stdio};

/// 发一个最简单的 HTTP/1.1 GET 请求，返回状态码。
fn get_status(addr: &str, path: &str, token: Option<&str>) -> u16 {
    let mut stream = TcpStream::connect(addr).unwrap();
    let auth = token.map(|t| format!("Authorization: Bearer {t}\r\n")).unwrap_or_default();
    write!(stream, "GET {path} HTTP/1.1\r\nHost: {addr}\r\n{auth}Connection: close\r\n\r\n").unwrap();
    let mut response = String::new();
    stream.read_to_string(&mut response).unwrap();
    response.split_whitespace().nth(1).unwrap().parse().unwrap()
}

#[test]
fn prints_address_and_token_and_enforces_it() {
    let dir = tempfile::tempdir().unwrap();
    let mut child = Command::new(env!("CARGO_BIN_EXE_dblens-server"))
        .args(["--listen", "127.0.0.1:0", "--data-dir"])
        .arg(dir.path())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .unwrap();
    let mut lines = BufReader::new(child.stdout.take().unwrap()).lines();
    let first = lines.next().unwrap().unwrap();
    let second = lines.next().unwrap().unwrap();
    let addr = first.rsplit("http://").next().unwrap().trim().to_string();
    let token = second.split('：').nth(1).unwrap().trim().to_string();
    assert_eq!(token.len(), 64, "{second}");

    assert_eq!(get_status(&addr, "/api/profiles", None), 401);
    assert_eq!(get_status(&addr, "/api/profiles", Some("wrong")), 401);
    assert_eq!(get_status(&addr, "/api/profiles", Some(&token)), 200);
    assert!(dir.path().join("dblens.db").is_file(), "本地库建在指定的数据目录中");
    child.kill().unwrap();
    let _ = child.wait();
}

# DBLens 接口说明（M0-4b）

桌面模式和浏览器模式共用同一套接口，由 `dblens-api` 实现，路径都在 `/api` 下，请求和响应都是 JSON。

## 鉴权

- 每个请求都要带访问令牌：
  - 优先用请求头 `Authorization: Bearer <令牌>`；
  - 浏览器的 WebSocket 不能设请求头，所以也接受查询参数 `?token=<令牌>`。
- 令牌的来源：
  - 浏览器模式：`dblens-server` 启动时打印；
  - 桌面模式：由 Tauri 注入前端（M0-4c）。
- 浏览器发出的请求（带 `Origin` 头）必须同源，或来源在 `allowed_origins` 列表中。
  - 前端开发服务器要用 `dblens-server --allow-origin http://localhost:5173` 放行。
- 令牌缺失或错误时返回 401，响应体为 `{"kind":"auth",…}`。

## 错误

出错时响应体就是错误对象，按 `kind` 区分，例如 `{"kind":"not_found","what":"连接配置 x"}`。状态码与 `kind` 的对应：

| 状态码 | kind | 含义 |
|---|---|---|
| 400 | `invalid` | 输入不合法 |
| 401 | `auth` | 访问令牌缺失或错误（数据库认证失败是 422） |
| 403 | `denied` | 被执行策略拒绝，或 Origin 不允许 |
| 404 | `not_found` | 对象不存在 |
| 409 | `busy` / `cancelled` | 会话正忙，或已取消 |
| 423 | `locked` | 本地密码库已锁定，需要先解锁 |
| 422 | `connect` / `auth` / `sql` / `timeout` / `driver_unavailable` | 数据库一侧的问题 |
| 500 | `internal` | 程序内部错误 |

`sql` 错误带 `code`（数据库原生错误码）、`message`、`position`。

## REST

| PUT | `/drivers/{driver}/lib-dir` | 确认原生库目录，`{"path": "绝对路径" \| null}` |

### 密码库

|---|---|---|
| GET | `/secrets` | `{backend: "keyring" \| "vault", vault_initialized, unlocked}` |

| POST | `/secrets/unlock` | 解锁，`{"master": "…"}` |
| POST | `/secrets/lock` | 加锁 |

### 连接配置

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/profiles` | 列表 |
| POST | `/profiles` | 新建，`{"profile": {…}, "password": "…" \| null}`，返回 201 |
| GET | `/profiles/{id}` | 读取 |
| PUT | `/profiles/{id}` | 修改，请求体为配置本身 |
| DELETE | `/profiles/{id}` | 删除，返回 204 |
| PUT | `/profiles/{id}/password` | 设置或清除密码，`{"password": "…" \| null}` |

## WebSocket：`GET /api/sessions/{id}/ws?token=…`

### 客户端发送

- `{"type":"exec","sql":"…","confirmed":false,"max_rows":500}`：执行一段 SQL，可以有多条语句。
- `{"type":"fetch_more","max_rows":500}`：取下一批行。
- `{"type":"cancel"}`：取消。

### 服务端发送

| type | 字段 | 说明 |
|---|---|---|
| `statement_start` | `index, start, end, info` | 开始执行第 `index` 条语句。`start`/`end` 是它在提交的 SQL 中的 UTF-16 偏移（可直接用于 Monaco）。`info` 是语句分析结果 |
| `result_start` | `columns` | 结果集的列 |
| `rows` | `rows` | 一批行，每个值形如 `{"t": 类型, "v": 值}` |
| `result_end` | — | 结果集结束 |
| `affected` | `count` | 影响的行数 |
| `message` | `text` | 服务器消息（PG notice、DBMS_OUTPUT） |
| `statement_end` | `index, elapsed_ms` | 这条语句结束 |
| `confirm_required` | `index, start, reason` | 这条语句需要确认，脚本停在这里。确认后从 `start`（UTF-16 偏移）处截取剩余 SQL，带 `confirmed: true` 重新发送 |
| `failed` | `index, error` | 这条语句失败、被拒绝或被取消，脚本停在这里 |
| `done` | — | 整段 SQL 结束 |
| `error` | `error` | 协议层面的错误，如消息无法解析、上一段还没执行完 |

### 背压与断开

- 服务端每发出一个装满 `max_rows` 行的 `rows`，就停下等 `fetch_more`。
- 一批不满，说明结果集已取完，服务端会直接发后面的事件。
- WebSocket 断开时，正在执行的语句会被取消，会话恢复空闲。
