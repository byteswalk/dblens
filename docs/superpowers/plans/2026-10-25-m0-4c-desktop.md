# M0-4c 前端外壳与桌面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 前端外壳 `web/`（联调页）、接口服务同源提供前端页面，以及 Tauri 2 桌面程序 `dblens-desktop`（进程内接口服务、令牌注入、窗口行为、按天滚动的日志）。

**Architecture:**
- 前端页面由 `dblens-api` 的接口服务同源提供（`with_web`），桌面模式和浏览器模式相同，接口不需要 CORS。
- 桌面程序在进程内启动接口服务，只绑定 `127.0.0.1` 的随机端口。窗口直接加载这个地址，令牌经 Tauri 的初始化脚本注入页面。
- 窗口置顶、恢复默认位置都走原生菜单和系统热键，前端不用 Tauri IPC。
- 窗口位置的计算、状态文件的读写都是不依赖 Tauri 的纯函数，单独测试。与 Tauri 交互的部分按清单实测。

**Tech Stack:**
- Rust：Tauri 2.12.5、tauri-plugin-global-shortcut 2.4.1、tracing-appender 0.2.5、axum 0.8；
- 前端：Vite 8、React 19、TypeScript 7、Ant Design 6、Vitest 5，包管理器 pnpm 11.8.0。

use axum::Router;
use axum::body::Body;
use axum::http::{Request, StatusCode, header};
use dblens_api::{ApiConfig, router, with_web};
use dblens_service::fake::FakeDriver;
use dblens_service::{DefaultPolicy, DriverRegistry, SecretBackend, Secrets, Service, Store};
use http_body_util::BodyExt;
use tower::ServiceExt;

fn app(dir: &std::path::Path) -> Router {
    let store = Arc::new(Store::open_in_memory().unwrap());
    let secrets = Arc::new(Secrets::with_backend(store.clone(), SecretBackend::Vault));
    let registry = Arc::new(DriverRegistry::with_drivers(
        store.clone(),
        vec![Box::new(FakeDriver { log: Arc::default() })],
    ));
    let service = Arc::new(Service::with_parts(store, secrets, registry, Arc::new(DefaultPolicy)));
    let config = ApiConfig { token: "t".into(), allowed_origins: vec![] };

async fn get(app: &Router, uri: &str) -> (StatusCode, String, String, String) {
    let resp = app.clone().oneshot(Request::get(uri).body(Body::empty()).unwrap()).await.unwrap();
    let header_of = |name| {
        resp.headers()
            .get(name)
            .map(|v: &header::HeaderValue| v.to_str().unwrap().to_string())
            .unwrap_or_default()
    };
    let (ct, cache) = (header_of(header::CONTENT_TYPE), header_of(header::CACHE_CONTROL));
    let status = resp.status();
    let body = String::from_utf8(resp.into_body().collect().await.unwrap().to_bytes().to_vec()).unwrap();
    (status, ct, cache, body)
}

//! 前端页面（`web/` 构建出的 `dist` 目录）的静态文件服务，桌面模式和浏览器模式共用。
//!
//! - 页面与 `/api` 同源，前端调用接口不涉及跨域。
//! - 静态文件不需要令牌：页面加载之后才拿得到令牌。业务全部在 `/api` 下，仍受令牌保护。
//! - 前端是单页应用：没有扩展名的路径找不到文件时返回 `index.html`，由前端路由处理。
//!   `/api` 下不存在的路径一律 404，不回退到页面。

use std::path::{Path, PathBuf};
use std::sync::Arc;

use axum::Router;
use axum::http::{HeaderValue, StatusCode, Uri, header};
use axum::response::{IntoResponse, Response};

/// 给接口路由加上前端页面：凡是没有匹配到接口的 GET 请求，都到 `dir` 中找文件。
pub fn with_web(app: Router, dir: PathBuf) -> Router {
    let dir = Arc::new(dir);
    app.fallback(move |uri: Uri| serve(dir.clone(), uri))
}

/// 把 URL 路径转成 `dir` 下的相对路径。含 `..`、`.`、空段、反斜杠或冒号（Windows 盘符）的路径一律拒绝。
/// 路径不做百分号解码：`%2e%2e` 只会被当成一个普通文件名，找不到就是 404。
fn safe_relative(path: &str) -> Option<PathBuf> {
    let rest = path.strip_prefix('/')?;
    let mut out = PathBuf::new();
    if rest.is_empty() {
        return Some(out);
    }
    for seg in rest.split('/') {
        if seg.is_empty() || seg == "." || seg == ".." || seg.contains(['\\', ':']) {
            return None;
        }
        out.push(seg);
    }
    Some(out)
}

fn content_type(path: &Path) -> &'static str {
    match path.extension().and_then(|e| e.to_str()).unwrap_or("") {
        "html" => "text/html; charset=utf-8",
        "js" | "mjs" => "text/javascript; charset=utf-8",
        "css" => "text/css; charset=utf-8",
        "json" | "map" => "application/json",
        "svg" => "image/svg+xml",
        "png" => "image/png",
        "ico" => "image/x-icon",
        "woff2" => "font/woff2",
        "woff" => "font/woff",
        "ttf" => "font/ttf",
        "wasm" => "application/wasm",
        "txt" => "text/plain; charset=utf-8",
        _ => "application/octet-stream",
    }
}

fn file_response(path: &Path, bytes: Vec<u8>) -> Response {
    // Vite 输出的 assets/ 下的文件名带内容哈希，可以长期缓存；index.html 每次都要重新验证
    let cache = if path.components().next().is_some_and(|c| c.as_os_str() == "assets") {
        "public, max-age=31536000, immutable"
    } else {
        "no-cache"
    };
    let mut resp = bytes.into_response();
    let h = resp.headers_mut();
    h.insert(header::CONTENT_TYPE, HeaderValue::from_static(content_type(path)));
    h.insert(header::CACHE_CONTROL, HeaderValue::from_static(cache));
    h.insert(header::X_CONTENT_TYPE_OPTIONS, HeaderValue::from_static("nosniff"));
    resp
}

async fn serve(dir: Arc<PathBuf>, uri: Uri) -> Response {
    let Some(rel) = safe_relative(uri.path()) else { return StatusCode::NOT_FOUND.into_response() };
    if rel.starts_with("api") {
        return StatusCode::NOT_FOUND.into_response();
    }
    let rel = if rel.as_os_str().is_empty() { PathBuf::from("index.html") } else { rel };
    if let Ok(bytes) = tokio::fs::read(dir.join(&rel)).await {
        return file_response(&rel, bytes);
    }
    if rel.extension().is_none()
        && let Ok(bytes) = tokio::fs::read(dir.join("index.html")).await
    {
        return file_response(Path::new("index.html"), bytes);
    }
    StatusCode::NOT_FOUND.into_response()
}

#[cfg(test)]

````rust
//! 浏览器模式的服务入口（设计文档 4.1 节）。
//!
//! ```text
//! dblens-server [--listen 127.0.0.1:8742] [--data-dir 目录] [--web-dir 目录] [--allow-origin 来源]...
//! ```
//!
//! 启动时生成一次访问令牌并打印出来，本次运行期间有效。首期只供单用户使用，多用户鉴权留给团队版。
//!
//! 前端页面默认取可执行文件旁边的 `web/` 目录；找不到时只提供接口，并在日志中提示。

use std::net::SocketAddr;
use std::path::PathBuf;
use std::sync::Arc;

use dblens_api::{ApiConfig, new_token, router, serve, with_web};
use dblens_service::{Service, default_data_dir};

const DEFAULT_LISTEN: &str = "127.0.0.1:8742";

#[derive(Debug, PartialEq, Eq)]
struct Args {
    listen: SocketAddr,
    data_dir: Option<PathBuf>,
    web_dir: Option<PathBuf>,
    allowed_origins: Vec<String>,
}

const USAGE: &str =
    "用法：dblens-server [--listen 地址:端口] [--data-dir 目录] [--web-dir 目录] [--allow-origin 来源]...";

fn parse_args(args: impl IntoIterator<Item = String>) -> Result<Args, String> {
    let mut out = Args {
        listen: DEFAULT_LISTEN.parse().unwrap(),
        data_dir: None,
        web_dir: None,
        allowed_origins: Vec::new(),
    };
    let mut it = args.into_iter();
    while let Some(a) = it.next() {
        let mut value = |name: &str| it.next().ok_or_else(|| format!("{name} 后面缺少参数\n{USAGE}"));
        match a.as_str() {
            "--listen" => {
                let v = value("--listen")?;
                out.listen = v.parse().map_err(|_| format!("无效的监听地址：{v}"))?;
            }
            "--data-dir" => out.data_dir = Some(PathBuf::from(value("--data-dir")?)),
            "--web-dir" => out.web_dir = Some(PathBuf::from(value("--web-dir")?)),
            "--allow-origin" => out.allowed_origins.push(value("--allow-origin")?),
            "-h" | "--help" => return Err(USAGE.to_string()),
            other => return Err(format!("未知参数：{other}\n{USAGE}")),
        }
    }
    Ok(out)
}

/// 前端页面目录：命令行指定的优先，否则取可执行文件旁边的 `web/`。目录里没有 `index.html` 时返回 `None`。
fn resolve_web_dir(arg: Option<PathBuf>, exe: Option<PathBuf>) -> Option<PathBuf> {
    let dir = arg.or_else(|| exe?.parent().map(|p| p.join("web")))?;
    dir.join("index.html").is_file().then_some(dir)
}

        Some(d) => d,
        None => default_data_dir().map_err(|e| e.to_string())?,
    };
    let service = Arc::new(Service::open(&data_dir).map_err(|e| e.to_string())?);
    let token = new_token();
    let listener = tokio::net::TcpListener::bind(args.listen)
        .await
        .map_err(|e| format!("无法监听 {}：{e}", args.listen))?;
    let addr = listener.local_addr().map_err(|e| e.to_string())?;
    if !addr.ip().is_loopback() {
        tracing::warn!("正在监听非本机地址 {addr}：同一网络中的其他人只要拿到访问令牌就能访问");
    }
    let web_dir = resolve_web_dir(args.web_dir, std::env::current_exe().ok());
    // 第一行是地址、第二行是令牌，便于脚本读取
    println!("DBLens 服务已启动：http://{addr}");
    println!("访问令牌：{token}");
    println!("数据目录：{}", data_dir.display());
    // 令牌放在 # 后面：浏览器不会把它发给服务器，也不会出现在访问日志和 Referer 中
    match &web_dir {
        Some(_) => println!("在浏览器中打开：http://{addr}/#token={token}"),
        None => tracing::warn!("没有找到前端页面目录（可用 --web-dir 指定），只提供接口"),
    }
    let mut app = router(service, ApiConfig { token, allowed_origins: args.allowed_origins });
    if let Some(dir) = web_dir {
        app = with_web(app, dir);
    }
    serve(listener, app).await.map_err(|e| e.to_string())
}

// 访问令牌的来源（设计文档 4.1 节）：
// - 桌面模式：Tauri 在页面脚本运行前注入 window.__DBLENS__.token；
// - 浏览器模式：dblens-server 打印的链接带 #token=…。取出后存进 sessionStorage（刷新页面仍可用），
//   并从地址栏去掉，避免被截图或复制出去。

export const TOKEN_KEY = 'dblens.token'

/** 只用到 window 的这几个部分，测试时可以传入假对象。 */
export interface TokenHost {
  __DBLENS__?: { token?: string }
  location: { hash: string; pathname: string; search: string }
  history: { replaceState(data: unknown, unused: string, url: string): void }
  sessionStorage: { getItem(key: string): string | null; setItem(key: string, value: string): void }
}

export function bootstrapToken(host: TokenHost): string | null {
  const injected = host.__DBLENS__?.token
  if (injected) return injected
  const m = /^#(?:.*&)?token=([^&]+)/.exec(host.location.hash)
  if (m) {
    const token = decodeURIComponent(m[1])
    try {
      host.sessionStorage.setItem(TOKEN_KEY, token)
    } catch {
      // 存储不可用（隐私模式等）时只在本页有效
    }
    host.history.replaceState(null, '', host.location.pathname + host.location.search)
    return token
  }
  try {
    return host.sessionStorage.getItem(TOKEN_KEY)
  } catch {
    return null
  }
}

// REST 接口客户端。接口说明见 docs/notes/m0-4b-api.md；页面与接口同源，路径都以 /api 开头。

export type DriverId = 'mysql' | 'postgres' | 'oracle' | 'dameng'
export type Environment = 'none' | 'dev' | 'test' | 'prod'

/** 服务端的错误对象（dblens_core::Error），按 kind 区分。 */
export interface ErrorBody {
  kind: string
  message?: string
  code?: string
  position?: number | null
  what?: string
  reason?: string
  hint?: string
}

export class ApiError extends Error {
  readonly status: number
  readonly body: ErrorBody

  constructor(status: number, body: ErrorBody) {
    super(errorText(body))
    this.status = status
    this.body = body
  }
}

/** 把错误对象转成给用户看的一句话，与服务端 Display 的措辞一致。 */
export function errorText(e: ErrorBody): string {
  switch (e.kind) {
    case 'connect':
      return `连接失败：${e.message}`
    case 'auth':
      return `认证失败：${e.message}`
    case 'sql':
      return `SQL 错误 [${e.code}]：${e.message}`
    case 'timeout':
      return '执行超时'
    case 'cancelled':
      return '执行已取消'
    case 'driver_unavailable':
      return `驱动不可用：${e.hint}`
    case 'invalid':
      return `无效的输入：${e.message}`
    case 'not_found':
      return `找不到${e.what}`
    case 'busy':
      return `会话正忙：${e.message}`
    case 'locked':
      return '密码库已锁定，请先输入主密码'
    case 'denied':
      return `执行被拒绝：${e.reason}`
    case 'internal':
      return `内部错误：${e.message}`
    default:
      return JSON.stringify(e)
  }
}

export type FetchFn = (input: string, init?: RequestInit) => Promise<Response>

export function createApi(token: string, fetchFn: FetchFn = (i, o) => fetch(i, o)) {
  async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
    const headers: Record<string, string> = { Authorization: `Bearer ${token}` }
    if (body !== undefined) headers['Content-Type'] = 'application/json'
    const resp = await fetchFn(`/api${path}`, {
      method,
      headers,
      body: body === undefined ? undefined : JSON.stringify(body),
    })
    const text = await resp.text()
    const data = text ? JSON.parse(text) : null
    if (!resp.ok) {
      throw new ApiError(resp.status, data ?? { kind: 'internal', message: `HTTP ${resp.status}` })
    }
    return data as T
  }

  return {
    drivers: () => request<DriverStatus[]>('GET', '/drivers'),
    setLibDir: (driver: DriverId, path: string | null) =>
      request<DriverStatus>('PUT', `/drivers/${driver}/lib-dir`, { path }),
    secrets: () => request<SecretStatus>('GET', '/secrets'),
    profiles: () => request<Profile[]>('GET', '/profiles'),

// 会话 WebSocket 执行协议（docs/notes/m0-4b-api.md）：发送 exec / fetch_more / cancel，
// 把服务端事件归并成界面要显示的状态。归并是纯函数，单独测试；ExecSocket 只负责收发。

import type { ErrorBody } from './api'

/** 单元格值：{"t": 类型, "v": 值}，Null 没有 v。 */
export interface CellValue {
  t: string
  v?: unknown
}

export interface ColumnMeta {
  name: string
  type_name: string
  nullable: boolean | null
}

export type ServerEvent =
  | { type: 'statement_start'; index: number; start: number; end: number; info: { keyword: string } }
  | { type: 'result_start'; columns: ColumnMeta[] }
  | { type: 'rows'; rows: CellValue[][] }
  | { type: 'result_end' }
  | { type: 'affected'; count: number }
  | { type: 'message'; text: string }
  | { type: 'statement_end'; index: number; elapsed_ms: number }
  | { type: 'confirm_required'; index: number; start: number; reason: string }
  | { type: 'failed'; index: number; error: ErrorBody }
  | { type: 'done' }
  | { type: 'error'; error: ErrorBody }

export interface ResultSet {
  columns: ColumnMeta[]
  rows: CellValue[][]
  /** 结果集已取完。 */
  complete: boolean
}

export interface StatementState {
  index: number
  /** 语句在提交的 SQL 中的 UTF-16 偏移，可直接用于 String.prototype.slice。 */
  start: number
  end: number
  keyword: string
  results: ResultSet[]
  affected: number | null
  messages: string[]
  elapsedMs: number | null
  error: ErrorBody | null
  confirm: { start: number; reason: string } | null
}

export interface ExecState {
  statements: StatementState[]
  /** 一批装满了 max_rows 行，服务端在等 fetch_more。 */
  waitingForMore: boolean
  done: boolean
  /** 协议层面的错误（消息无法解析、上一段还没执行完等）。 */
  protocolError: ErrorBody | null
}

export const initialExec: ExecState = { statements: [], waitingForMore: false, done: false, protocolError: null }

function updateLast(state: ExecState, f: (s: StatementState) => StatementState): ExecState {
  const last = state.statements.length - 1
  if (last < 0) return state
  return { ...state, statements: state.statements.map((s, i) => (i === last ? f(s) : s)) }
}

function updateLastResult(s: StatementState, f: (r: ResultSet) => ResultSet): StatementState {
  const last = s.results.length - 1
  if (last < 0) return s
  return { ...s, results: s.results.map((r, i) => (i === last ? f(r) : r)) }
}

/** 把一个服务端事件归并进状态。`maxRows` 是本次请求的每批行数，用来判断服务端是否在等 fetch_more。 */
export function reduceExec(state: ExecState, ev: ServerEvent, maxRows: number): ExecState {
  switch (ev.type) {
    case 'statement_start':
      return {
        ...state,
        statements: [
          ...state.statements,
          {
            index: ev.index,
            start: ev.start,
            end: ev.end,
            keyword: ev.info.keyword,
            results: [],
            affected: null,
            messages: [],
            elapsedMs: null,
            error: null,
            confirm: null,
          },
        ],
      }
    case 'result_start':
      return updateLast(state, (s) => ({ ...s, results: [...s.results, { columns: ev.columns, rows: [], complete: false }] }))
    case 'rows':
      return {
        ...updateLast(state, (s) => updateLastResult(s, (r) => ({ ...r, rows: [...r.rows, ...ev.rows] }))),
        waitingForMore: ev.rows.length >= maxRows,
      }
    case 'result_end':
      return { ...updateLast(state, (s) => updateLastResult(s, (r) => ({ ...r, complete: true }))), waitingForMore: false }
    case 'affected':
      return updateLast(state, (s) => ({ ...s, affected: ev.count }))
    case 'message':
      return updateLast(state, (s) => ({ ...s, messages: [...s.messages, ev.text] }))
    case 'statement_end':
      return updateLast(state, (s) => ({ ...s, elapsedMs: ev.elapsed_ms }))
    case 'confirm_required':
      return updateLast(state, (s) => ({ ...s, confirm: { start: ev.start, reason: ev.reason } }))
    case 'failed':
      return { ...updateLast(state, (s) => ({ ...s, error: ev.error })), waitingForMore: false }
    case 'done':
      return { ...state, done: true, waitingForMore: false }
    case 'error':
      return { ...state, protocolError: ev.error, waitingForMore: false }
  }
}

export const DEFAULT_MAX_ROWS = 500

/** 一个会话的执行连接。onEvent 收到服务端的每个事件；连接断开时服务端会取消正在执行的语句。 */
export class ExecSocket {
  private ws: WebSocket
  private ready: Promise<void>

  constructor(url: string, onEvent: (ev: ServerEvent) => void, onClose: () => void) {
    this.ws = new WebSocket(url)
    this.ready = new Promise((resolve, reject) => {
      this.ws.addEventListener('open', () => resolve(), { once: true })
      this.ws.addEventListener('error', () => reject(new Error('WebSocket 连接失败')), { once: true })
    })
    this.ws.addEventListener('message', (m) => onEvent(JSON.parse(m.data as string) as ServerEvent))
    this.ws.addEventListener('close', onClose)
  }

  private async send(msg: object) {
    await this.ready
    this.ws.send(JSON.stringify(msg))
  }

  exec(sql: string, confirmed = false, maxRows = DEFAULT_MAX_ROWS) {
    return this.send({ type: 'exec', sql, confirmed, max_rows: maxRows })
  }

  fetchMore(maxRows = DEFAULT_MAX_ROWS) {
    return this.send({ type: 'fetch_more', max_rows: maxRows })
  }

  cancel() {
    return this.send({ type: 'cancel' })
  }

  close() {
    this.ws.close()
  }
}

/** 单元格的显示文本。 */
export function cellText(c: CellValue): string {
  if (c.t === 'null') return 'NULL'
  if (c.t === 'lob') {
    const lob = c.v as { preview: string; total_len: number; truncated: boolean; binary: boolean }
    return lob.truncated ? `${lob.binary ? '(二进制) ' : ''}${lob.preview}…（共 ${lob.total_len}）` : lob.preview
  }
  if (c.t === 'other') return (c.v as { text: string }).text
  if (typeof c.v === 'object') return JSON.stringify(c.v)
  return String(c.v)
}

```python
"""生成 1024×1024 的占位图标（蓝底白色镜头圈），只用标准库。正式图标随 M1 设计稿替换。"""
import math
import struct
import sys
import zlib

N = 1024


def pixel(x, y):
    # 圆角方形底
    r = 180
    dx = max(r - x, 0, x - (N - 1 - r))
    dy = max(r - y, 0, y - (N - 1 - r))
    if dx * dx + dy * dy > r * r:
        return (0, 0, 0, 0)
    d = math.hypot(x - N * 0.45, y - N * 0.45)
    # 镜头圈和手柄
    if 230 <= d <= 300:
        return (255, 255, 255, 255)
    t = (x - y) / (2 * N) + 0.5
    if abs((x - N * 0.45) - (y - N * 0.45)) < 55 and x > N * 0.45 + 200 and x < N * 0.82:
        return (255, 255, 255, 255)
    return (int(22 + 30 * t), int(119 + 40 * t), 255, 255)


rows = b''.join(b'\x00' + b''.join(struct.pack('4B', *pixel(x, y)) for x in range(N)) for y in range(N))


def chunk(kind, data):
    return struct.pack('>I', len(data)) + kind + data + struct.pack('>I', zlib.crc32(kind + data) & 0xFFFFFFFF)


png = b'\x89PNG\r\n\x1a\n' + chunk(b'IHDR', struct.pack('>IIBBBBB', N, N, 8, 6, 0, 0, 0))
png += chunk(b'IDAT', zlib.compress(rows, 9)) + chunk(b'IEND', b'')
with open(sys.argv[1], 'wb') as f:
    f.write(png)

//! 窗口位置和大小的计算（设计文档 7.2 节），不依赖 Tauri，单独测试。坐标和尺寸都是物理像素。

use serde::{Deserialize, Serialize};

/// 默认大小与最小大小（逻辑像素）。
pub const DEFAULT_SIZE: (f64, f64) = (1440.0, 900.0);
pub const MIN_SIZE: (f64, f64) = (1024.0, 640.0);

/// 窗口顶部这么高的条带算作标题栏。
const TITLE_BAR: i64 = 40;
/// 标题栏至少要有这么大的一块落在某个显示器的工作区内，用户才拖得动窗口。
const REACHABLE: (i64, i64) = (100, 20);

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub struct Rect {
    pub x: i32,
    pub y: i32,
    pub width: u32,
    pub height: u32,
}

/// 默认位置和大小：在 `work_area`（显示器去掉任务栏后的区域）中居中，默认 1440×900；
/// 某个方向上放不下时，这个方向取工作区的 90%。`scale` 是显示器的缩放比例。
pub fn default_rect(work_area: Rect, scale: f64) -> Rect {
    let fit = |logical: f64, available: u32| {
        let want = (logical * scale).round();
        if want <= f64::from(available) { want as u32 } else { (f64::from(available) * 0.9).round() as u32 }
    };
    let width = fit(DEFAULT_SIZE.0, work_area.width);
    let height = fit(DEFAULT_SIZE.1, work_area.height);
    Rect {
        x: work_area.x + ((work_area.width - width) / 2) as i32,
        y: work_area.y + ((work_area.height - height) / 2) as i32,
        width,
        height,
    }
}

/// 保存的窗口位置是否还能用：标题栏有足够大的一块落在某个显示器的工作区内。
/// 显示器被拔掉或分辨率变小后，返回 false，由调用方改用主屏幕上的默认位置。
pub fn is_reachable(rect: Rect, work_areas: &[Rect]) -> bool {
    let (left, top) = (i64::from(rect.x), i64::from(rect.y));
    let (right, bottom) = (left + i64::from(rect.width), top + TITLE_BAR.min(i64::from(rect.height)));
    work_areas.iter().any(|a| {
        let (al, at) = (i64::from(a.x), i64::from(a.y));
        let (ar, ab) = (al + i64::from(a.width), at + i64::from(a.height));
        let w = right.min(ar) - left.max(al);
        let h = bottom.min(ab) - top.max(at);
        w >= REACHABLE.0 && h >= REACHABLE.1
    })
}

//! 窗口状态的保存与读取：数据目录下的 `window.json`。

use std::path::Path;

use serde::{Deserialize, Serialize};

use crate::geometry::Rect;

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct WindowState {
    /// 未最大化时的位置和大小；`None` 表示用默认位置。
    pub rect: Option<Rect>,
    pub maximized: bool,
    pub always_on_top: bool,
}

/// 读取保存的状态。文件不存在或内容损坏时用默认状态（损坏时记一条警告），不影响启动。
/// 允许开头有 UTF-8 BOM（用记事本等工具改过的文件）。
pub fn load(path: &Path) -> WindowState {
    match std::fs::read(path) {
        Ok(bytes) => serde_json::from_slice(bytes.strip_prefix(b"\xEF\xBB\xBF").unwrap_or(&bytes))
            .unwrap_or_else(|e| {
                tracing::warn!("窗口状态文件 {} 无法解析，改用默认状态：{e}", path.display());
                WindowState::default()
            }),
        Err(_) => WindowState::default(),
    }
}

/// 先写临时文件再改名，避免写到一半退出时留下损坏的文件。
pub fn save(path: &Path, state: &WindowState) -> std::io::Result<()> {
    let tmp = path.with_extension("json.tmp");
    std::fs::write(&tmp, serde_json::to_vec_pretty(state)?)?;
    std::fs::rename(&tmp, path)
}

//! 日志（设计文档 4.3 节）：按天滚动，写在数据目录下的 `logs/`，保留最近 14 天。
//! 调试构建同时输出到控制台。日志中不得出现密码和访问令牌。

use std::path::Path;

use tracing_appender::non_blocking::WorkerGuard;
use tracing_appender::rolling::{RollingFileAppender, Rotation};
use tracing_subscriber::fmt;
use tracing_subscriber::layer::SubscriberExt;
use tracing_subscriber::util::SubscriberInitExt;

pub const KEEP_DAYS: usize = 14;

/// 按天滚动的日志文件：`dblens.2026-10-25.log`。
pub fn appender(dir: &Path) -> Result<RollingFileAppender, String> {
    RollingFileAppender::builder()
        .rotation(Rotation::DAILY)
        .filename_prefix("dblens")
        .filename_suffix("log")
        .max_log_files(KEEP_DAYS)
        .build(dir)
        .map_err(|e| format!("无法创建日志目录 {}：{e}", dir.display()))
}

/// 初始化全局日志。返回的 guard 要一直持有到程序退出，否则缓冲中的日志会丢失。
pub fn init(dir: &Path) -> Result<WorkerGuard, String> {
    let (writer, guard) = tracing_appender::non_blocking(appender(dir)?);
    let file = fmt::layer().with_writer(writer).with_ansi(false);
    let console = cfg!(debug_assertions).then(|| fmt::layer().with_writer(std::io::stderr));
    tracing_subscriber::registry()
        .with(tracing_subscriber::filter::LevelFilter::INFO)
        .with(file)
        .with(console)
        .try_init()
        .map_err(|e| e.to_string())?;
    // panic 也写进日志：发布版没有控制台，不写就看不到
    let default_hook = std::panic::take_hook();
    std::panic::set_hook(Box::new(move |info| {
        tracing::error!("程序异常：{info}");
        default_hook(info);
    }));
    Ok(guard)
}

//! 主窗口（设计文档 7.2 节）：
//! - 首次启动 1440×900 居中，屏幕小时取工作区的 90%，最小 1024×640；
//! - 菜单"窗口"里有"窗口置顶"（Ctrl+Shift+T）和"恢复默认窗口位置和大小"；
//! - 退出时保存位置、大小、是否最大化和置顶状态；保存的位置已不在任何显示器上时，改用主屏幕的默认位置。
//!
//! 页面由进程内的接口服务提供（与 `/api` 同源）。访问令牌经初始化脚本注入页面；
//! 窗口只允许停留在这个地址下，防止令牌被注入到其他网站的页面中。
//!
//! 快捷键：Windows 上键盘焦点在页面（WebView2）里时，按键不经过窗口的消息循环，菜单快捷键不会触发（实测）。
//! 所以置顶快捷键用系统热键实现，只在窗口获得焦点时注册、失去焦点时注销，不影响其他程序。

use std::path::PathBuf;
use std::sync::Mutex;
use std::sync::atomic::{AtomicU64, Ordering};
use std::time::Duration;

use tauri::menu::{CheckMenuItem, CheckMenuItemBuilder, MenuBuilder, MenuItemBuilder, SubmenuBuilder};
use tauri::{
    App, AppHandle, Manager, PhysicalPosition, PhysicalSize, WebviewUrl, WebviewWindow, WebviewWindowBuilder,
    WindowEvent,
};
use tauri_plugin_global_shortcut::{GlobalShortcutExt, Shortcut, ShortcutEvent, ShortcutState};

use crate::geometry::{self, MIN_SIZE, Rect};
use crate::window_state::{self, WindowState};

const MAIN: &str = "main";
const MENU_ON_TOP: &str = "always_on_top";
const MENU_RESET: &str = "reset_window";
const MENU_QUIT: &str = "quit";
/// "窗口置顶"的快捷键。没有用 Ctrl+Alt+T：它在 Linux 桌面上是打开终端的系统快捷键。
pub const ON_TOP_SHORTCUT: &str = "CmdOrCtrl+Shift+T";

/// 移动、缩放后等这么久再记录位置：最大化时移动和缩放事件先于"已最大化"标志到达，立即记录会把最大化后的大小当成普通大小。
const SETTLE: Duration = Duration::from_millis(300);

/// 运行期间的窗口状态，退出时写回文件。
struct Tracked {
    path: PathBuf,
    state: Mutex<WindowState>,
    on_top: CheckMenuItem<tauri::Wry>,
    /// 每次移动、缩放加一；延迟记录时编号已变，说明之后又有新事件，这次就不记了。
    generation: AtomicU64,
}

/// 页面脚本运行前执行的初始化脚本：注入访问令牌。
pub fn init_script(token: &str) -> String {
    format!("window.__DBLENS__ = Object.freeze({{ token: {} }});", serde_json::Value::from(token))
}

/// 窗口只能停留在接口服务的地址下（`base` 形如 `http://127.0.0.1:端口/`）。
pub fn allowed_navigation(base: &str, url: &str) -> bool {
    url.starts_with(base)
}

fn on_top_shortcut() -> Shortcut {
    ON_TOP_SHORTCUT.parse().expect("快捷键格式")
}

fn to_rect(p: PhysicalPosition<i32>, s: PhysicalSize<u32>) -> Rect {
    Rect { x: p.x, y: p.y, width: s.width, height: s.height }
}

fn apply_rect(win: &WebviewWindow, r: Rect) -> tauri::Result<()> {
    win.set_size(PhysicalSize::new(r.width, r.height))?;
    win.set_position(PhysicalPosition::new(r.x, r.y))
}

/// 主屏幕（取不到时用窗口当前所在的屏幕）上的默认位置和大小。
fn default_rect(win: &WebviewWindow) -> tauri::Result<Option<Rect>> {
    let monitor = match win.primary_monitor()? {
        Some(m) => Some(m),
        None => win.current_monitor()?,
    };
    Ok(monitor.map(|m| {
        let a = m.work_area();
        geometry::default_rect(to_rect(a.position, a.size), m.scale_factor())
    }))
}

fn reset(win: &WebviewWindow) -> tauri::Result<()> {
    win.unmaximize()?;
    if let Some(r) = default_rect(win)? {
        apply_rect(win, r)?;
    }
    Ok(())
}

/// 记下未最大化、未最小化时的位置和大小，作为下次启动的位置。
fn remember(win: &WebviewWindow, tracked: &Tracked) -> tauri::Result<()> {
    if win.is_maximized()? || win.is_minimized()? {
        return Ok(());
    }
    let r = to_rect(win.outer_position()?, win.inner_size()?);
    tracked.state.lock().unwrap().rect = Some(r);
    Ok(())
}

/// 移动、缩放后延迟记录位置，连续的事件只记最后一次。
fn remember_later(win: &WebviewWindow) {
    let generation = win.state::<Tracked>().generation.fetch_add(1, Ordering::SeqCst) + 1;
    let win = win.clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(SETTLE).await;
        let tracked = win.state::<Tracked>();
        if tracked.generation.load(Ordering::SeqCst) == generation {
            let _ = remember(&win, &tracked);
        }
    });
}

fn save(win: &WebviewWindow, tracked: &Tracked) {
    // 退出时状态已稳定，补记一次，免得最后一次移动还没来得及记录
    let _ = remember(win, tracked);
    let mut s = *tracked.state.lock().unwrap();
    s.maximized = win.is_maximized().unwrap_or(false);
    s.always_on_top = tracked.on_top.is_checked().unwrap_or(false);
    if let Err(e) = window_state::save(&tracked.path, &s) {
        tracing::warn!("无法保存窗口状态到 {}：{e}", tracked.path.display());
    }
}

/// 按菜单项的勾选状态设置置顶。
fn apply_on_top(app: &AppHandle) -> tauri::Result<()> {
    if let Some(win) = app.get_webview_window(MAIN) {
        win.set_always_on_top(app.state::<Tracked>().on_top.is_checked()?)?;
    }
    Ok(())
}

/// 快捷键：翻转菜单项的勾选状态，再按它设置置顶。
pub fn on_shortcut(app: &AppHandle, shortcut: &Shortcut, event: ShortcutEvent) {
    if event.state != ShortcutState::Pressed || *shortcut != on_top_shortcut() {
        return;
    }
    let item = &app.state::<Tracked>().on_top;
    let result = item.is_checked().and_then(|c| item.set_checked(!c)).and_then(|()| apply_on_top(app));
    if let Err(e) = result {
        tracing::warn!("切换窗口置顶失败：{e}");
    }
}

fn on_menu(app: &AppHandle, id: &str) -> tauri::Result<()> {
    let Some(win) = app.get_webview_window(MAIN) else { return Ok(()) };
    match id {
        // 点击时菜单项已自动切换了勾选状态
        MENU_ON_TOP => apply_on_top(app)?,
        MENU_RESET => reset(&win)?,
        MENU_QUIT => {
            save(&win, &app.state::<Tracked>());
            app.exit(0);
        }
        _ => {}
    }
    Ok(())
}

/// 窗口获得焦点时注册快捷键，失去焦点时注销。注册失败（被其他程序占用）只记日志，菜单仍可用。
fn focus_changed(app: &AppHandle, focused: bool) {
    let gs = app.global_shortcut();
    let shortcut = on_top_shortcut();
    let result = if focused {
        if gs.is_registered(shortcut) { Ok(()) } else { gs.register(shortcut) }
    } else if gs.is_registered(shortcut) {
        gs.unregister(shortcut)
    } else {
        Ok(())
    };
    if let Err(e) = result {
        tracing::warn!("快捷键 {ON_TOP_SHORTCUT} {}失败：{e}", if focused { "注册" } else { "注销" });
    }
}

/// 创建主窗口：恢复保存的状态，注入令牌，挂上菜单和窗口事件。
pub fn create_main(app: &App, base: &str, token: &str, state_path: PathBuf) -> tauri::Result<()> {
    let saved = window_state::load(&state_path);
    let on_top = CheckMenuItemBuilder::with_id(MENU_ON_TOP, "窗口置顶")
        .checked(saved.always_on_top)
        .accelerator(ON_TOP_SHORTCUT)
        .build(app)?;
    let window_menu = SubmenuBuilder::new(app, "窗口")
        .item(&on_top)
        .item(&MenuItemBuilder::with_id(MENU_RESET, "恢复默认窗口位置和大小").build(app)?)
        .separator()
        .item(&MenuItemBuilder::with_id(MENU_QUIT, "退出").build(app)?)
        .build()?;
    let menu = MenuBuilder::new(app).item(&window_menu).build()?;

    let allowed = base.to_string();
    let win = WebviewWindowBuilder::new(app, MAIN, WebviewUrl::External(base.parse().expect("接口地址")))
        .title("DBLens 数洞")
        .menu(menu)
        .min_inner_size(MIN_SIZE.0, MIN_SIZE.1)
        .visible(false)
        .initialization_script(init_script(token))
        .on_navigation(move |url| {
            let ok = allowed_navigation(&allowed, url.as_str());
            if !ok {
                tracing::warn!("已阻止窗口跳转到 {url}");
            }
            ok
        })
        .build()?;

    let work_areas: Vec<Rect> = win
        .available_monitors()?
        .iter()
        .map(|m| to_rect(m.work_area().position, m.work_area().size))
        .collect();
    match saved.rect {
        Some(r) if geometry::is_reachable(r, &work_areas) => apply_rect(&win, r)?,
        Some(r) => {
            tracing::info!("保存的窗口位置 {r:?} 已不在任何显示器上，移回主屏幕");
            reset(&win)?;
        }
        None => reset(&win)?,
    }
    if saved.maximized {
        win.maximize()?;
    }
    win.set_always_on_top(saved.always_on_top)?;
    win.show()?;

    let tracked =
        Tracked { path: state_path, state: Mutex::new(saved), on_top, generation: AtomicU64::new(0) };
    remember(&win, &tracked)?;
    app.manage(tracked);
    app.on_menu_event(|app, event| {
        if let Err(e) = on_menu(app, event.id().as_ref()) {
            tracing::warn!("菜单操作失败：{e}");
        }
    });
    let w = win.clone();
    win.on_window_event(move |event| {
        let tracked = w.state::<Tracked>();
        match event {
            WindowEvent::Moved(_) | WindowEvent::Resized(_) => remember_later(&w),
            WindowEvent::Focused(focused) => focus_changed(w.app_handle(), *focused),
            WindowEvent::CloseRequested { .. } => save(&w, &tracked),
            _ => {}
        }
    });
    Ok(())
}

//! 桌面模式入口（设计文档 4.1 节）：进程内启动接口服务，只绑定 127.0.0.1 的随机端口，
//! 每次启动生成新的访问令牌，经 Tauri 注入页面。前端只通过 HTTP 和 WebSocket 调用业务；
//! Tauri 只负责窗口、菜单等原生能力。

mod geometry;
mod logging;
mod window;
mod window_state;

use std::path::{Path, PathBuf};
use std::sync::Arc;

use dblens_api::{ApiConfig, new_token, router, serve, with_web};
use dblens_service::{Service, default_data_dir};
use tauri::Manager;

/// 前端页面目录，按顺序查找：
/// 1. 环境变量 `DBLENS_WEB_DIR`；
/// 2. 安装包中的资源目录 `web/`（打包在 M0-4d 中配置）；
/// 3. 调试构建时，源码树中的 `web/dist`。
fn web_dir(resource_dir: Option<PathBuf>) -> Option<PathBuf> {
    let dev = cfg!(debug_assertions).then(|| Path::new(env!("CARGO_MANIFEST_DIR")).join("../../web/dist"));
    std::env::var_os("DBLENS_WEB_DIR")
        .map(PathBuf::from)
        .into_iter()
        .chain(resource_dir.map(|d| d.join("web")))
        .chain(dev)
        .find(|d| d.join("index.html").is_file())
}

fn run(data_dir: PathBuf) -> Result<(), String> {
    let service = Arc::new(Service::open(&data_dir).map_err(|e| e.to_string())?);
    let token = new_token();
    // 先在当前线程绑定端口，窗口创建时地址已经确定
    let listener =
        std::net::TcpListener::bind("127.0.0.1:0").map_err(|e| format!("无法监听本机端口：{e}"))?;
    listener.set_nonblocking(true).map_err(|e| e.to_string())?;
    let addr = listener.local_addr().map_err(|e| e.to_string())?;
    let base = format!("http://{addr}/");
    tracing::info!("接口服务地址 {base}，数据目录 {}", data_dir.display());

    tauri::Builder::default()
        .plugin(tauri_plugin_global_shortcut::Builder::new().with_handler(window::on_shortcut).build())
        .setup(move |app| {
            let mut api = router(service, ApiConfig { token: token.clone(), allowed_origins: Vec::new() });
            match web_dir(app.path().resource_dir().ok()) {
                Some(dir) => {
                    tracing::info!("前端页面目录 {}", dir.display());
                    api = with_web(api, dir);
                }
                None => tracing::error!("没有找到前端页面（web/dist），请先在 web/ 下执行 pnpm build"),
            }
            tauri::async_runtime::spawn(async move {
                let result = match tokio::net::TcpListener::from_std(listener) {
                    Ok(l) => serve(l, api).await,
                    Err(e) => Err(e),
                };
                if let Err(e) = result {
                    tracing::error!("接口服务异常退出：{e}");
                }
            });
            window::create_main(app, &base, &token, data_dir.join("window.json"))?;
            Ok(())
        })
        .run(tauri::generate_context!())
        .map_err(|e| e.to_string())
}

/// 数据目录：环境变量 `DBLENS_DATA_DIR`（开发和测试时用，避免碰到真实数据）优先，否则用默认的用户数据目录。
fn data_dir() -> dblens_core::Result<PathBuf> {
    match std::env::var_os("DBLENS_DATA_DIR") {
        Some(d) => Ok(PathBuf::from(d)),
        None => default_data_dir(),
    }
}

fn main() {
    let data_dir = match data_dir() {
        Ok(d) => d,
        Err(e) => {
            eprintln!("{e}");
            std::process::exit(1);
        }
    };
    let _guard = match logging::init(&data_dir.join("logs")) {
        Ok(g) => Some(g),
        Err(e) => {
            eprintln!("日志初始化失败：{e}");
            None
        }
    };
    tracing::info!("DBLens {} 启动", env!("CARGO_PKG_VERSION"));
    if let Err(e) = run(data_dir) {
        tracing::error!("启动失败：{e}");
        std::process::exit(1);
    }
}

| 场景 | 步骤 |
|---|---|
| 浏览器模式 | `cd web && pnpm install && pnpm build`；`cargo run -p dblens-server -- --web-dir web/dist`；打开它打印的"在浏览器中打开"链接 |
| 前端开发（热更新） | `cargo run -p dblens-server -- --allow-origin http://localhost:5173`；`cd web && pnpm dev`；打开 server 打印的链接，把其中的 `http://127.0.0.1:8742` 换成 `http://localhost:5173` |
| 桌面 | 先在 `web/` 下 `pnpm build`，再 `cargo run -p dblens-desktop` |

桌面程序可用的环境变量（开发和测试用）：

- `DBLENS_DATA_DIR`：数据目录，默认是用户数据目录下的 `DBLens`（Windows 为 `%APPDATA%\DBLens`）。
- `DBLENS_WEB_DIR`：前端页面目录。不设时依次找安装包资源目录下的 `web/`、调试构建时源码树中的 `web/dist`。

## 架构要点

- 前端页面由接口服务同源提供（`dblens_api::with_web`），前端调用接口不涉及跨域，接口不需要 CORS。
  - 静态文件不需要令牌，`/api` 下的接口仍然需要。
  - 没有扩展名的路径找不到文件时返回 `index.html`（单页应用）。`/api` 下不存在的路径一律 404。
- 令牌：
  - 桌面模式：Tauri 的初始化脚本在页面脚本运行前设置 `window.__DBLENS__.token`。窗口只允许停留在接口服务的地址下，防止令牌被注入其他网站的页面。
  - 浏览器模式：`dblens-server` 打印的链接带 `#token=…`。`#` 后面的内容不会发给服务器，也不会出现在访问日志和 Referer 中。前端取出后存进 sessionStorage，并从地址栏去掉。
- 桌面程序不用 Tauri IPC，前端里也没有 Tauri 相关代码。窗口置顶、恢复默认位置都走原生菜单和系统热键。

## 窗口行为（设计文档 7.2 节）

| 行为 | 实现 |
|---|---|
| 默认大小 | 主屏幕工作区内居中，1440×900 逻辑像素；某个方向放不下时，这个方向取工作区的 90%；最小 1024×640 |
| 主题 | 页面跟随系统的亮色/暗色（`prefers-color-scheme`），切换系统主题时实时生效；标题栏由系统绘制，同样跟随 |
| 置顶 | 菜单"窗口 → 窗口置顶"，快捷键 Ctrl+Shift+T |
| 恢复默认 | 菜单"窗口 → 恢复默认窗口位置和大小" |
| 记住状态 | 数据目录下的 `window.json`：未最大化时的位置和大小、是否最大化、是否置顶。允许开头有 BOM |
| 拉回 | 保存的标题栏没有至少 100×20 像素落在某个显示器的工作区内时，启动时改用主屏幕的默认位置 |

以上在 Windows 11（2560×1600，100% 缩放）上逐项实测通过。实测中发现两个问题，都已处理：

- **菜单快捷键在页面有焦点时不触发。** WebView2 运行在单独的进程里，按键不经过窗口的消息循环。改用系统热键（`tauri-plugin-global-shortcut`），窗口获得焦点时注册、失去焦点时注销，所以不影响其他程序。
  - 不用 Ctrl+Alt+T：它在 Linux 桌面上是打开终端的系统快捷键。
- **最大化时会误记位置。** 移动、缩放事件比"已最大化"标志先到，立即记录会把最大化后的大小当成普通大小。改为最后一次事件后 300ms 再记录，退出时再同步记录一次。
