# M0-4d 打包与更新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 桌面版打成各平台安装包，Windows 为 NSIS，按当前用户安装；接入 Tauri updater 自动更新，并给出签名密钥与发布流程；`dblens-server` 提示新版本；CI 发布矩阵。

**Architecture:**
- 打包：
  - `tauri.conf.json` 开启 bundle，各平台的产物写在 `tauri.<平台>.conf.json`；
  - 把 `web/dist` 打进安装包的配置单独放在 `tauri.bundle.json`，只在 `tauri build` 时传入，普通的 `cargo build` 不受影响。
- 更新：
  - 桌面程序启动后在后台读取 `latest.json`，用原生对话框提示，确认后下载、校验签名、安装、重启；
  - 菜单"帮助"中可以手动检查、关闭自动检查；
  - 数据目录下的 `update.json` 可以把更新源改成内网地址。
- 发布：推送 `v*` 标签后，CI 构建各平台安装包和 `dblens-server`，生成带 `latest.json` 的草稿 Release，人工检查后发布。

**Tech Stack:**
- tauri-plugin-updater 2.14.0、tauri-plugin-dialog 2.8.3；
- @tauri-apps/cli 2.12.4（NSIS 由 Tauri 自动下载）；
- reqwest 0.13.5、semver 1.0.28（dblens-server 检查新版本）；
- tauri-apps/tauri-action（CI）。

**Spec:** `docs/superpowers/specs/2026-10-22-dblens-design.md` 第 10 节（打包、发布与更新）。前置：M0-4c（`docs/notes/m0-4c-desktop.md`）。

### Task 1: MySQL 驱动在使用 TLS 前安装默认加密实现

**Files:**
- Modify: `crates/dblens-driver-mysql/Cargo.toml`
- Modify: `crates/dblens-driver-mysql/src/lib.rs`

**为什么先做：**
- Task 4 引入的更新插件依赖 rustls 的 ring 实现，工作区里原有的是 aws-lc-rs。两种实现都编进同一个程序后，rustls 选不出进程级默认实现。
- mysql_async 用 `ClientConfig::builder()` 建 TLS 连接，依赖默认实现，这时会直接 panic（实测：在全工作区测试中，MySQL 的 TLS 实库测试必现）。
- PG 驱动显式指定了实现，不受影响。

**Interfaces:**
- Produces: 驱动内部函数 `ensure_crypto_provider()`。`ssl_opts` 在 TLS 模式下会先调用它，对外接口不变。

- [ ] **Step 1: 写失败的测试**

`crates/dblens-driver-mysql/Cargo.toml` 的 `[dependencies]` 中加 `rustls.workspace = true`（测试要用到 `rustls::crypto::CryptoProvider`）。然后在 `src/lib.rs` 末尾追加：

```rust

        assert!(ssl_opts(&TlsMode::Disable).is_none());
        assert!(ssl_opts(&TlsMode::Require).is_some());
        assert!(rustls::crypto::CryptoProvider::get_default().is_some(), "建 TLS 连接前已有进程级默认实现");
```

Expected: FAIL，报"建 TLS 连接前已有进程级默认实现"。

- [ ] **Step 3: 实现**

把 `ssl_opts` 的文档注释和函数开头（到 `match mode {` 为止）替换为：

```rust
/// mysql_async 使用 rustls 的进程级默认加密实现。同一个程序里同时编进了 aws-lc-rs 和 ring 时（桌面版的更新插件用 ring），
/// rustls 无法自动选择，建 TLS 连接时会直接 panic。所以用 TLS 之前先装上 aws-lc-rs；已经有默认实现时保持不变。
fn ensure_crypto_provider() {
    let _ = rustls::crypto::aws_lc_rs::default_provider().install_default();
}

/// TLS 选项：`require` 只加密不校验证书；`verify` 校验证书链和主机名，`tls_ca` 为额外信任的 CA 证书。
/// 取消查询时另开的连接沿用同一份选项。
fn ssl_opts(mode: &TlsMode) -> Option<SslOpts> {
    if !matches!(mode, TlsMode::Disable) {
        ensure_crypto_provider();
    }
```

```rust
//! 数据目录下的小型 JSON 设置文件（窗口状态、更新设置等）的读写。

use std::path::Path;

use serde::Serialize;
use serde::de::DeserializeOwned;

/// 读取设置。文件不存在或内容损坏时用默认值（损坏时记一条警告），不影响启动。
/// 允许开头有 UTF-8 BOM（用记事本等工具改过的文件）。
pub fn load<T: DeserializeOwned + Default>(path: &Path) -> T {
    match std::fs::read(path) {
        Ok(bytes) => serde_json::from_slice(bytes.strip_prefix(b"\xEF\xBB\xBF").unwrap_or(&bytes))
            .unwrap_or_else(|e| {
                tracing::warn!("设置文件 {} 无法解析，改用默认值：{e}", path.display());
                T::default()
            }),
        Err(_) => T::default(),
    }
}

/// 先写临时文件再改名，避免写到一半退出时留下损坏的文件。
pub fn save<T: Serialize>(path: &Path, value: &T) -> std::io::Result<()> {
    let tmp = path.with_extension("json.tmp");
    std::fs::write(&tmp, serde_json::to_vec_pretty(value)?)?;
    std::fs::rename(&tmp, path)
}

#[cfg(test)]
mod tests {
    use serde::Deserialize;

    use super::*;

    #[derive(Debug, Default, PartialEq, Serialize, Deserialize)]
    #[serde(default)]
    struct Demo {
        a: bool,
        b: Option<String>,
    }

    #[test]
    fn round_trip_and_fallbacks() {
        let dir = tempfile::tempdir().unwrap();
        let path = dir.path().join("demo.json");
        assert_eq!(load::<Demo>(&path), Demo::default(), "文件不存在");

        let v = Demo { a: true, b: Some("x".into()) };
        save(&path, &v).unwrap();
        assert_eq!(load::<Demo>(&path), v);
        save(&path, &Demo::default()).unwrap();
        assert_eq!(load::<Demo>(&path), Demo::default(), "覆盖保存");

        std::fs::write(&path, "\u{feff}{\"a\": true}").unwrap();
        assert_eq!(load::<Demo>(&path), Demo { a: true, b: None }, "带 BOM、缺少的字段取默认值");
        std::fs::write(&path, "{ broken").unwrap();
        assert_eq!(load::<Demo>(&path), Demo::default(), "内容损坏");
    }
}
```

`crates/dblens-desktop/src/window_state.rs`：

```rust
//! 窗口状态的保存与读取：数据目录下的 `window.json`。

use std::path::Path;

use serde::{Deserialize, Serialize};

use crate::geometry::Rect;
use crate::json_file;

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct WindowState {
    /// 未最大化时的位置和大小；`None` 表示用默认位置。
    pub rect: Option<Rect>,
    pub maximized: bool,
    pub always_on_top: bool,
}

/// 读取保存的状态。文件不存在或内容损坏时用默认状态，见 `json_file::load`。
pub fn load(path: &Path) -> WindowState {
    json_file::load(path)
}

pub fn save(path: &Path, state: &WindowState) -> std::io::Result<()> {
    json_file::save(path, state)
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn round_trip_and_fallbacks() {
        let dir = tempfile::tempdir().unwrap();
        let path = dir.path().join("window.json");
        assert_eq!(load(&path), WindowState::default(), "文件不存在");

        let s = WindowState {
            rect: Some(Rect { x: -1200, y: 50, width: 1440, height: 900 }),
            maximized: true,
            always_on_top: true,
        };
        save(&path, &s).unwrap();
        assert_eq!(load(&path), s);
        save(&path, &WindowState::default()).unwrap();
        assert_eq!(load(&path), WindowState::default(), "覆盖保存");

        std::fs::write(&path, "\u{feff}{\"maximized\": true}").unwrap();
        assert_eq!(load(&path), WindowState { maximized: true, ..Default::default() }, "带 BOM");
        std::fs::write(&path, "{ broken").unwrap();
        assert_eq!(load(&path), WindowState::default(), "内容损坏");
        std::fs::write(&path, r#"{"always_on_top": true}"#).unwrap();
        assert_eq!(
            load(&path),
            WindowState { always_on_top: true, ..Default::default() },
            "缺少的字段取默认值"
        );
    }
}
```

- Modify: `web/package.json`、`web/pnpm-lock.yaml`

**Interfaces:**
- Produces（Task 4、Task 6 使用）：
  - `pnpm --dir web tauri <参数>`：在仓库根运行 Tauri CLI；
  - `pnpm --dir web package`：本地打包。
  - 产物输出到 `target/release/bundle/`。Windows 上是 `nsis/DBLens_<版本>_x64-setup.exe`，装好后主程序为 `DBLens.exe`，资源目录下有 `web/`。

要点：
- **CLI 必须从仓库根目录运行。** Tauri CLI 从当前目录往下找 `tauri.conf.json`，在 `web/` 下运行找不到（实测）。所以 `web/package.json` 的脚本先 `cd ..`。
- **`web/dist` 的资源配置单独放。** `bundle.resources` 写进 `tauri.conf.json` 的话，`tauri-build` 在普通 `cargo build` 时也会检查 `web/dist` 是否存在，没构建过前端时 `cargo test --workspace` 就会失败。所以单独放在 `tauri.bundle.json`，只由 `pnpm package` 传入。这时 `beforeBuildCommand` 已经构建好前端。
- **只在 Windows 上改主程序名。** `mainBinaryName` 只写在 Windows 配置里，Linux 上按惯例保留小写的 `dblens-desktop`。

```rust
//! 自动更新（设计文档第 10 节）：
//! - 启动后在后台检查更新源（静态的 `latest.json`）；有新版本时提示版本号和更新说明，用户确认后下载、校验签名、安装、重启。
//! - 菜单"帮助"中可以手动检查，也可以关闭启动时的自动检查。
//! - 更新源默认是 GitHub Releases；数据目录下的 `update.json` 可以改成内网地址。
//! - Linux 上只有 AppImage 能自动安装；deb、rpm 只提示新版本，由用户自己下载。
//!
//! 更新包用 updater 自带的密钥对签名，公钥在 `tauri.conf.json` 中，私钥只在发布时使用（见 `docs/notes/m0-4d-release.md`）。

use std::path::PathBuf;
use std::sync::Mutex;
use std::time::Duration;

use serde::{Deserialize, Serialize};
use tauri::menu::{CheckMenuItem, CheckMenuItemBuilder, MenuItemBuilder, Submenu, SubmenuBuilder};
use tauri::{App, AppHandle, Manager, Wry};
use tauri_plugin_dialog::{DialogExt, MessageDialogButtons, MessageDialogKind};
use tauri_plugin_updater::{Update, UpdaterExt};

use crate::json_file;

/// 发布页，Linux 的 deb、rpm 包从这里手动下载新版本。
pub const RELEASES_PAGE: &str = "https://github.com/byteswalk/dblens/releases";
const MENU_CHECK: &str = "check_update";
const MENU_AUTO: &str = "auto_check_update";
const MENU_ABOUT: &str = "about";
/// 启动后等这么久再自动检查，不和启动抢资源。
const STARTUP_DELAY: Duration = Duration::from_secs(5);
const TIMEOUT: Duration = Duration::from_secs(30);

/// 数据目录下的 `update.json`。
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct UpdateSettings {
    /// 启动后在后台检查更新。
    pub auto_check: bool,
    /// 更新源（`latest.json` 的地址）。为空时用 `tauri.conf.json` 中的默认地址；内网部署时改成内网地址。
    pub endpoint: Option<String>,
}

impl Default for UpdateSettings {
    fn default() -> Self {
        Self { auto_check: true, endpoint: None }
    }
}

/// 当前的安装方式能否自动安装更新：Windows（NSIS）和 macOS 可以；Linux 上只有 AppImage 可以。
pub fn can_self_update(os: &str, appimage: bool) -> bool {
    os != "linux" || appimage
}

/// 发现新版本时的提示文字。
pub fn offer_text(version: &str, current: &str, notes: Option<&str>, self_update: bool) -> String {
    let mut text = format!("发现新版本 {version}（当前 {current}）。");
    if let Some(notes) = notes.map(str::trim).filter(|n| !n.is_empty()) {
        text.push_str("\n\n更新说明：\n");
        text.push_str(notes);
    }
    if self_update {
        text.push_str("\n\n现在下载并安装吗？安装完成后程序会自动重启。");
    } else {
        text.push_str(&format!("\n\n请到 {RELEASES_PAGE} 下载新版本。"));
    }
    text
}

/// 把更新插件的英文错误转成给用户看的说明，原文附在后面便于排查。
pub fn error_text(err: &str) -> String {
    let lower = err.to_lowercase();
    let hint = if lower.contains("signature") {
        "安装包签名校验失败，已取消安装。安装包可能被篡改，或更新源提供的签名不对"
    } else if lower.contains("secure protocol") {
        "更新源必须使用 https 地址"
    } else if lower.contains("could not fetch")
        || lower.contains("error sending request")
        || lower.contains("timed out")
    {
        "无法连接更新源，请检查网络或 update.json 中的地址"
    } else {
        return err.to_string();
    };
    format!("{hint}（{err}）")
}

struct UpdateState {
    path: PathBuf,
    settings: Mutex<UpdateSettings>,
    auto_item: CheckMenuItem<Wry>,
}

/// 弹出消息框，等用户关闭后返回是否点了确认按钮。
async fn dialog(
    app: &AppHandle,
    kind: MessageDialogKind,
    text: String,
    buttons: MessageDialogButtons,
) -> bool {
    let (tx, rx) = tokio::sync::oneshot::channel();
    app.dialog().message(text).title("DBLens 数洞").kind(kind).buttons(buttons).show(move |ok| {
        let _ = tx.send(ok);
    });
    rx.await.unwrap_or(false)
}

async fn info(app: &AppHandle, text: String) {
    dialog(app, MessageDialogKind::Info, text, MessageDialogButtons::Ok).await;
}

async fn find_update(app: &AppHandle) -> Result<Option<Update>, String> {
    let endpoint = app.state::<UpdateState>().settings.lock().unwrap().endpoint.clone();
    let mut builder = app.updater_builder().timeout(TIMEOUT);
    if let Some(e) = endpoint.filter(|e| !e.trim().is_empty()) {
        let url = e.trim().parse().map_err(|err| format!("update.json 中的更新源地址无效（{e}）：{err}"))?;
        builder = builder.endpoints(vec![url]).map_err(|err| err.to_string())?;
    }
    builder.build().map_err(|e| e.to_string())?.check().await.map_err(|e| e.to_string())
}

async fn install(app: &AppHandle, update: Update) -> Result<(), String> {
    let mut downloaded = 0usize;
    let mut last_logged = 0usize;
    update
        .download_and_install(
            |chunk, total| {
                downloaded += chunk;
                if downloaded - last_logged >= 10 * 1024 * 1024 {
                    last_logged = downloaded;
                    tracing::info!("已下载 {downloaded} / {total:?} 字节");
                }
            },
            || tracing::info!("下载完成，开始安装"),
        )
        .await
        .map_err(|e| e.to_string())?;
    tracing::info!("更新已安装，重启");
    app.restart()
}

/// 检查更新。`manual` 为 true 表示用户从菜单发起：没有新版本或出错时也要告诉用户；自动检查出错只记日志。
pub async fn check(app: AppHandle, manual: bool) {
    let update = match find_update(&app).await {
        Ok(u) => u,
        Err(e) => {
            tracing::warn!("检查更新失败：{e}");
            if manual {
                dialog(
                    &app,
                    MessageDialogKind::Error,
                    format!("检查更新失败：{}", error_text(&e)),
                    MessageDialogButtons::Ok,
                )
                .await;
            }
            return;
        }
    };
    let Some(update) = update else {
        tracing::info!("已是最新版本");
        if manual {
            info(&app, format!("已是最新版本（{}）。", app.package_info().version)).await;
        }
        return;
    };
    tracing::info!("发现新版本 {}（当前 {}）", update.version, update.current_version);
    let self_update = can_self_update(std::env::consts::OS, std::env::var_os("APPIMAGE").is_some());
    let text = offer_text(&update.version, &update.current_version, update.body.as_deref(), self_update);
    if !self_update {
        info(&app, text).await;
        return;
    }
    let buttons = MessageDialogButtons::OkCancelCustom("下载并安装".into(), "以后再说".into());
    if !dialog(&app, MessageDialogKind::Info, text, buttons).await {
        return;
    }
    if let Err(e) = install(&app, update).await {
        tracing::error!("安装更新失败：{e}");
        let text = format!("安装更新失败：{}", error_text(&e));
        dialog(&app, MessageDialogKind::Error, text, MessageDialogButtons::Ok).await;
    }
}

/// 读取更新设置，生成"帮助"菜单；开启了自动检查时，启动后在后台检查一次。
pub fn init(app: &App, path: PathBuf) -> tauri::Result<Submenu<Wry>> {
    let settings: UpdateSettings = json_file::load(&path);
    let auto_item = CheckMenuItemBuilder::with_id(MENU_AUTO, "启动时自动检查更新")
        .checked(settings.auto_check)
        .build(app)?;
    let menu = SubmenuBuilder::new(app, "帮助")
        .item(&MenuItemBuilder::with_id(MENU_CHECK, "检查更新…").build(app)?)
        .item(&auto_item)
        .separator()
        .item(&MenuItemBuilder::with_id(MENU_ABOUT, "关于 DBLens").build(app)?)
        .build()?;
    if settings.auto_check {
        let handle = app.handle().clone();
        tauri::async_runtime::spawn(async move {
            tokio::time::sleep(STARTUP_DELAY).await;
            check(handle, false).await;
        });
    }
    app.manage(UpdateState { path, settings: Mutex::new(settings), auto_item });
    Ok(menu)
}

/// 处理"帮助"菜单的事件；不是这个菜单的事件返回 false。
pub fn on_menu(app: &AppHandle, id: &str) -> bool {
    match id {
        MENU_CHECK => {
            tauri::async_runtime::spawn(check(app.clone(), true));
        }
        MENU_AUTO => {
            let state = app.state::<UpdateState>();
            let mut s = state.settings.lock().unwrap();
            // 点击时菜单项已自动切换了勾选状态
            s.auto_check = state.auto_item.is_checked().unwrap_or(s.auto_check);
            if let Err(e) = json_file::save(&state.path, &*s) {
                tracing::warn!("无法保存更新设置到 {}：{e}", state.path.display());
            }
        }
        MENU_ABOUT => {
            let text = format!("DBLens 数洞 {}\n\n{RELEASES_PAGE}", app.package_info().version);
            let app = app.clone();
            tauri::async_runtime::spawn(async move { info(&app, text).await });
        }
        _ => return false,
    }
    true
}
```

```rust
//! 主窗口（设计文档 7.2 节）：
//! - 首次启动 1440×900 居中，屏幕小时取工作区的 90%，最小 1024×640；
//! - 菜单"窗口"里有"窗口置顶"（Ctrl+Shift+T）和"恢复默认窗口位置和大小"；
//! - 退出时保存位置、大小、是否最大化和置顶状态；保存的位置已不在任何显示器上时，改用主屏幕的默认位置。
//!
//! 页面由进程内的接口服务提供（与 `/api` 同源）。访问令牌经初始化脚本注入页面；
//! 窗口只允许停留在这个地址下，防止令牌被注入到其他网站的页面中。
//!
//! 快捷键：Windows 上键盘焦点在页面（WebView2）里时，按键不经过窗口的消息循环，菜单快捷键不会触发（实测）。
//! 所以置顶快捷键用系统热键实现，只在窗口获得焦点时注册、失去焦点时注销，不影响其他程序。

use std::path::PathBuf;
use std::sync::Mutex;
use std::sync::atomic::{AtomicU64, Ordering};
use std::time::Duration;

use tauri::menu::{
    CheckMenuItem, CheckMenuItemBuilder, MenuBuilder, MenuItemBuilder, Submenu, SubmenuBuilder,
};
use tauri::{
    App, AppHandle, Manager, PhysicalPosition, PhysicalSize, WebviewUrl, WebviewWindow, WebviewWindowBuilder,
    WindowEvent, Wry,
};
use tauri_plugin_global_shortcut::{GlobalShortcutExt, Shortcut, ShortcutEvent, ShortcutState};

use crate::geometry::{self, MIN_SIZE, Rect};
use crate::update;
use crate::window_state::{self, WindowState};

const MAIN: &str = "main";
const MENU_ON_TOP: &str = "always_on_top";
const MENU_RESET: &str = "reset_window";
const MENU_QUIT: &str = "quit";
/// "窗口置顶"的快捷键。没有用 Ctrl+Alt+T：它在 Linux 桌面上是打开终端的系统快捷键。
pub const ON_TOP_SHORTCUT: &str = "CmdOrCtrl+Shift+T";

/// 移动、缩放后等这么久再记录位置：最大化时移动和缩放事件先于"已最大化"标志到达，立即记录会把最大化后的大小当成普通大小。
const SETTLE: Duration = Duration::from_millis(300);

/// 运行期间的窗口状态，退出时写回文件。
struct Tracked {
    path: PathBuf,
    state: Mutex<WindowState>,
    on_top: CheckMenuItem<tauri::Wry>,
    /// 每次移动、缩放加一；延迟记录时编号已变，说明之后又有新事件，这次就不记了。
    generation: AtomicU64,
}

/// 页面脚本运行前执行的初始化脚本：注入访问令牌。
pub fn init_script(token: &str) -> String {
    format!("window.__DBLENS__ = Object.freeze({{ token: {} }});", serde_json::Value::from(token))
}

/// 窗口只能停留在接口服务的地址下（`base` 形如 `http://127.0.0.1:端口/`）。
pub fn allowed_navigation(base: &str, url: &str) -> bool {
    url.starts_with(base)
}

fn on_top_shortcut() -> Shortcut {
    ON_TOP_SHORTCUT.parse().expect("快捷键格式")
}

fn to_rect(p: PhysicalPosition<i32>, s: PhysicalSize<u32>) -> Rect {
    Rect { x: p.x, y: p.y, width: s.width, height: s.height }
}

fn apply_rect(win: &WebviewWindow, r: Rect) -> tauri::Result<()> {
    win.set_size(PhysicalSize::new(r.width, r.height))?;
    win.set_position(PhysicalPosition::new(r.x, r.y))
}

/// 主屏幕（取不到时用窗口当前所在的屏幕）上的默认位置和大小。
fn default_rect(win: &WebviewWindow) -> tauri::Result<Option<Rect>> {
    let monitor = match win.primary_monitor()? {
        Some(m) => Some(m),
        None => win.current_monitor()?,
    };
    Ok(monitor.map(|m| {
        let a = m.work_area();
        geometry::default_rect(to_rect(a.position, a.size), m.scale_factor())
    }))
}

fn reset(win: &WebviewWindow) -> tauri::Result<()> {
    win.unmaximize()?;
    if let Some(r) = default_rect(win)? {
        apply_rect(win, r)?;
    }
    Ok(())
}

/// 记下未最大化、未最小化时的位置和大小，作为下次启动的位置。
fn remember(win: &WebviewWindow, tracked: &Tracked) -> tauri::Result<()> {
    if win.is_maximized()? || win.is_minimized()? {
        return Ok(());
    }
    let r = to_rect(win.outer_position()?, win.inner_size()?);
    tracked.state.lock().unwrap().rect = Some(r);
    Ok(())
}

/// 移动、缩放后延迟记录位置，连续的事件只记最后一次。
fn remember_later(win: &WebviewWindow) {
    let generation = win.state::<Tracked>().generation.fetch_add(1, Ordering::SeqCst) + 1;
    let win = win.clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(SETTLE).await;
        let tracked = win.state::<Tracked>();
        if tracked.generation.load(Ordering::SeqCst) == generation {
            let _ = remember(&win, &tracked);
        }
    });
}

fn save(win: &WebviewWindow, tracked: &Tracked) {
    // 退出时状态已稳定，补记一次，免得最后一次移动还没来得及记录
    let _ = remember(win, tracked);
    let mut s = *tracked.state.lock().unwrap();
    s.maximized = win.is_maximized().unwrap_or(false);
    s.always_on_top = tracked.on_top.is_checked().unwrap_or(false);
    if let Err(e) = window_state::save(&tracked.path, &s) {
        tracing::warn!("无法保存窗口状态到 {}：{e}", tracked.path.display());
    }
}

/// 按菜单项的勾选状态设置置顶。
fn apply_on_top(app: &AppHandle) -> tauri::Result<()> {
    if let Some(win) = app.get_webview_window(MAIN) {
        win.set_always_on_top(app.state::<Tracked>().on_top.is_checked()?)?;
    }
    Ok(())
}

/// 快捷键：翻转菜单项的勾选状态，再按它设置置顶。
pub fn on_shortcut(app: &AppHandle, shortcut: &Shortcut, event: ShortcutEvent) {
    if event.state != ShortcutState::Pressed || *shortcut != on_top_shortcut() {
        return;
    }
    let item = &app.state::<Tracked>().on_top;
    let result = item.is_checked().and_then(|c| item.set_checked(!c)).and_then(|()| apply_on_top(app));
    if let Err(e) = result {
        tracing::warn!("切换窗口置顶失败：{e}");
    }
}

fn on_menu(app: &AppHandle, id: &str) -> tauri::Result<()> {
    if update::on_menu(app, id) {
        return Ok(());
    }
    let Some(win) = app.get_webview_window(MAIN) else { return Ok(()) };
    match id {
        // 点击时菜单项已自动切换了勾选状态
        MENU_ON_TOP => apply_on_top(app)?,
        MENU_RESET => reset(&win)?,
        MENU_QUIT => {
            save(&win, &app.state::<Tracked>());
            app.exit(0);
        }
        _ => {}
    }
    Ok(())
}

/// 窗口获得焦点时注册快捷键，失去焦点时注销。注册失败（被其他程序占用）只记日志，菜单仍可用。
fn focus_changed(app: &AppHandle, focused: bool) {
    let gs = app.global_shortcut();
    let shortcut = on_top_shortcut();
    let result = if focused {
        if gs.is_registered(shortcut) { Ok(()) } else { gs.register(shortcut) }
    } else if gs.is_registered(shortcut) {
        gs.unregister(shortcut)
    } else {
        Ok(())
    };
    if let Err(e) = result {
        tracing::warn!("快捷键 {ON_TOP_SHORTCUT} {}失败：{e}", if focused { "注册" } else { "注销" });
    }
}

/// 创建主窗口：恢复保存的状态，注入令牌，挂上菜单（"窗口"和 `help`）和窗口事件。
pub fn create_main(
    app: &App,
    base: &str,
    token: &str,
    state_path: PathBuf,
    help: &Submenu<Wry>,
) -> tauri::Result<()> {
    let saved = window_state::load(&state_path);
    let on_top = CheckMenuItemBuilder::with_id(MENU_ON_TOP, "窗口置顶")
        .checked(saved.always_on_top)
        .accelerator(ON_TOP_SHORTCUT)
        .build(app)?;
    let window_menu = SubmenuBuilder::new(app, "窗口")
        .item(&on_top)
        .item(&MenuItemBuilder::with_id(MENU_RESET, "恢复默认窗口位置和大小").build(app)?)
        .separator()
        .item(&MenuItemBuilder::with_id(MENU_QUIT, "退出").build(app)?)
        .build()?;
    let menu = MenuBuilder::new(app).item(&window_menu).item(help).build()?;

    let allowed = base.to_string();
    let win = WebviewWindowBuilder::new(app, MAIN, WebviewUrl::External(base.parse().expect("接口地址")))
        .title("DBLens 数洞")
        .menu(menu)
        .min_inner_size(MIN_SIZE.0, MIN_SIZE.1)
        .visible(false)
        .initialization_script(init_script(token))
        .on_navigation(move |url| {
            let ok = allowed_navigation(&allowed, url.as_str());
            if !ok {
                tracing::warn!("已阻止窗口跳转到 {url}");
            }
            ok
        })
        .build()?;

    let work_areas: Vec<Rect> = win
        .available_monitors()?
        .iter()
        .map(|m| to_rect(m.work_area().position, m.work_area().size))
        .collect();
    match saved.rect {
        Some(r) if geometry::is_reachable(r, &work_areas) => apply_rect(&win, r)?,
        Some(r) => {
            tracing::info!("保存的窗口位置 {r:?} 已不在任何显示器上，移回主屏幕");
            reset(&win)?;
        }
        None => reset(&win)?,
    }
    if saved.maximized {
        win.maximize()?;
    }
    win.set_always_on_top(saved.always_on_top)?;
    win.show()?;

    let tracked =
        Tracked { path: state_path, state: Mutex::new(saved), on_top, generation: AtomicU64::new(0) };
    remember(&win, &tracked)?;
    app.manage(tracked);
    app.on_menu_event(|app, event| {
        if let Err(e) = on_menu(app, event.id().as_ref()) {
            tracing::warn!("菜单操作失败：{e}");
        }
    });
    let w = win.clone();
    win.on_window_event(move |event| {
        let tracked = w.state::<Tracked>();
        match event {
            WindowEvent::Moved(_) | WindowEvent::Resized(_) => remember_later(&w),
            WindowEvent::Focused(focused) => focus_changed(w.app_handle(), *focused),
            WindowEvent::CloseRequested { .. } => save(&w, &tracked),
            _ => {}
        }
    });
    Ok(())
}
```

```rust
/// 前端页面目录，按顺序查找：
/// 1. 环境变量 `DBLENS_WEB_DIR`；
/// 2. 安装包中的资源目录 `web/`（打包在 M0-4d 中配置）；

fn web_dir(resource_dir: Option<PathBuf>) -> Option<PathBuf> {
    let dev = cfg!(debug_assertions).then(|| Path::new(env!("CARGO_MANIFEST_DIR")).join("../../web/dist"));
    std::env::var_os("DBLENS_WEB_DIR")
        .map(PathBuf::from)
        .into_iter()
        .chain(resource_dir.map(|d| d.join("web")))
        .chain(dev)
        .find(|d| d.join("index.html").is_file())
}

fn run(data_dir: PathBuf) -> Result<(), String> {
    let service = Arc::new(Service::open(&data_dir).map_err(|e| e.to_string())?);
    let token = new_token();
    // 先在当前线程绑定端口，窗口创建时地址已经确定
    let listener =
        std::net::TcpListener::bind("127.0.0.1:0").map_err(|e| format!("无法监听本机端口：{e}"))?;
    listener.set_nonblocking(true).map_err(|e| e.to_string())?;
    let addr = listener.local_addr().map_err(|e| e.to_string())?;
    let base = format!("http://{addr}/");
    tracing::info!("接口服务地址 {base}，数据目录 {}", data_dir.display());

    tauri::Builder::default()
        .plugin(tauri_plugin_global_shortcut::Builder::new().with_handler(window::on_shortcut).build())
        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_updater::Builder::new().build())
        .setup(move |app| {
            let mut api = router(service, ApiConfig { token: token.clone(), allowed_origins: Vec::new() });
            match web_dir(app.path().resource_dir().ok()) {
                Some(dir) => {
                    tracing::info!("前端页面目录 {}", dir.display());
                    api = with_web(api, dir);
                }
                None => tracing::error!("没有找到前端页面（web/dist），请先在 web/ 下执行 pnpm build"),
            }
            tauri::async_runtime::spawn(async move {
                let result = match tokio::net::TcpListener::from_std(listener) {
                    Ok(l) => serve(l, api).await,
                    Err(e) => Err(e),
                };
                if let Err(e) = result {
                    tracing::error!("接口服务异常退出：{e}");
                }
            });
            let help = update::init(app, data_dir.join("update.json"))?;
            window::create_main(app, &base, &token, data_dir.join("window.json"), &help)?;
            Ok(())
        })
        .run(tauri::generate_context!())
        .map_err(|e| e.to_string())
}

    }
}
```

```rust
//! 新版本提示（设计文档第 10 节）：浏览器模式的服务只提示有新版本，不会自动替换自己。
//! 读取的是桌面版同一个 `latest.json`，只用其中的 `version` 和 `notes`。

use std::time::Duration;

use serde::Deserialize;

/// 默认更新源，与桌面版 `tauri.conf.json` 中的相同。
pub const DEFAULT_URL: &str = "https://github.com/byteswalk/dblens/releases/latest/download/latest.json";
/// 发布页。
pub const RELEASES_PAGE: &str = "https://github.com/byteswalk/dblens/releases";

#[derive(Debug, Deserialize)]
struct Latest {
    version: String,
    #[serde(default)]
    notes: Option<String>,
}

/// 比 `current` 新的版本。版本号按语义化版本比较，允许带前缀 `v`。
fn newer(current: &str, latest: &str) -> Result<bool, String> {
    let parse = |v: &str| {
        semver::Version::parse(v.trim().trim_start_matches('v')).map_err(|e| format!("无效的版本号 {v}：{e}"))
    };
    Ok(parse(latest)? > parse(current)?)
}

/// 新版本的提示文字；`latest.json` 中的版本不比当前新时返回 `None`。
pub fn notice(current: &str, latest_json: &[u8]) -> Result<Option<String>, String> {
    let latest: Latest =
        serde_json::from_slice(latest_json).map_err(|e| format!("latest.json 格式不对：{e}"))?;
    if !newer(current, &latest.version)? {
        return Ok(None);
    }
    let mut text = format!("发现新版本 {}（当前 {current}），下载地址：{RELEASES_PAGE}", latest.version);
    if let Some(notes) = latest.notes.as_deref().map(str::trim).filter(|n| !n.is_empty()) {
        text.push_str("\n更新说明：");
        text.push_str(notes);
    }
    Ok(Some(text))
}

/// 读取更新源并返回提示文字。
pub async fn check(url: &str, current: &str) -> Result<Option<String>, String> {
    let client =
        reqwest::Client::builder().timeout(Duration::from_secs(15)).build().map_err(|e| e.to_string())?;
    let resp = client.get(url).send().await.map_err(|e| format!("无法访问更新源 {url}：{e}"))?;
    if !resp.status().is_success() {
        return Err(format!("更新源 {url} 返回 {}", resp.status()));
    }
    let body = resp.bytes().await.map_err(|e| e.to_string())?;
    notice(current, &body)
}
```

//! 浏览器模式的服务入口（设计文档 4.1 节）。
//!
//! ```text
//! dblens-server [--listen 127.0.0.1:8742] [--data-dir 目录] [--web-dir 目录] [--allow-origin 来源]...
//!               [--update-url 地址] [--no-update-check]
//! ```
//!
//! 启动时生成一次访问令牌并打印出来，本次运行期间有效。首期只供单用户使用，多用户鉴权留给团队版。
//!
//! 前端页面默认取可执行文件旁边的 `web/` 目录；找不到时只提供接口，并在日志中提示。
//!
//! 启动后在后台检查一次新版本（默认读 GitHub Releases 的 `latest.json`，`--update-url` 可改成内网地址），
//! 有新版本时在日志中提示，不会自动替换自己。

use std::net::SocketAddr;
use std::path::PathBuf;
use std::sync::Arc;

use dblens_api::{ApiConfig, new_token, router, serve, with_web};
use dblens_service::{Service, default_data_dir};

mod update;

const DEFAULT_LISTEN: &str = "127.0.0.1:8742";

#[derive(Debug, PartialEq, Eq)]
struct Args {
    listen: SocketAddr,
    data_dir: Option<PathBuf>,
    web_dir: Option<PathBuf>,
    allowed_origins: Vec<String>,
    /// 更新源；`None` 表示不检查新版本。
    update_url: Option<String>,
}

const USAGE: &str = "用法：dblens-server [--listen 地址:端口] [--data-dir 目录] [--web-dir 目录] [--allow-origin 来源]... \n                     [--update-url 地址] [--no-update-check]";

fn parse_args(args: impl IntoIterator<Item = String>) -> Result<Args, String> {
    let mut out = Args {
        listen: DEFAULT_LISTEN.parse().unwrap(),
        data_dir: None,
        web_dir: None,
        allowed_origins: Vec::new(),
        update_url: Some(update::DEFAULT_URL.to_string()),
    };
    let mut no_update_check = false;
    let mut it = args.into_iter();
    while let Some(a) = it.next() {
        let mut value = |name: &str| it.next().ok_or_else(|| format!("{name} 后面缺少参数\n{USAGE}"));
        match a.as_str() {
            "--listen" => {
                let v = value("--listen")?;
                out.listen = v.parse().map_err(|_| format!("无效的监听地址：{v}"))?;
            }
            "--data-dir" => out.data_dir = Some(PathBuf::from(value("--data-dir")?)),
            "--web-dir" => out.web_dir = Some(PathBuf::from(value("--web-dir")?)),
            "--allow-origin" => out.allowed_origins.push(value("--allow-origin")?),
            "--update-url" => out.update_url = Some(value("--update-url")?),
            "--no-update-check" => no_update_check = true,
            "-h" | "--help" => return Err(USAGE.to_string()),
            other => return Err(format!("未知参数：{other}\n{USAGE}")),
        }
    }
    if no_update_check {
        out.update_url = None;
    }
    Ok(out)
}

/// 前端页面目录：命令行指定的优先，否则取可执行文件旁边的 `web/`。目录里没有 `index.html` 时返回 `None`。
fn resolve_web_dir(arg: Option<PathBuf>, exe: Option<PathBuf>) -> Option<PathBuf> {
    let dir = arg.or_else(|| exe?.parent().map(|p| p.join("web")))?;
    dir.join("index.html").is_file().then_some(dir)
}

#[tokio::main]
async fn main() {
    tracing_subscriber::fmt().with_writer(std::io::stderr).init();
    let args = match parse_args(std::env::args().skip(1)) {
        Ok(a) => a,
        Err(msg) => {
            eprintln!("{msg}");
            std::process::exit(2);
        }
    };
    if let Err(msg) = run(args).await {
        eprintln!("启动失败：{msg}");
        std::process::exit(1);
    }
}

async fn run(args: Args) -> Result<(), String> {
    let data_dir = match args.data_dir {
        Some(d) => d,
        None => default_data_dir().map_err(|e| e.to_string())?,
    };
    let service = Arc::new(Service::open(&data_dir).map_err(|e| e.to_string())?);
    let token = new_token();
    let listener = tokio::net::TcpListener::bind(args.listen)
        .await
        .map_err(|e| format!("无法监听 {}：{e}", args.listen))?;
    let addr = listener.local_addr().map_err(|e| e.to_string())?;
    if !addr.ip().is_loopback() {
        tracing::warn!("正在监听非本机地址 {addr}：同一网络中的其他人只要拿到访问令牌就能访问");
    }
    let web_dir = resolve_web_dir(args.web_dir, std::env::current_exe().ok());
    // 第一行是地址、第二行是令牌，便于脚本读取
    println!("DBLens 服务已启动：http://{addr}");
    println!("访问令牌：{token}");
    println!("数据目录：{}", data_dir.display());
    // 令牌放在 # 后面：浏览器不会把它发给服务器，也不会出现在访问日志和 Referer 中
    match &web_dir {
        Some(_) => println!("在浏览器中打开：http://{addr}/#token={token}"),
        None => tracing::warn!("没有找到前端页面目录（可用 --web-dir 指定），只提供接口"),
    }
    if let Some(url) = args.update_url {
        tokio::spawn(async move {
            match update::check(&url, env!("CARGO_PKG_VERSION")).await {
                Ok(Some(text)) => tracing::info!("{text}"),
                Ok(None) => tracing::info!("已是最新版本"),
                Err(e) => tracing::warn!("检查新版本失败：{e}"),
            }
        });
    }
    let mut app = router(service, ApiConfig { token, allowed_origins: args.allowed_origins });
    if let Some(dir) = web_dir {
        app = with_web(app, dir);
    }
    serve(listener, app).await.map_err(|e| e.to_string())
}

````markdown
# 打包、发布与更新（M0-4d）

## 产物

| 平台 | 产物 | 自动更新 |
|---|---|---|
| Windows x64 | `DBLens_<版本>_x64-setup.exe`（NSIS），按当前用户安装到 `%LOCALAPPDATA%\DBLens`，不需要管理员权限 | 支持 |
| macOS | 通用 dmg（Intel + Apple Silicon） | 支持 |
| Linux x64 | deb、rpm、AppImage | 只有 AppImage 支持；deb、rpm 只提示新版本 |
| Linux ARM64（信创） | deb | 只提示新版本 |
| 浏览器模式 | `dblens-server-<版本>-<目标平台>.zip/.tar.gz`（可执行文件 + `web/` 前端页面） | 只在日志中提示新版本 |

- 没有代码签名证书（设计文档第 10 节）：
  - Windows 首次运行时 SmartScreen 会提示"未知发布者"，要点"更多信息 → 仍要运行"；
  - macOS 要在"系统设置 → 隐私与安全性"中放行。
- 信创 LoongArch 留到发布阶段再落实。

## 更新签名密钥

更新包用 Tauri updater 自带的密钥对签名（minisign），与代码签名证书无关，免费。

- 公钥写在 `crates/dblens-desktop/tauri.conf.json` 的 `plugins.updater.pubkey`，随程序发布。
- 私钥只在发布时由 CI 使用。

**私钥丢失或密码遗忘的后果**：已经发出去的版本再也收不到自动更新，只能让用户手动下载安装新版本（新版本换用新密钥）。所以私钥和密码必须离线备份。

### 生成（只做一次）

在仓库根目录执行：

```bash
pnpm --dir web tauri signer generate -w "<私钥保存路径>"
```

私钥保存路径写绝对路径，如 `C:\Users\<用户名>\.tauri\dblens-updater.key`。pnpm 在 Windows 上用 cmd 执行脚本，cmd 不会展开 `~`。

- 按提示设置密码，生成两个文件：私钥 `dblens-updater.key` 和公钥 `dblens-updater.key.pub`。
- 把 `.pub` 文件的内容（一整行 base64）填进 `tauri.conf.json` 的 `pubkey` 并提交。
- 私钥文件绝不提交到仓库。

### 备份

- 私钥文件：至少两份离线备份，例如加密 U 盘和密码管理器的附件，存放在不同地方。
- 密码：存进密码管理器，不要和私钥文件放在同一个地方。
- 每次大版本发布前，确认备份能读出来。

### 配置到 GitHub

仓库 `byteswalk/dblens` → Settings → Secrets and variables → Actions，新建两个 secret：

- `TAURI_SIGNING_PRIVATE_KEY`：私钥文件的全部内容；
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`：私钥密码。

## 发布流程

1. 改版本号：
   - 根 `Cargo.toml` 的 `[workspace.package] version`，桌面程序和 `dblens-server` 都用它；
   - `web/package.json` 的 `version` 保持一致。
2. 写发布说明 `docs/releases/v<版本>.md`。
   - CI 会把它写进 Release 正文和 `latest.json` 的 `notes`，客户端提示更新时会显示；
   - 写给用户看，简短列出变化。
3. 提交后打标签并推送：

   ```bash
   git tag v<版本>
   git push origin v<版本>
   ```

4. `release` 工作流（`.github/workflows/release.yml`）：
   - 先检查标签与版本号一致、发布说明存在；
   - 再构建各平台安装包和 `dblens-server`，生成**草稿** Release，附带 `latest.json` 和每个更新包的 `.sig` 签名。
5. 在 GitHub 上检查草稿：安装包齐全，`latest.json` 中有各平台的地址和签名。然后点 Publish。
   - **发布之前客户端看不到新版本**：更新源 `…/releases/latest/download/latest.json` 只指向已发布的最新 Release。
6. 验证：用上一版本的程序点"帮助 → 检查更新…"，应提示新版本。

## 更新源

- 默认：`https://github.com/byteswalk/dblens/releases/latest/download/latest.json`。
  - 桌面版写在 `tauri.conf.json`；
  - `dblens-server` 写在 `crates/dblens-server/src/update.rs`。
- 内网部署：
  1. 把 `latest.json` 和安装包放到内网的静态文件服务器上；
  2. 改 `latest.json` 中各平台的 `url`，指向内网地址。签名不用改，它只和安装包的内容有关。
  3. 桌面版：在数据目录（Windows 为 `%APPDATA%\DBLens`）下建 `update.json`：

     ```json
     { "endpoint": "https://内网地址/dblens/latest.json" }
     ```

  4. `dblens-server`：启动时加 `--update-url https://内网地址/dblens/latest.json`。不想检查时加 `--no-update-check`。
- 关闭桌面版的自动检查：菜单"帮助 → 启动时自动检查更新"取消勾选，或在 `update.json` 中写 `"auto_check": false`。

## 本地打包（调试用）

```bash
cd web
pnpm install
pnpm package
```

- `pnpm package` 等于在仓库根执行 `tauri build --config crates/dblens-desktop/tauri.bundle.json`：
  - 先构建前端；
  - 再把 `web/dist` 作为资源打进安装包；
  - 输出到 `target/release/bundle/`。
- `tauri.bundle.json` 只在打包时传入。如果写进 `tauri.conf.json`，普通的 `cargo build` 也会检查 `web/dist` 是否存在，没构建过前端就会失败。
- 因为开启了 `createUpdaterArtifacts`，打包时要提供签名私钥：
  - 设置环境变量 `TAURI_SIGNING_PRIVATE_KEY`（私钥文件路径或内容）和 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`；
  - 只想要安装包、不要更新签名时，加 `-- --config "{\"bundle\":{\"createUpdaterArtifacts\":false}}"`。
- 首次打包时，Tauri 会从 GitHub 下载 NSIS。

## 实测（Windows 11，测试密钥，本机静态服务器充当更新源）

1. **按当前用户安装**：`DBLens_0.1.0_x64-setup.exe /S`。
   - 装到 `%LOCALAPPDATA%\DBLens`，主程序为 `DBLens.exe`，前端页面在 `web/`；
   - 卸载信息写在 HKCU 下，不需要管理员权限。
2. **完整的自动更新流程**：
   - 0.1.0 启动 5 秒后读取 `latest.json`，弹窗显示"发现新版本 0.1.1（当前 0.1.0）"和更新说明；
   - 点"下载并安装"后下载、校验签名、以 passive 模式安装，再自动重启为 0.1.1；
   - 数据目录和窗口状态保留，注册表中的版本变为 0.1.1。
3. **签名不对时拒绝安装**：把 `latest.json` 中的签名换成另一个文件的签名后，弹出"安装更新失败：安装包签名校验失败……"，版本保持 0.1.0。
4. **卸载**：`uninstall.exe /S` 删除程序文件和注册表项，数据目录保留。
5. **更新源必须是 https**：
   - 正式配置下 `http://` 更新源会被拒绝（"更新源必须使用 https 地址"），内网更新源也要用 https；
   - 实测时 0.1.0 是用测试配置（`dangerousInsecureTransportProtocol: true`）打的包，只为了能用本机的 http 服务器做更新源。
6. **dblens-server 访问默认更新源**：HTTPS 正常，仓库建好之前返回 404，日志中记一条警告。
7. **测试环境的特殊情况**：从 Claude 桌面应用（MSIX 打包）中启动安装程序时，写入 `%LOCALAPPDATA%` 的文件会被重定向到该应用的包目录下。这是测试环境本身的问题，普通安装不受影响。

## 实现中发现的问题

- **MySQL 的 TLS 连接会 panic。** 更新插件依赖 rustls 的 ring 实现，工作区里原有的是 aws-lc-rs 实现。两者同时编进同一个程序后，rustls 选不出默认实现，mysql_async 一建 TLS 连接就 panic。PG 驱动指定了实现，不受影响。
  - 影响范围：全工作区测试中 MySQL 的 TLS 实库测试必现；桌面版启动后 5 秒内（更新检查之前）用 TLS 连 MySQL 也会触发。
  - 处理：MySQL 驱动在使用 TLS 前先安装 aws-lc-rs 作为进程默认实现。
````
