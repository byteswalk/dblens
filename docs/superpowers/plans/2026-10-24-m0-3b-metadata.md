# M0-3b 元数据读取 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 方言层能为五种数据库生成元数据查询（SQL 加绑定参数），并把查询结果组装成 `dblens-core` 的结构模型。这五种数据库是 MySQL、MariaDB、PostgreSQL、Oracle 和达梦。

**架构：**
- 每个家族一个 minijinja 模板文件（`crates/dblens-dialect/sql/<家族>.sql`），按 `-- [key]` 分段。兼容库可以有只含差异 key 的覆盖文件。
- 所有家族的查询都返回同一套规范化列，差异全部写在 SQL 里，组装代码各家族共用。
- 方言层不做 IO。测试用真实驱动执行查询：设置了 `DBLENS_TEST_*_URL` 环境变量才运行，否则跳过。

**技术栈：** Rust 1.99（edition 2024），minijinja 3.0.3，insta 1.49.0（快照测试）；已有的四个驱动 crate 用于实库测试。

**Spec：** `docs/superpowers/specs/2026-10-22-dblens-design.md`，重点是 6.1–6.4 节；第 9 节要求元数据 SQL 用 `insta` 做快照测试。

### Task 1：达梦驱动——并发加载死锁、连接参数中的模式

**背景：**
- **死锁现象：** 在同一进程里，达梦连接与 PostgreSQL 连接同时发起时，整个进程卡死，CPU 为 0。
- **线程栈（cdb）：**
  - `dmdpi.dll` 的初始化例程持有 Windows 加载器锁，在里面调用 `getaddrinfo`，等待 Winsock 的目录锁；
  - 另一个线程正在第一次创建 socket，持有 Winsock 的目录锁，在 `LoadLibrary` 里等加载器锁。

  修复方法是加载 dmdpi 之前先在本线程初始化 Winsock，这样 dmdpi 初始化时不会再触发 DLL 加载。
- **database 参数：** `m0-2-followups.md` 提到达梦驱动没有使用 `ConnectParams.database`。达梦用 `SET SCHEMA` 切换当前模式，已实测可用。

- Modify: `crates/dblens-driver-dameng/src/lib.rs`
- Create: `crates/dblens-driver-dameng/tests/concurrent_load.rs`
- Modify: `crates/dblens-driver-dameng/tests/conformance.rs`

```rust
//! 回归测试：dmdpi 在 DLL 初始化时调用 getaddrinfo。若此时另一个线程正在进程内第一次创建 socket，
//! 两边会在 Windows 加载器锁和 Winsock 目录锁上互相等待，整个进程卡死。
//! 必须是独立的测试程序：进程里此前不能创建过任何 socket。

use std::net::TcpStream;
use std::sync::{Arc, Barrier, mpsc};
use std::thread;
use std::time::Duration;

use dblens_driver::{ConnectParams, Driver};
use dblens_driver_dameng::DmDriver;

#[test]
fn loading_dpi_while_another_thread_opens_first_socket_does_not_deadlock() {
    let Ok(url) = std::env::var("DBLENS_TEST_DM_URL") else { return };
    let (_, params) = ConnectParams::from_url(&url).unwrap();
    let addr = format!("{}:{}", params.host, params.port);
    let barrier = Arc::new(Barrier::new(2));
    let (done, finished) = mpsc::channel();

    let (b, tx) = (barrier.clone(), done.clone());
    thread::spawn(move || {
        let rt = tokio::runtime::Builder::new_current_thread().enable_all().build().unwrap();
        b.wait();
        let ok = rt.block_on(DmDriver.connect(&params)).is_ok();
        tx.send(("达梦连接", ok)).unwrap();
    });
    thread::spawn(move || {
        barrier.wait();
        let ok = TcpStream::connect(addr).is_ok();
        done.send(("TCP 连接", ok)).unwrap();
    });

    for _ in 0..2 {
        match finished.recv_timeout(Duration::from_secs(60)) {
            Ok((who, ok)) => assert!(ok, "{who} 失败"),
            Err(_) => {
                // 死锁的线程占着加载器锁，正常退出进程也会卡住，只能直接中止
                eprintln!("60 秒内没有完成：加载 dmdpi 与创建 socket 互相死锁");
                std::process::abort();
            }
        }
    }
}
```

```rust
/// dmdpi 在 DLL 初始化例程里（持有 Windows 加载器锁时）调用 getaddrinfo。如果这时另一个线程正在进程内
/// 第一次创建 socket，ws2_32 会持有自己的目录锁、再去加载协议提供程序 DLL 而等待加载器锁，两边互相等待
/// （实测：达梦连接与 PostgreSQL 连接同时发起时整个进程卡死）。所以加载前先在本线程把 Winsock 的协议
/// 目录和名字解析初始化好，让 dmdpi 初始化时不再触发 DLL 加载。其他平台没有这个问题。
fn warm_up_winsock() {
    #[cfg(windows)]
    {
        use std::net::{ToSocketAddrs, UdpSocket};
        let _ = UdpSocket::bind("127.0.0.1:0");
        let _ = UdpSocket::bind("[::1]:0");
        let _ = "localhost:0".to_socket_addrs();
    }
}
```

```rust
//! 服务器版本号的解析与编码。

/// 把版本文本编码为 `major*10000 + minor*100 + patch`（minor、patch 超过 99 时按 99 计），
/// 便于模板里写 `{% if version >= 80016 %}`。识别不出时返回 None。
///
/// 先找第一个独立的 `数字.数字[.数字]`（如 `8.0.36`、`PostgreSQL 18.6`、`Release 23.26.3.0.0`）；
/// 找不到时再识别金仓、达梦的 `V008R006`、`V8` 写法。
pub fn parse_version(text: &str) -> Option<u32> {
    let b = text.as_bytes();
    let num = |i: usize| -> (u32, usize) {
        let mut j = i;
        let mut n: u32 = 0;
        while j < b.len() && b[j].is_ascii_digit() {
            n = n.saturating_mul(10).saturating_add(u32::from(b[j] - b'0'));
            j += 1;
        }
        (n, j)
    };
    let digit_at = |i: usize| i < b.len() && b[i].is_ascii_digit();
    let encode =
        |major: u32, minor: u32, patch: u32| major.min(9999) * 10000 + minor.min(99) * 100 + patch.min(99);
    let mut i = 0;
    while i < b.len() {
        if b[i].is_ascii_digit() && (i == 0 || !b[i - 1].is_ascii_alphanumeric()) {
            let (major, j) = num(i);
            if j < b.len() && b[j] == b'.' && digit_at(j + 1) {
                let (minor, k) = num(j + 1);
                let patch = if k < b.len() && b[k] == b'.' && digit_at(k + 1) { num(k + 1).0 } else { 0 };
                return Some(encode(major, minor, patch));
            }
            i = j;
        } else {
            i += 1;
        }
    }
    for i in 0..b.len() {
        let starts = i == 0 || !b[i - 1].is_ascii_alphanumeric();
        if starts && b[i].eq_ignore_ascii_case(&b'V') && digit_at(i + 1) {
            let (major, j) = num(i + 1);
            let minor = if j < b.len() && b[j].eq_ignore_ascii_case(&b'R') && digit_at(j + 1) {
                num(j + 1).0
            } else {
                0
            };
            return Some(encode(major, minor, 0));
        }
    }
    None
}
```

```rust
//! 元数据查询的结果行，以及按列名取值的宽松转换（各驱动对同一列可能返回不同的 `Value` 变体）。

use dblens_core::{Error, Result, Row, Value};
use dblens_driver::ExecEvent;

/// 一个结果集：列名（已转小写）和行。
#[derive(Debug, Clone, Default, PartialEq)]
pub struct MetaRows {
    columns: Vec<String>,
    rows: Vec<Row>,
}

impl MetaRows {
    pub fn new(columns: Vec<String>, rows: Vec<Row>) -> Self {
        Self { columns: columns.into_iter().map(|c| c.to_lowercase()).collect(), rows }
    }

    /// 从执行事件中取第一个结果集。没有结果集（如只返回影响行数）时报错。
    pub fn from_events(events: Vec<ExecEvent>) -> Result<Self> {
        let mut columns = None;
        let mut rows = Vec::new();
        for ev in events {
            match ev {
                ExecEvent::ResultStart { columns: c } if columns.is_none() => {
                    columns = Some(c.into_iter().map(|m| m.name).collect());
                }
                ExecEvent::Rows(r) if columns.is_some() => rows.extend(r),
                ExecEvent::ResultEnd if columns.is_some() => break,
                _ => {}
            }
        }
        let columns = columns.ok_or_else(|| Error::internal("元数据查询没有返回结果集"))?;
        Ok(Self::new(columns, rows))
    }

    pub fn len(&self) -> usize {
        self.rows.len()
    }

    pub fn is_empty(&self) -> bool {
        self.rows.is_empty()
    }

    /// 检查结果里有这些列（模板写错列别名时尽早报错）。
    pub fn require(&self, key: &str, columns: &[&str]) -> Result<()> {
        match columns.iter().find(|c| !self.columns.iter().any(|have| have == *c)) {
            Some(missing) => Err(Error::internal(format!("元数据查询 {key} 的结果缺少列 {missing}"))),
            None => Ok(()),
        }
    }

    pub fn iter(&self) -> impl Iterator<Item = MetaRow<'_>> {
        self.rows.iter().map(|row| MetaRow { columns: &self.columns, row })
    }
}

/// 一行。取不到的列按 NULL 处理（用 `MetaRows::require` 事先检查）。
#[derive(Debug, Clone, Copy)]
pub struct MetaRow<'a> {
    columns: &'a [String],
    row: &'a Row,
}

impl MetaRow<'_> {
    pub fn get(&self, name: &str) -> &Value {
        const NULL: Value = Value::Null;
        self.columns.iter().position(|c| c == name).and_then(|i| self.row.get(i)).unwrap_or(&NULL)
    }

    /// 文本值；数字等也转成文本。NULL 返回 None。LOB 只能拿到预览部分。
    pub fn str(&self, name: &str) -> Option<String> {
        match self.get(name) {
            Value::Null => None,
            Value::String(s) | Value::Decimal(s) | Value::Interval(s) => Some(s.clone()),
            Value::Int(i) => Some(i.to_string()),
            Value::UInt(u) => Some(u.to_string()),
            Value::Float(f) => Some(f.to_string()),
            Value::Bool(b) => Some(b.to_string()),
            Value::Bytes(b) => Some(String::from_utf8_lossy(b).into_owned()),
            Value::Lob(l) if !l.binary => Some(l.preview.clone()),
            Value::Other { text, .. } => Some(text.clone()),
            other => Some(format!("{other:?}")),
        }
    }

    /// 去掉首尾空白后的文本，空串当作 None（注释、默认值、表达式用）。
    pub fn text(&self, name: &str) -> Option<String> {
        self.str(name).map(|s| s.trim().to_string()).filter(|s| !s.is_empty())
    }

    /// 名字等必有的文本，NULL 时为空串。
    pub fn name(&self, name: &str) -> String {
        self.str(name).unwrap_or_default()
    }

    pub fn int(&self, name: &str) -> Option<i64> {
        match self.get(name) {
            Value::Int(i) => Some(*i),
            Value::UInt(u) => i64::try_from(*u).ok(),
            Value::Bool(b) => Some(i64::from(*b)),
            Value::Float(f) if f.fract() == 0.0 => Some(*f as i64),
            Value::Decimal(s) | Value::String(s) => {
                let s = s.trim();
                s.parse().ok().or_else(|| s.strip_suffix(".0").and_then(|t| t.parse().ok()))
            }
            _ => None,
        }
    }

    /// 布尔标志：接受 bool、非零整数，以及 Y/YES/T/TRUE/1（不区分大小写）。
    pub fn flag(&self, name: &str) -> bool {
        match self.get(name) {
            Value::Bool(b) => *b,
            Value::Int(i) => *i != 0,
            Value::UInt(u) => *u != 0,
            Value::Decimal(s) | Value::String(s) => {
                matches!(s.trim().to_ascii_uppercase().as_str(), "Y" | "YES" | "T" | "TRUE" | "1")
            }
            _ => false,
        }
    }
}
```

```rust
//! 文件按 `-- [key]` 行分段，每段是一个 minijinja 模板。

/// 把模板文件按 `-- [key]` 行拆成 key → 模板正文。
pub(crate) fn parse_sections(text: &str) -> HashMap<String, String> {
    let mut out = HashMap::new();
    let mut current: Option<(String, String)> = None;
    for line in text.lines() {
        let t = line.trim();
        if let Some(key) = t.strip_prefix("-- [").and_then(|r| r.strip_suffix(']')) {
            if let Some((k, body)) = current.take() {
                out.insert(k, body.trim().to_string());
            }
            current = Some((key.trim().to_string(), String::new()));
        } else if let Some((_, body)) = current.as_mut() {
            body.push_str(line);
            body.push('\n');
        }
    }
    if let Some((k, body)) = current {
        out.insert(k, body.trim().to_string());
    }
    out
}

fn base_file(family: Family) -> &'static str {
    match family {
        Family::MySql => MYSQL,
        Family::Postgres => POSTGRES,
        Family::Oracle => ORACLE,
        Family::Dameng => DAMENG,
    }
}

fn override_file(variant: Variant) -> Option<&'static str> {
    match variant {
        Variant::MariaDb => Some(MARIADB),
        _ => None,
    }
}

/// 某个变体的全部模板：家族基础模板，再用变体覆盖文件中的同名 key 替换；
/// 覆盖文件里正文为空的 key 表示该变体没有这种查询，从结果中删除。
pub(crate) fn sections(variant: Variant) -> &'static HashMap<String, String> {
    static CACHE: OnceLock<HashMap<Variant, HashMap<String, String>>> = OnceLock::new();
    let all = CACHE.get_or_init(|| {
        ALL_VARIANTS
            .iter()
            .map(|&v| {
                let mut m = parse_sections(base_file(v.family()));
                if let Some(o) = override_file(v) {
                    m.extend(parse_sections(o));
                    m.retain(|_, body| !body.is_empty());
                }
                (v, m)
            })
            .collect()
    });
    &all[&variant]
}

/// LIKE 模式：包含匹配，`!` 作转义符（模板里写 `ESCAPE '!'`）。
pub(crate) fn like_pattern(filter: &str) -> String {
    let mut p = String::from("%");
    for c in filter.chars() {
        if matches!(c, '%' | '_' | '!') {
            p.push('!');
        }
        p.push(c);
    }
    p.push('%');
    p
}

/// 渲染一个模板。`version` 是编码后的版本号，未知时传 `u32::MAX`（按最新版本处理）。
pub(crate) fn render(
    key: MetaKey,
    template: &str,
    family: Family,
    version: u32,
    args: &MetaArgs,
) -> Result<MetaQuery> {
    let names: Arc<Mutex<Vec<String>>> = Arc::default();
    let mut env = Environment::new();
    env.set_undefined_behavior(UndefinedBehavior::Strict);
    let syntax = SyntaxConfig::builder()
        .trim_blocks(true)
        .lstrip_blocks(true)
        .build()
        .map_err(|e| Error::internal(format!("模板语法配置错误：{e}")))?;
    env.set_syntax(syntax);
    let recorded = names.clone();
    env.add_function("bind", move |name: String| -> String {
        let mut list = recorded.lock().unwrap();
        list.push(name);
        ident::placeholder(family, list.len())
    });
    let k = key.as_str();
    let tmpl = env
        .template_from_str(template)
        .map_err(|e| Error::internal(format!("元数据模板 {k} 解析失败：{e}")))?;
    let sql = tmpl
        .render(context! {
            table => args.table.is_some(),
            name => args.name.is_some(),
            kind => args.kind.is_some(),
            filter => args.filter.is_some(),
            version => version,
        })
        .map_err(|e| Error::internal(format!("元数据模板 {k} 渲染失败：{e}")))?;
    let params = names
        .lock()
        .unwrap()
        .iter()
        .map(|n| {
            let v = match n.as_str() {
                "schema" => args.schema.clone(),
                "table" => args.table.clone(),
                "name" => args.name.clone(),
                "kind" => args.kind.clone(),
                "filter" => args.filter.as_deref().map(like_pattern),
                other => return Err(Error::internal(format!("元数据模板 {k} 绑定了未知参数 {other}"))),
            };
            Ok(v.map_or(Value::Null, Value::String))
        })
        .collect::<Result<Vec<_>>>()?;
    Ok(MetaQuery { key, sql: sql.trim().to_string(), params })
}
```

```rust
//! 把规范化的元数据结果行组装成结构模型。所有家族共用，列名约定见 `sql/*.sql` 文件头。

use std::collections::HashMap;

use dblens_core::schema::{
    CheckConstraint, Column, ForeignKey, Index, IndexColumn, PrimaryKey, Routine, RoutineKind, Sequence,
    Synonym, Table, Trigger, UniqueConstraint, View,
};
use dblens_core::{ColumnType, Result};
use serde::{Deserialize, Serialize};

use super::{MetaKey, MetaRow, MetaRows};
use crate::Dialect;

/// 对象树里的 schema 节点。
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct SchemaInfo {
    pub name: String,
    /// 数据库自带的系统 schema（界面默认折叠或隐藏）。
    pub is_system: bool,
}

/// 对象树里的表、视图、物化视图节点：只有名字和注释，展开时再取明细。
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct ObjectInfo {
    pub name: String,
    pub comment: Option<String>,
}

/// 组装表明细所需的六个结果集，按 `MetaKey::TABLE_DETAIL` 的顺序执行得到。
#[derive(Debug, Clone, Default, PartialEq)]
pub struct TableRows {
    pub tables: MetaRows,
    pub columns: MetaRows,
    pub keys: MetaRows,
    pub checks: MetaRows,
    pub indexes: MetaRows,
    pub triggers: MetaRows,
}

pub fn schemas(rows: &MetaRows) -> Result<Vec<SchemaInfo>> {
    rows.require("schemas", &["name", "is_system"])?;
    Ok(rows.iter().map(|r| SchemaInfo { name: r.name("name"), is_system: r.flag("is_system") }).collect())
}

/// 表、视图、物化视图的名字列表。
pub fn objects(key: MetaKey, rows: &MetaRows) -> Result<Vec<ObjectInfo>> {
    rows.require(key.as_str(), &["name", "comment"])?;
    Ok(rows.iter().map(|r| ObjectInfo { name: r.name("name"), comment: r.text("comment") }).collect())
}

/// 按表名分组，组内保持结果行的顺序。
fn group_by_table<'a>(rows: &'a MetaRows) -> HashMap<String, Vec<MetaRow<'a>>> {
    let mut map: HashMap<String, Vec<MetaRow<'a>>> = HashMap::new();
    for r in rows.iter() {
        map.entry(r.name("table_name")).or_default().push(r);
    }
    map
}

/// 按某一列的值把相邻、同名的行归成一组（结果已按该列排序）。
fn runs<'a>(rows: &[MetaRow<'a>], column: &str) -> Vec<Vec<MetaRow<'a>>> {
    let mut out: Vec<Vec<MetaRow<'a>>> = Vec::new();
    for r in rows {
        match out.last_mut() {
            Some(run) if run[0].str(column) == r.str(column) => run.push(*r),
            _ => out.push(vec![*r]),
        }
    }
    out
}

fn column(d: &Dialect, r: &MetaRow) -> Column {
    let native = r.name("type_text").trim().to_string();
    Column {
        name: r.name("name"),
        ordinal: r.int("ordinal").and_then(|v| u32::try_from(v).ok()).unwrap_or(0),
        data_type: ColumnType { logical: d.logical_type(&native), native },
        nullable: r.flag("nullable"),
        default: r.text("default_value"),
        comment: r.text("comment"),
        auto_increment: r.flag("auto_increment"),
        generated: r.text("generated"),
    }
}

const COLUMN_COLS: [&str; 9] = [
    "table_name",
    "name",
    "ordinal",
    "type_text",
    "nullable",
    "default_value",
    "comment",
    "auto_increment",
    "generated",
];

/// 组装表明细。只组装 `tables` 结果里出现的表；`columns` 里视图的列会被忽略。
pub fn tables(d: &Dialect, rows: &TableRows) -> Result<Vec<Table>> {
    rows.tables.require("tables", &["name", "comment", "partition"])?;
    rows.columns.require("columns", &COLUMN_COLS)?;
    rows.keys.require(
        "keys",
        &[
            "table_name",
            "constraint_name",
            "constraint_type",
            "column_name",
            "position",
            "ref_schema",
            "ref_table",
            "ref_column",
            "on_delete",
            "on_update",
        ],
    )?;
    rows.checks.require("checks", &["table_name", "constraint_name", "expression"])?;
    rows.indexes.require(
        "indexes",
        &["table_name", "index_name", "is_unique", "method", "column_expr", "position", "descending"],
    )?;
    rows.triggers.require("triggers", &["table_name", "name", "timing", "events", "definition"])?;

    let columns = group_by_table(&rows.columns);
    let keys = group_by_table(&rows.keys);
    let checks = group_by_table(&rows.checks);
    let indexes = group_by_table(&rows.indexes);
    let triggers = group_by_table(&rows.triggers);
    let none: Vec<MetaRow> = Vec::new();

    Ok(rows
        .tables
        .iter()
        .map(|t| {
            let name = t.name("name");
            let mut table = Table {
                comment: t.text("comment"),
                partition: t.text("partition"),
                columns: columns.get(&name).unwrap_or(&none).iter().map(|r| column(d, r)).collect(),
                ..Default::default()
            };
            for run in runs(keys.get(&name).unwrap_or(&none), "constraint_name") {
                let first = run[0];
                let cname = first.text("constraint_name");
                let cols: Vec<String> = run.iter().map(|r| r.name("column_name")).collect();
                match first.name("constraint_type").trim() {
                    "P" => table.primary_key = Some(PrimaryKey { name: cname, columns: cols }),
                    "U" => table.uniques.push(UniqueConstraint { name: cname, columns: cols }),
                    "F" => table.foreign_keys.push(ForeignKey {
                        name: cname,
                        columns: cols,
                        ref_schema: first.text("ref_schema"),
                        ref_table: first.name("ref_table"),
                        ref_columns: run.iter().map(|r| r.name("ref_column")).collect(),
                        on_delete: first.text("on_delete"),
                        on_update: first.text("on_update"),
                    }),
                    _ => {}
                }
            }
            table.checks = checks
                .get(&name)
                .unwrap_or(&none)
                .iter()
                .map(|r| CheckConstraint {
                    name: r.text("constraint_name"),
                    expression: r.text("expression").unwrap_or_default(),
                })
                .filter(|c| !is_not_null_check(&c.expression))
                .collect();
            table.indexes = runs(indexes.get(&name).unwrap_or(&none), "index_name")
                .into_iter()
                .map(|run| Index {
                    name: run[0].name("index_name"),
                    unique: run[0].flag("is_unique"),
                    method: run[0].text("method"),
                    columns: run
                        .iter()
                        .map(|r| IndexColumn {
                            // Oracle 12.2 以前函数索引的表达式另放在 LONG 列 column_expression 中
                            name: unquote_column(
                                r.text("column_expression").unwrap_or_else(|| r.name("column_expr")),
                            ),
                            descending: r.flag("descending"),
                        })
                        .collect(),
                })
                .collect();
            table.triggers = triggers
                .get(&name)
                .unwrap_or(&none)
                .iter()
                .map(|r| Trigger {
                    name: r.name("name"),
                    timing: r.text("timing"),
                    events: r
                        .name("events")
                        .split(',')
                        .map(|e| e.trim().to_string())
                        .filter(|e| !e.is_empty())
                        .collect(),
                    definition: r.text("definition"),
                })
                .collect();
            table.name = name;
            table
        })
        .collect())
}

/// Oracle 的降序索引列以表达式 `"CREATED"` 的形式出现，只是一个带引号的列名时去掉引号。
fn unquote_column(expr: String) -> String {
    match expr.strip_prefix('"').and_then(|e| e.strip_suffix('"')) {
        Some(inner) if !inner.is_empty() && !inner.contains('"') => inner.to_string(),
        _ => expr,
    }
}

/// Oracle 12.2 以前，NOT NULL 也以 `"COL" IS NOT NULL` 形式的检查约束出现，这里统一过滤掉。
fn is_not_null_check(expression: &str) -> bool {
    expression
        .strip_suffix(" IS NOT NULL")
        .and_then(|c| c.strip_prefix('"'))
        .and_then(|c| c.strip_suffix('"'))
        .is_some_and(|c| !c.contains('"'))
}

/// 组装视图（或物化视图）及其列；定义 SQL 另用 `view_definition` 按需获取。
pub fn views(d: &Dialect, key: MetaKey, views: &MetaRows, columns: &MetaRows) -> Result<Vec<View>> {
    views.require(key.as_str(), &["name", "comment"])?;
    columns.require("columns", &COLUMN_COLS)?;
    let columns = group_by_table(columns);
    Ok(views
        .iter()
        .map(|v| {
            let name = v.name("name");
            View {
                comment: v.text("comment"),
                definition: None,
                columns: columns
                    .get(&name)
                    .map(|rs| rs.iter().map(|r| column(d, r)).collect())
                    .unwrap_or_default(),
                name,
            }
        })
        .collect())
}

pub fn sequences(rows: &MetaRows) -> Result<Vec<Sequence>> {
    rows.require(
        "sequences",
        &["name", "start_value", "increment", "min_value", "max_value", "cycle", "cache"],
    )?;
    Ok(rows
        .iter()
        .map(|r| Sequence {
            name: r.name("name"),
            start: r.text("start_value"),
            increment: r.text("increment"),
            min_value: r.text("min_value"),
            max_value: r.text("max_value"),
            cycle: r.flag("cycle"),
            cache: r.int("cache").and_then(|c| u64::try_from(c).ok()),
        })
        .collect())
}

/// 存储过程、函数、包。不认识的种类跳过。源码另用 `routine_source` 按需获取。
pub fn routines(rows: &MetaRows) -> Result<Vec<Routine>> {
    rows.require("routines", &["name", "kind", "comment"])?;
    Ok(rows
        .iter()
        .filter_map(|r| {
            let kind = match r.name("kind").trim().to_ascii_uppercase().as_str() {
                "PROCEDURE" => RoutineKind::Procedure,
                "FUNCTION" => RoutineKind::Function,
                "PACKAGE" => RoutineKind::Package,
                "PACKAGE BODY" => RoutineKind::PackageBody,
                _ => return None,
            };
            Some(Routine { name: r.name("name"), kind, source: None })
        })
        .collect())
}

pub fn synonyms(rows: &MetaRows) -> Result<Vec<Synonym>> {
    rows.require("synonyms", &["name", "target_schema", "target_name", "db_link"])?;
    Ok(rows
        .iter()
        .map(|r| Synonym {
            name: r.name("name"),
            target_schema: r.text("target_schema"),
            target_name: r.name("target_name"),
            db_link: r.text("db_link"),
        })
        .collect())
}

/// 视图定义或程序源码：`view_definition` 取第一行的 `definition`；
/// `routine_source` 按行顺序拼接 `text`（每行自带换行，原样拼接）。找不到对象时返回 None。
pub fn source_text(key: MetaKey, rows: &MetaRows) -> Result<Option<String>> {
    match key {
        MetaKey::RoutineSource => {
            rows.require("routine_source", &["line", "text"])?;
            if rows.is_empty() {
                return Ok(None);
            }
            Ok(Some(rows.iter().map(|r| r.str("text").unwrap_or_default()).collect()))
        }
        _ => {
            rows.require(key.as_str(), &["definition"])?;
            Ok(rows.iter().next().and_then(|r| r.str("definition")))
        }
    }
}

/// 服务器报告的保留字，统一转成大写。
pub fn reserved_words(rows: &MetaRows) -> Result<Vec<String>> {
    rows.require("reserved_words", &["word"])?;
    Ok(rows.iter().map(|r| r.name("word").trim().to_ascii_uppercase()).filter(|w| !w.is_empty()).collect())
}
```

```rust
//! 元数据查询的实库测试。设置对应的环境变量时运行，否则直接通过（与驱动一致性测试相同的约定）：
//! DBLENS_TEST_MYSQL_URL、DBLENS_TEST_MARIADB_URL、DBLENS_TEST_PG_URL、DBLENS_TEST_ORACLE_URL、DBLENS_TEST_DM_URL。
//!
//! 每个家族先执行 `tests/fixtures/<家族>.sql` 建测试对象，再用全部元数据查询读回来逐项核对。

use std::time::Instant;

use dblens_core::schema::{RoutineKind, Table};
use dblens_core::{LogicalType, Value};
use dblens_dialect::meta::{self, MetaArgs, MetaKey, MetaRows, TableRows};
use dblens_dialect::{Dialect, Family, Variant};
use dblens_driver::{ConnectParams, Connection, Driver, DriverId, collect_all};

struct Live {
    conn: Box<dyn Connection>,
    d: Dialect,
}

async fn fetch(conn: &mut Box<dyn Connection>, sql: &str, params: &[Value]) -> MetaRows {
    let mut stream = conn.execute(sql, params).await.unwrap_or_else(|e| panic!("{e}\n{sql}"));
    let events = collect_all(stream.as_mut(), 10_000).await.unwrap_or_else(|e| panic!("{e}\n{sql}"));
    MetaRows::from_events(events).unwrap()
}

async fn connect(env: &str) -> Option<Live> {
    let url = std::env::var(env).ok()?;
    let (id, params) = ConnectParams::from_url(&url).unwrap();
    let driver: Box<dyn Driver> = match id {
        DriverId::Mysql => Box::new(dblens_driver_mysql::MySqlDriver),
        DriverId::Postgres => Box::new(dblens_driver_postgres::PgDriver),
        DriverId::Oracle => Box::new(dblens_driver_oracle::OracleDriver),
        DriverId::Dameng => Box::new(dblens_driver_dameng::DmDriver),
    };
    let mut conn = driver.connect(&params).await.unwrap();
    let info = conn.server_info().await.unwrap();
    let mut d = Dialect::detect(id, &info);
    if let Some(q) = d.meta_query(MetaKey::VariantProbe, &MetaArgs::default()).unwrap() {
        let probe = fetch(&mut conn, &q.sql, &q.params).await;
        d = d.refine(&probe);
    }
    Some(Live { conn, d })
}

fn args(schema: &str) -> MetaArgs {
    MetaArgs { schema: Some(schema.into()), ..Default::default() }
}

impl Live {
    async fn rows(&mut self, key: MetaKey, a: &MetaArgs) -> MetaRows {
        let q = self
            .d
            .meta_query(key, a)
            .unwrap()
            .unwrap_or_else(|| panic!("{:?} 没有 {key:?} 模板", self.d.variant()));
        fetch(&mut self.conn, &q.sql, &q.params).await
    }

    /// 按 `-- @@ 标签` 分段逐条执行建测试对象的脚本。
    async fn run_script(&mut self, text: &str) {
        let mut sections: Vec<String> = Vec::new();
        for line in text.lines() {
            if line.starts_with("-- @@") {
                sections.push(String::new());
            } else if let Some(last) = sections.last_mut() {
                last.push_str(line);
                last.push('\n');
            }
        }
        for sql in sections {
            let sql = sql.trim();
            if sql.is_empty() {
                continue;
            }
            let mut stream = self.conn.execute(sql, &[]).await.unwrap_or_else(|e| panic!("{e}\n{sql}"));
            collect_all(stream.as_mut(), 1000).await.unwrap_or_else(|e| panic!("{e}\n{sql}"));
        }
    }

    /// 取表明细：一类对象一条查询，共六条。
    async fn tables(&mut self, schema: &str, table: Option<&str>) -> Vec<Table> {
        let a = MetaArgs { table: table.map(Into::into), ..args(schema) };
        let rows = TableRows {
            tables: self.rows(MetaKey::Tables, &a).await,
            columns: self.rows(MetaKey::Columns, &a).await,
            keys: self.rows(MetaKey::Keys, &a).await,
            checks: self.rows(MetaKey::Checks, &a).await,
            indexes: self.rows(MetaKey::Indexes, &a).await,
            triggers: self.rows(MetaKey::Triggers, &a).await,
        };
        meta::tables(&self.d, &rows).unwrap()
    }

    /// 服务器报告的每个保留字都必须被 `ident` 加引号。
    async fn check_reserved_words(&mut self) {
        let rows = self.rows(MetaKey::ReservedWords, &MetaArgs::default()).await;
        let words = meta::reserved_words(&rows).unwrap();
        assert!(words.len() > 50, "{:?} 只取到 {} 个保留字", self.d.variant(), words.len());
        let lower = matches!(self.d.family(), Family::MySql | Family::Postgres);
        let unquoted: Vec<&String> = words
            .iter()
            .filter(|w| {
                let name = if lower { w.to_ascii_lowercase() } else { w.to_string() };
                self.d.ident(&name) == name
            })
            .collect();
        assert!(unquoted.is_empty(), "{:?} 这些保留字没有加引号：{unquoted:?}", self.d.variant());
    }
}

fn table<'a>(tables: &'a [Table], name: &str) -> &'a Table {
    tables.iter().find(|t| t.name == name).unwrap_or_else(|| panic!("没有表 {name}"))
}

fn logical(t: &Table, column: &str) -> LogicalType {
    t.columns
        .iter()
        .find(|c| c.name == column)
        .unwrap_or_else(|| panic!("{} 没有列 {column}", t.name))
        .data_type
        .logical
        .clone()
}

fn has(text: &str, needle: &str) -> bool {
    text.to_ascii_lowercase().contains(&needle.to_ascii_lowercase())
}
```

```rust
use dblens_dialect::meta::{MetaArgs, MetaKey};
```
