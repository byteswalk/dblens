**Interfaces:**
- Produces（前端 Task 3 使用）：
  - `GET /api/settings`：返回 `{ "ui.xxx": "值", … }`，只包含 `ui.` 开头的键；
  - `PUT /api/settings/{key}`：请求体 `{ "value": "…" | null }`，返回 204；`null` 表示删除。
  - 键：`ui.` 开头，总长不超过 64，只能含小写字母、数字和 `._-`。值不超过 64 KiB。违反时返回 400 `invalid`。
- `Store::settings(&self) -> Result<BTreeMap<String, String>>`。

为什么只开放 `ui.*`：同一张 `settings` 表里还有服务层自己的设置，如已确认的原生库目录 `native.*`。如果设置接口能写它们，就能绕过 `PUT /drivers/{driver}/lib-dir` 的绝对路径校验。这是准备阶段实测发现的问题。

```rust
use std::sync::Arc;

use axum::Router;
use axum::body::Body;
use axum::http::{Request, StatusCode, header};
use dblens_api::{ApiConfig, router};
use dblens_service::fake::FakeDriver;
use dblens_service::{DefaultPolicy, DriverRegistry, SecretBackend, Secrets, Service, Store};
use http_body_util::BodyExt;
use serde_json::{Value, json};
use tower::ServiceExt;

fn app() -> Router {
    let store = Arc::new(Store::open_in_memory().unwrap());
    let secrets = Arc::new(Secrets::with_backend(store.clone(), SecretBackend::Vault));
    let registry = Arc::new(DriverRegistry::with_drivers(
        store.clone(),
        vec![Box::new(FakeDriver { log: Arc::default() })],
    ));
    let service = Arc::new(Service::with_parts(store, secrets, registry, Arc::new(DefaultPolicy)));
    router(service, ApiConfig { token: "t".into(), allowed_origins: vec![] })

async fn call(app: &Router, method: &str, uri: &str, body: Option<Value>) -> (StatusCode, Value) {
    let mut req = Request::builder().method(method).uri(uri).header(header::AUTHORIZATION, "Bearer t");
    if body.is_some() {
        req = req.header(header::CONTENT_TYPE, "application/json");
    }
    let req = req.body(body.map_or_else(Body::empty, |b| Body::from(b.to_string()))).unwrap();
    let resp = app.clone().oneshot(req).await.unwrap();
    let status = resp.status();
    let bytes = resp.into_body().collect().await.unwrap().to_bytes();
    (status, if bytes.is_empty() { Value::Null } else { serde_json::from_slice(&bytes).unwrap() })
}

async fn put(app: &Router, key: &str, value: Value) -> (StatusCode, Value) {
    call(app, "PUT", &format!("/api/settings/{key}"), Some(json!({ "value": value }))).await
}
```

```rust
// ---- 设置 ----

/// 单个设置项的值上限。设置是界面状态（主题、面板大小、打开的标签页等），不应很大。
const MAX_SETTING_BYTES: usize = 64 * 1024;

/// 这个接口只读写界面设置（`ui.` 开头）。同一张表里还有服务层自己的设置（如已确认的原生库目录 `native.*`），
/// 它们有各自的接口和校验，不能经这里绕过。
const UI_PREFIX: &str = "ui.";

/// 设置项名称：`ui.` 开头，共 1–64 个小写字母、数字或 `.`、`_`、`-`，如 `ui.theme`。
fn valid_setting_key(key: &str) -> bool {
    key.starts_with(UI_PREFIX)
        && key.len() <= 64
        && key.bytes().all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b"._-".contains(&b))
}

pub async fn settings(State(s): State<AppState>) -> ApiResult<Json<BTreeMap<String, String>>> {
    let mut all = s.service.store.settings()?;
    all.retain(|k, _| k.starts_with(UI_PREFIX));
    Ok(Json(all))
}

#[derive(Deserialize)]
pub struct SettingBody {
    /// null 表示删除这一项。
    pub value: Option<String>,
}

pub async fn set_setting(
    State(s): State<AppState>,
    Path(key): Path<String>,
    Json(b): Json<SettingBody>,
) -> ApiResult<StatusCode> {
    if !valid_setting_key(&key) {
        return Err(Error::invalid(format!("设置项名称不合法：{key}")).into());
    }
    if b.value.as_ref().is_some_and(|v| v.len() > MAX_SETTING_BYTES) {
        return Err(Error::invalid(format!("设置项 {key} 的值超过 64 KiB")).into());
    }
    s.service.store.set_setting(&key, b.value.as_deref())?;
    Ok(StatusCode::NO_CONTENT)
}
```

`crates/dblens-desktop/src/shell.rs`：

```rust
//! 页面可以调用的原生能力（M1 设计文档 2.2 节）。
//!
//! 业务仍然只走 HTTP 和 WebSocket；自绘标题栏需要的窗口操作，以及原本在原生菜单里的几项（置顶、恢复默认位置、
//! 检查更新、关于、退出），通过这里的三个命令提供。`capabilities/main.json` 只放行这三个命令和事件监听，
//! 且只对 `http://127.0.0.1:*` 上的本地页面生效。
//!
//! 窗口状态变化（最大化、置顶、自动检查更新）后，通过事件 [`EVENT`] 把新的 [`ShellInfo`] 推给页面。

use serde::{Deserialize, Serialize};
use tauri::{AppHandle, Emitter, Manager};

use crate::{update, window};

/// 状态变化事件名，载荷为 [`ShellInfo`]。
pub const EVENT: &str = "dblens://shell";

/// 标题栏需要的状态。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct ShellInfo {
    /// `windows` / `macos` / `linux`。macOS 上页面要给系统的红黄绿按钮留位置。
    pub platform: &'static str,
    pub version: String,
    pub maximized: bool,
    pub always_on_top: bool,
    pub auto_check_update: bool,
}

/// 页面发起的窗口操作。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum WindowAction {
    Minimize,
    ToggleMaximize,
    Close,
    /// 鼠标在标题栏空白处按下：开始拖动窗口。
    StartDragging,
    ToggleAlwaysOnTop,
    /// 恢复默认窗口位置和大小。
    ResetPosition,
    CheckUpdate,
    About,
    Quit,
}

pub fn info(app: &AppHandle) -> ShellInfo {
    let maximized = app.get_webview_window(window::MAIN).and_then(|w| w.is_maximized().ok()).unwrap_or(false);
    ShellInfo {
        platform: std::env::consts::OS,
        version: app.package_info().version.to_string(),
        maximized,
        always_on_top: window::always_on_top(app),
        auto_check_update: update::auto_check(app),
    }
}

/// 把最新状态推给页面。
pub fn notify(app: &AppHandle) {
    if let Err(e) = app.emit(EVENT, info(app)) {
        tracing::warn!("推送窗口状态失败：{e}");
    }
}

#[tauri::command]
pub fn shell_info(app: AppHandle) -> ShellInfo {
    info(&app)
}

#[tauri::command]
pub fn window_action(app: AppHandle, action: WindowAction) -> Result<(), String> {
    let win = app.get_webview_window(window::MAIN).ok_or("主窗口不存在")?;
    let result = match action {
        WindowAction::Minimize => win.minimize(),
        WindowAction::ToggleMaximize => {
            if win.is_maximized().map_err(|e| e.to_string())? {
                win.unmaximize()
            } else {
                win.maximize()
            }
        }
        WindowAction::Close => win.close(),
        WindowAction::StartDragging => win.start_dragging(),
        WindowAction::ToggleAlwaysOnTop => window::toggle_always_on_top(&app),
        WindowAction::ResetPosition => window::reset(&win),
        WindowAction::CheckUpdate => {
            tauri::async_runtime::spawn(update::check(app.clone(), true));
            Ok(())
        }
        WindowAction::About => {
            update::about(&app);
            Ok(())
        }
        WindowAction::Quit => {
            window::quit(&app);
            Ok(())
        }
    };
    result.map_err(|e| e.to_string())
}

#[tauri::command]
pub fn set_auto_check_update(app: AppHandle, on: bool) {
    update::set_auto_check(&app, on);
    notify(&app);
}
```

```rust
//! 主窗口（设计文档 7.2 节；M1 设计文档 1.2、2.2 节）：
//! - 首次启动 1440×900 居中，屏幕小时取工作区的 90%，最小 1024×640；
//! - 窗口置顶（Ctrl+Shift+T）、恢复默认窗口位置和大小；
//! - 退出时保存位置、大小、是否最大化和置顶状态；保存的位置已不在任何显示器上时，改用主屏幕的默认位置。
//!
//! 标题栏由页面自绘（M1）：Windows、Linux 去掉系统标题栏，菜单也由页面绘制，经 [`crate::shell`] 的命令调用这里；
//! macOS 保留系统的红黄绿按钮（标题栏叠加在页面上），菜单仍用屏幕顶部的系统菜单栏。
//!
//! 页面由进程内的接口服务提供（与 `/api` 同源）。访问令牌经初始化脚本注入页面；
//! 窗口只允许停留在这个地址下，防止令牌被注入到其他网站的页面中。
//!
//! 快捷键：Windows 上键盘焦点在页面（WebView2）里时，按键不经过窗口的消息循环，菜单快捷键不会触发（实测）。
//! 所以置顶快捷键用系统热键实现，只在窗口获得焦点时注册、失去焦点时注销，不影响其他程序。

use std::path::PathBuf;
use std::sync::Mutex;
use std::sync::atomic::{AtomicU64, Ordering};
use std::time::Duration;

    CheckMenuItem, CheckMenuItemBuilder, MenuBuilder, MenuItemBuilder, Submenu, SubmenuBuilder,

pub const MAIN: &str = "main";
const MENU_ON_TOP: &str = "always_on_top";
const MENU_RESET: &str = "reset_window";
const MENU_QUIT: &str = "quit";
/// "窗口置顶"的快捷键。没有用 Ctrl+Alt+T：它在 Linux 桌面上是打开终端的系统快捷键。
pub const ON_TOP_SHORTCUT: &str = "CmdOrCtrl+Shift+T";

/// 移动、缩放后等这么久再记录位置：最大化时移动和缩放事件先于"已最大化"标志到达，立即记录会把最大化后的大小当成普通大小。
const SETTLE: Duration = Duration::from_millis(300);

/// 运行期间的窗口状态，退出时写回文件。
struct Tracked {
    path: PathBuf,
    state: Mutex<WindowState>,
    /// macOS 系统菜单里的"窗口置顶"勾选项；其他平台没有系统菜单。
    on_top_item: Option<CheckMenuItem<Wry>>,
    /// 每次移动、缩放加一；延迟记录时编号已变，说明之后又有新事件，这次就不记了。
    generation: AtomicU64,
}

/// 页面脚本运行前执行的初始化脚本：注入访问令牌。
pub fn init_script(token: &str) -> String {
    format!("window.__DBLENS__ = Object.freeze({{ token: {} }});", serde_json::Value::from(token))
}

/// 窗口只能停留在接口服务的地址下（`base` 形如 `http://127.0.0.1:端口/`）。
pub fn allowed_navigation(base: &str, url: &str) -> bool {
    url.starts_with(base)
}

fn on_top_shortcut() -> Shortcut {
    ON_TOP_SHORTCUT.parse().expect("快捷键格式")
}

fn to_rect(p: PhysicalPosition<i32>, s: PhysicalSize<u32>) -> Rect {
    Rect { x: p.x, y: p.y, width: s.width, height: s.height }
}

fn apply_rect(win: &WebviewWindow, r: Rect) -> tauri::Result<()> {
    win.set_size(PhysicalSize::new(r.width, r.height))?;
    win.set_position(PhysicalPosition::new(r.x, r.y))
}

/// 主屏幕（取不到时用窗口当前所在的屏幕）上的默认位置和大小。
fn default_rect(win: &WebviewWindow) -> tauri::Result<Option<Rect>> {
    let monitor = match win.primary_monitor()? {
        Some(m) => Some(m),
        None => win.current_monitor()?,
    };
    Ok(monitor.map(|m| {
        let a = m.work_area();
        geometry::default_rect(to_rect(a.position, a.size), m.scale_factor())
    }))
}

pub fn reset(win: &WebviewWindow) -> tauri::Result<()> {
    win.unmaximize()?;
    if let Some(r) = default_rect(win)? {
        apply_rect(win, r)?;
    }
    Ok(())
}

/// 记下未最大化、未最小化时的位置和大小，作为下次启动的位置。
fn remember(win: &WebviewWindow, tracked: &Tracked) -> tauri::Result<()> {
    if win.is_maximized()? || win.is_minimized()? {
        return Ok(());
    }
    let r = to_rect(win.outer_position()?, win.inner_size()?);
    tracked.state.lock().unwrap().rect = Some(r);
    Ok(())
}

/// 移动、缩放后延迟记录位置，连续的事件只记最后一次。
fn remember_later(win: &WebviewWindow) {
    let generation = win.state::<Tracked>().generation.fetch_add(1, Ordering::SeqCst) + 1;
    let win = win.clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(SETTLE).await;
        let tracked = win.state::<Tracked>();
        if tracked.generation.load(Ordering::SeqCst) == generation {
            let _ = remember(&win, &tracked);
        }
    });
}

fn save(win: &WebviewWindow, tracked: &Tracked) {
    // 退出时状态已稳定，补记一次，免得最后一次移动还没来得及记录
    let _ = remember(win, tracked);
    let mut s = *tracked.state.lock().unwrap();
    s.maximized = win.is_maximized().unwrap_or(false);
    if let Err(e) = window_state::save(&tracked.path, &s) {
        tracing::warn!("无法保存窗口状态到 {}：{e}", tracked.path.display());
    }
}

pub fn always_on_top(app: &AppHandle) -> bool {
    app.state::<Tracked>().state.lock().unwrap().always_on_top
}

/// 设置置顶，同步系统菜单的勾选状态，并通知页面。
fn set_always_on_top(app: &AppHandle, on: bool) -> tauri::Result<()> {
    if let Some(win) = app.get_webview_window(MAIN) {
        win.set_always_on_top(on)?;
    }
    let tracked = app.state::<Tracked>();
    tracked.state.lock().unwrap().always_on_top = on;
    if let Some(item) = &tracked.on_top_item {
        item.set_checked(on)?;
    }
    shell::notify(app);
    Ok(())
}

pub fn toggle_always_on_top(app: &AppHandle) -> tauri::Result<()> {
    set_always_on_top(app, !always_on_top(app))
}

/// 保存窗口状态后退出。
pub fn quit(app: &AppHandle) {
    if let Some(win) = app.get_webview_window(MAIN) {
        save(&win, &app.state::<Tracked>());
    }
    app.exit(0);
}

/// 快捷键：切换置顶。
pub fn on_shortcut(app: &AppHandle, shortcut: &Shortcut, event: ShortcutEvent) {
    if event.state != ShortcutState::Pressed || *shortcut != on_top_shortcut() {
        return;
    }
    if let Err(e) = toggle_always_on_top(app) {
        tracing::warn!("切换窗口置顶失败：{e}");
    }
}

fn on_menu(app: &AppHandle, id: &str) -> tauri::Result<()> {
    if update::on_menu(app, id) {
        return Ok(());
    }
    let Some(win) = app.get_webview_window(MAIN) else { return Ok(()) };
    match id {
        // 点击时系统菜单已自动切换了勾选状态，以它为准
        MENU_ON_TOP => {
            let on = app.state::<Tracked>().on_top_item.as_ref().map_or(Ok(false), |i| i.is_checked())?;
            set_always_on_top(app, on)?
        }
        MENU_RESET => reset(&win)?,
        MENU_QUIT => quit(app),
        _ => {}
    }
    Ok(())
}

/// 窗口获得焦点时注册快捷键，失去焦点时注销。注册失败（被其他程序占用）只记日志，菜单仍可用。
fn focus_changed(app: &AppHandle, focused: bool) {
    let gs = app.global_shortcut();
    let shortcut = on_top_shortcut();
    let result = if focused {
        if gs.is_registered(shortcut) { Ok(()) } else { gs.register(shortcut) }
    } else if gs.is_registered(shortcut) {
        gs.unregister(shortcut)
    } else {
        Ok(())
    };
    if let Err(e) = result {
        tracing::warn!("快捷键 {ON_TOP_SHORTCUT} {}失败：{e}", if focused { "注册" } else { "注销" });
    }
}

/// macOS 的系统菜单："窗口"和"帮助"（`help`）。其他平台的菜单由页面绘制。
fn mac_menu(
    app: &App,
    saved: &WindowState,
    help: &Submenu<Wry>,
) -> tauri::Result<(tauri::menu::Menu<Wry>, CheckMenuItem<Wry>)> {
    let on_top = CheckMenuItemBuilder::with_id(MENU_ON_TOP, "窗口置顶")
        .checked(saved.always_on_top)
        .accelerator(ON_TOP_SHORTCUT)
        .build(app)?;
    let window_menu = SubmenuBuilder::new(app, "窗口")
        .item(&on_top)
        .item(&MenuItemBuilder::with_id(MENU_RESET, "恢复默认窗口位置和大小").build(app)?)
        .separator()
        .item(&MenuItemBuilder::with_id(MENU_QUIT, "退出").build(app)?)
        .build()?;
    Ok((MenuBuilder::new(app).item(&window_menu).item(help).build()?, on_top))
}

/// 创建主窗口：恢复保存的状态，注入令牌，按平台设置标题栏和菜单，挂上窗口事件。
/// `help` 是"帮助"菜单，只在 macOS 上使用。
pub fn create_main(
    app: &App,
    base: &str,
    token: &str,
    state_path: PathBuf,
    help: &Submenu<Wry>,
) -> tauri::Result<()> {
    let saved = window_state::load(&state_path);
    let allowed = base.to_string();
    let mut builder =
        WebviewWindowBuilder::new(app, MAIN, WebviewUrl::External(base.parse().expect("接口地址")))
            .title("DBLens 数洞")
            .min_inner_size(MIN_SIZE.0, MIN_SIZE.1)
            .visible(false)
            .initialization_script(init_script(token))
            .on_navigation(move |url| {
                let ok = allowed_navigation(&allowed, url.as_str());
                if !ok {
                    tracing::warn!("已阻止窗口跳转到 {url}");
                }
                ok
            });
    let mut on_top_item = None;
    if cfg!(target_os = "macos") {
        let (menu, item) = mac_menu(app, &saved, help)?;
        on_top_item = Some(item);
        builder = builder.menu(menu);
        // 标题栏叠加在页面上：保留红黄绿按钮，其余由页面绘制（这两个方法只在 macOS 上存在）
        #[cfg(target_os = "macos")]
        {
            builder = builder.title_bar_style(tauri::TitleBarStyle::Overlay).hidden_title(true);
        }
    } else {
        builder = builder.decorations(false);
    }
    let win = builder.build()?;

    let work_areas: Vec<Rect> = win
        .available_monitors()?
        .iter()
        .map(|m| to_rect(m.work_area().position, m.work_area().size))
        .collect();
    match saved.rect {
        Some(r) if geometry::is_reachable(r, &work_areas) => apply_rect(&win, r)?,
        Some(r) => {
            tracing::info!("保存的窗口位置 {r:?} 已不在任何显示器上，移回主屏幕");
            reset(&win)?;
        }
        None => reset(&win)?,
    }
    if saved.maximized {
        win.maximize()?;
    }
    win.set_always_on_top(saved.always_on_top)?;
    win.show()?;

    let tracked =
        Tracked { path: state_path, state: Mutex::new(saved), on_top_item, generation: AtomicU64::new(0) };
    remember(&win, &tracked)?;
    app.manage(tracked);
    app.on_menu_event(|app, event| {
        if let Err(e) = on_menu(app, event.id().as_ref()) {
            tracing::warn!("菜单操作失败：{e}");
        }
    });
    let w = win.clone();
    win.on_window_event(move |event| {
        let tracked = w.state::<Tracked>();
        match event {
            WindowEvent::Moved(_) => remember_later(&w),
            WindowEvent::Resized(_) => {
                remember_later(&w);
                // 最大化、还原都会触发缩放，页面据此切换"最大化 / 还原"按钮
                shell::notify(w.app_handle());
            }
            WindowEvent::Focused(focused) => focus_changed(w.app_handle(), *focused),
            WindowEvent::CloseRequested { .. } => save(&w, &tracked),
            _ => {}
        }
    });
    Ok(())
}
```

```rust
//! 自动更新（设计文档第 10 节）：
//! - 启动后在后台检查更新源（静态的 `latest.json`）；有新版本时提示版本号和更新说明，用户确认后下载、校验签名、安装、重启。
//! - 菜单"帮助"中可以手动检查，也可以关闭启动时的自动检查（Windows、Linux 的菜单由页面绘制，经 `shell` 的命令调用这里）。
//! - 更新源默认是 GitHub Releases；数据目录下的 `update.json` 可以改成内网地址。
//! - Linux 上只有 AppImage 能自动安装；deb、rpm 只提示新版本，由用户自己下载。
//!

/// 数据目录下的 `update.json`。
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct UpdateSettings {
    /// 启动后在后台检查更新。
    pub auto_check: bool,
    /// 更新源（`latest.json` 的地址）。为空时用 `tauri.conf.json` 中的默认地址；内网部署时改成内网地址。
    pub endpoint: Option<String>,
}

impl Default for UpdateSettings {
    fn default() -> Self {
        Self { auto_check: true, endpoint: None }
    }
}

/// 当前的安装方式能否自动安装更新：Windows（NSIS）和 macOS 可以；Linux 上只有 AppImage 可以。
pub fn can_self_update(os: &str, appimage: bool) -> bool {
    os != "linux" || appimage
}

/// 发现新版本时的提示文字。
pub fn offer_text(version: &str, current: &str, notes: Option<&str>, self_update: bool) -> String {
    let mut text = format!("发现新版本 {version}（当前 {current}）。");
    if let Some(notes) = notes.map(str::trim).filter(|n| !n.is_empty()) {
        text.push_str("\n\n更新说明：\n");
        text.push_str(notes);
    }
    if self_update {
        text.push_str("\n\n现在下载并安装吗？安装完成后程序会自动重启。");
    } else {
        text.push_str(&format!("\n\n请到 {RELEASES_PAGE} 下载新版本。"));
    }
    text
}

/// 把更新插件的英文错误转成给用户看的说明，原文附在后面便于排查。
pub fn error_text(err: &str) -> String {
    let lower = err.to_lowercase();
    let hint = if lower.contains("signature") {
        "安装包签名校验失败，已取消安装。安装包可能被篡改，或更新源提供的签名不对"
    } else if lower.contains("secure protocol") {
        "更新源必须使用 https 地址"
    } else if lower.contains("could not fetch")
        || lower.contains("error sending request")
        || lower.contains("timed out")
    {
        "无法连接更新源，请检查网络或 update.json 中的地址"
    } else {
        return err.to_string();
    };
    format!("{hint}（{err}）")
}

struct UpdateState {
    path: PathBuf,
    settings: Mutex<UpdateSettings>,
    auto_item: CheckMenuItem<Wry>,
}

/// 弹出消息框，等用户关闭后返回是否点了确认按钮。
async fn dialog(
    app: &AppHandle,
    kind: MessageDialogKind,
    text: String,
    buttons: MessageDialogButtons,
) -> bool {
    let (tx, rx) = tokio::sync::oneshot::channel();
    app.dialog().message(text).title("DBLens 数洞").kind(kind).buttons(buttons).show(move |ok| {
        let _ = tx.send(ok);
    });
    rx.await.unwrap_or(false)
}

async fn info(app: &AppHandle, text: String) {
    dialog(app, MessageDialogKind::Info, text, MessageDialogButtons::Ok).await;
}

async fn find_update(app: &AppHandle) -> Result<Option<Update>, String> {
    let endpoint = app.state::<UpdateState>().settings.lock().unwrap().endpoint.clone();
    let mut builder = app.updater_builder().timeout(TIMEOUT);
    if let Some(e) = endpoint.filter(|e| !e.trim().is_empty()) {
        let url = e.trim().parse().map_err(|err| format!("update.json 中的更新源地址无效（{e}）：{err}"))?;
        builder = builder.endpoints(vec![url]).map_err(|err| err.to_string())?;
    }
    builder.build().map_err(|e| e.to_string())?.check().await.map_err(|e| e.to_string())
}

async fn install(app: &AppHandle, update: Update) -> Result<(), String> {
    let mut downloaded = 0usize;
    let mut last_logged = 0usize;
    update
        .download_and_install(
            |chunk, total| {
                downloaded += chunk;
                if downloaded - last_logged >= 10 * 1024 * 1024 {
                    last_logged = downloaded;
                    tracing::info!("已下载 {downloaded} / {total:?} 字节");
                }
            },
            || tracing::info!("下载完成，开始安装"),
        )
        .await
        .map_err(|e| e.to_string())?;
    tracing::info!("更新已安装，重启");
    app.restart()
}

/// 检查更新。`manual` 为 true 表示用户从菜单发起：没有新版本或出错时也要告诉用户；自动检查出错只记日志。
pub async fn check(app: AppHandle, manual: bool) {
    let update = match find_update(&app).await {
        Ok(u) => u,
        Err(e) => {
            tracing::warn!("检查更新失败：{e}");
            if manual {
                dialog(
                    &app,
                    MessageDialogKind::Error,
                    format!("检查更新失败：{}", error_text(&e)),
                    MessageDialogButtons::Ok,
                )
                .await;
            }
            return;
        }
    };
    let Some(update) = update else {
        tracing::info!("已是最新版本");
        if manual {
            info(&app, format!("已是最新版本（{}）。", app.package_info().version)).await;
        }
        return;
    };
    tracing::info!("发现新版本 {}（当前 {}）", update.version, update.current_version);
    let self_update = can_self_update(std::env::consts::OS, std::env::var_os("APPIMAGE").is_some());
    let text = offer_text(&update.version, &update.current_version, update.body.as_deref(), self_update);
    if !self_update {
        info(&app, text).await;
        return;
    }
    let buttons = MessageDialogButtons::OkCancelCustom("下载并安装".into(), "以后再说".into());
    if !dialog(&app, MessageDialogKind::Info, text, buttons).await {
        return;
    }
    if let Err(e) = install(&app, update).await {
        tracing::error!("安装更新失败：{e}");
        let text = format!("安装更新失败：{}", error_text(&e));
        dialog(&app, MessageDialogKind::Error, text, MessageDialogButtons::Ok).await;
    }
}

/// 读取更新设置，生成"帮助"菜单；开启了自动检查时，启动后在后台检查一次。
pub fn init(app: &App, path: PathBuf) -> tauri::Result<Submenu<Wry>> {
    let settings: UpdateSettings = json_file::load(&path);
    let auto_item = CheckMenuItemBuilder::with_id(MENU_AUTO, "启动时自动检查更新")
        .checked(settings.auto_check)
        .build(app)?;
    let menu = SubmenuBuilder::new(app, "帮助")
        .item(&MenuItemBuilder::with_id(MENU_CHECK, "检查更新…").build(app)?)
        .item(&auto_item)
        .separator()
        .item(&MenuItemBuilder::with_id(MENU_ABOUT, "关于 DBLens").build(app)?)
        .build()?;
    if settings.auto_check {
        let handle = app.handle().clone();
        tauri::async_runtime::spawn(async move {
            tokio::time::sleep(STARTUP_DELAY).await;
            check(handle, false).await;
        });
    }
    app.manage(UpdateState { path, settings: Mutex::new(settings), auto_item });
    Ok(menu)
}

pub fn auto_check(app: &AppHandle) -> bool {
    app.state::<UpdateState>().settings.lock().unwrap().auto_check
}

/// 开关启动时的自动检查：保存到 `update.json`，并同步 macOS 系统菜单的勾选状态。
pub fn set_auto_check(app: &AppHandle, on: bool) {
    let state = app.state::<UpdateState>();
    let mut s = state.settings.lock().unwrap();
    s.auto_check = on;
    if let Err(e) = state.auto_item.set_checked(on) {
        tracing::warn!("同步菜单勾选状态失败：{e}");
    }
    if let Err(e) = json_file::save(&state.path, &*s) {
        tracing::warn!("无法保存更新设置到 {}：{e}", state.path.display());
    }
}

/// "关于 DBLens"对话框。
pub fn about(app: &AppHandle) {
    let text = format!(
        "DBLens 数洞 {}

{RELEASES_PAGE}",
        app.package_info().version
    );
    let app = app.clone();
    tauri::async_runtime::spawn(async move { info(&app, text).await });
}

/// 处理"帮助"菜单（macOS 系统菜单）的事件；不是这个菜单的事件返回 false。
pub fn on_menu(app: &AppHandle, id: &str) -> bool {
    match id {
        MENU_CHECK => {
            tauri::async_runtime::spawn(check(app.clone(), true));
        }
        MENU_AUTO => {
            // 点击时菜单项已自动切换了勾选状态，以它为准
            let on = app.state::<UpdateState>().auto_item.is_checked().unwrap_or(true);
            set_auto_check(app, on);
        }
        MENU_ABOUT => about(app),
        _ => return false,
    }
    true
}
```

```rust
//! 每次启动生成新的访问令牌，经 Tauri 注入页面。前端只通过 HTTP 和 WebSocket 调用业务；
//! Tauri 只负责窗口、菜单等原生能力。

#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod geometry;

use std::path::{Path, PathBuf};
use std::sync::Arc;

use dblens_api::{ApiConfig, new_token, router, serve, with_web};
use dblens_service::{Service, default_data_dir};
use tauri::Manager;

/// 前端页面目录，按顺序查找：
/// 1. 环境变量 `DBLENS_WEB_DIR`；
/// 2. 安装包中的资源目录 `web/`（打包在 M0-4d 中配置）；
/// 3. 调试构建时，源码树中的 `web/dist`。
fn web_dir(resource_dir: Option<PathBuf>) -> Option<PathBuf> {
    let dev = cfg!(debug_assertions).then(|| Path::new(env!("CARGO_MANIFEST_DIR")).join("../../web/dist"));
    std::env::var_os("DBLENS_WEB_DIR")
        .map(PathBuf::from)
        .into_iter()
        .chain(resource_dir.map(|d| d.join("web")))
        .chain(dev)
        .find(|d| d.join("index.html").is_file())
}

fn run(data_dir: PathBuf) -> Result<(), String> {
    let service = Arc::new(Service::open(&data_dir).map_err(|e| e.to_string())?);
    let token = new_token();
    // 先在当前线程绑定端口，窗口创建时地址已经确定
    let listener =
        std::net::TcpListener::bind("127.0.0.1:0").map_err(|e| format!("无法监听本机端口：{e}"))?;
    listener.set_nonblocking(true).map_err(|e| e.to_string())?;
    let addr = listener.local_addr().map_err(|e| e.to_string())?;
    let base = format!("http://{addr}/");
    tracing::info!("接口服务地址 {base}，数据目录 {}", data_dir.display());

    tauri::Builder::default()
        .plugin(tauri_plugin_global_shortcut::Builder::new().with_handler(window::on_shortcut).build())
        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_updater::Builder::new().build())
        .invoke_handler(tauri::generate_handler![
            shell::shell_info,
            shell::window_action,
            shell::set_auto_check_update
        ])
        .setup(move |app| {
            let mut api = router(service, ApiConfig { token: token.clone(), allowed_origins: Vec::new() });
            match web_dir(app.path().resource_dir().ok()) {
                Some(dir) => {
                    tracing::info!("前端页面目录 {}", dir.display());
                    api = with_web(api, dir);
                }
                None => tracing::error!("没有找到前端页面（web/dist），请先在 web/ 下执行 pnpm build"),
            }
            tauri::async_runtime::spawn(async move {
                let result = match tokio::net::TcpListener::from_std(listener) {
                    Ok(l) => serve(l, api).await,
                    Err(e) => Err(e),
                };
                if let Err(e) = result {
                    tracing::error!("接口服务异常退出：{e}");
                }
            });
            let help = update::init(app, data_dir.join("update.json"))?;
            window::create_main(app, &base, &token, data_dir.join("window.json"), &help)?;
            Ok(())
        })
        .run(tauri::generate_context!())
        .map_err(|e| e.to_string())
}

/// 数据目录：环境变量 `DBLENS_DATA_DIR`（开发和测试时用，避免碰到真实数据）优先，否则用默认的用户数据目录。
fn data_dir() -> dblens_core::Result<PathBuf> {
    match std::env::var_os("DBLENS_DATA_DIR") {
        Some(d) => Ok(PathBuf::from(d)),
        None => default_data_dir(),
    }
}

fn main() {
    let data_dir = match data_dir() {
        Ok(d) => d,
        Err(e) => {
            eprintln!("{e}");
            std::process::exit(1);
        }
    };
    let _guard = match logging::init(&data_dir.join("logs")) {
        Ok(g) => Some(g),
        Err(e) => {
            eprintln!("日志初始化失败：{e}");
            None
        }
    };
    tracing::info!("DBLens {} 启动", env!("CARGO_PKG_VERSION"));
    if let Err(e) = run(data_dir) {
        tracing::error!("启动失败：{e}");
        std::process::exit(1);
    }
}
```

```ts
// REST 接口客户端。接口说明见 docs/notes/m0-4b-api.md；页面与接口同源，路径都以 /api 开头。

export type DriverId = 'mysql' | 'postgres' | 'oracle' | 'dameng'
export type Environment = 'none' | 'dev' | 'test' | 'prod'

/** 服务端的错误对象（dblens_core::Error），按 kind 区分。 */
export interface ErrorBody {
  kind: string
  message?: string
  code?: string
  position?: number | null
  what?: string
  reason?: string
  hint?: string
}

export class ApiError extends Error {
  readonly status: number
  readonly body: ErrorBody

  constructor(status: number, body: ErrorBody) {
    super(errorText(body))
    this.status = status
    this.body = body
  }
}

/** 把错误对象转成给用户看的一句话，与服务端 Display 的措辞一致。 */
export function errorText(e: ErrorBody): string {
  switch (e.kind) {
    case 'connect':
      return `连接失败：${e.message}`
    case 'auth':
      return `认证失败：${e.message}`
    case 'sql':
      return `SQL 错误 [${e.code}]：${e.message}`
    case 'timeout':
      return '执行超时'
    case 'cancelled':
      return '执行已取消'
    case 'driver_unavailable':
      return `驱动不可用：${e.hint}`
    case 'invalid':
      return `无效的输入：${e.message}`
    case 'not_found':
      return `找不到${e.what}`
    case 'busy':
      return `会话正忙：${e.message}`
    case 'locked':
      return '密码库已锁定，请先输入主密码'
    case 'denied':
      return `执行被拒绝：${e.reason}`
    case 'internal':
      return `内部错误：${e.message}`
    default:
      return JSON.stringify(e)
  }
}

export type FetchFn = (input: string, init?: RequestInit) => Promise<Response>

export function createApi(token: string, fetchFn: FetchFn = (i, o) => fetch(i, o)) {
  async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
    const headers: Record<string, string> = { Authorization: `Bearer ${token}` }
    if (body !== undefined) headers['Content-Type'] = 'application/json'
    const resp = await fetchFn(`/api${path}`, {
      method,
      headers,
      body: body === undefined ? undefined : JSON.stringify(body),
    })
    const text = await resp.text()
    const data = text ? JSON.parse(text) : null
    if (!resp.ok) {
      throw new ApiError(resp.status, data ?? { kind: 'internal', message: `HTTP ${resp.status}` })
    }
    return data as T
  }

  const p = (id: string) => `/profiles/${encodeURIComponent(id)}`
  const s = (id: string, schema: string) => `${p(id)}/schemas/${encodeURIComponent(schema)}`
  const q = (params: Record<string, string | undefined>) => {
    const entries = Object.entries(params).filter((e): e is [string, string] => e[1] !== undefined && e[1] !== '')
    return entries.length ? `?${new URLSearchParams(entries)}` : ''
  }

  return {
    settings: () => request<Record<string, string>>('GET', '/settings'),
    putSetting: (key: string, value: string | null) =>
      request<null>('PUT', `/settings/${encodeURIComponent(key)}`, { value }),
    drivers: () => request<DriverStatus[]>('GET', '/drivers'),
    setLibDir: (driver: DriverId, path: string | null) =>
      request<DriverStatus>('PUT', `/drivers/${driver}/lib-dir`, { path }),
    secrets: () => request<SecretStatus>('GET', '/secrets'),
    initVault: (master: string) => request<SecretStatus>('POST', '/secrets/init', { master }),
    unlockVault: (master: string) => request<SecretStatus>('POST', '/secrets/unlock', { master }),
    lockVault: () => request<SecretStatus>('POST', '/secrets/lock'),
    profiles: () => request<Profile[]>('GET', '/profiles'),
    profile: (id: string) => request<Profile>('GET', p(id)),
    createProfile: (profile: ProfileInput, password: string | null) =>
      request<Profile>('POST', '/profiles', { profile, password }),
    updateProfile: (id: string, profile: ProfileInput) => request<Profile>('PUT', p(id), profile),
    setPassword: (id: string, password: string | null) => request<null>('PUT', `${p(id)}/password`, { password }),
    deleteProfile: (id: string) => request<null>('DELETE', p(id)),
    testConnection: (profile: ProfileInput, password: string) =>
      request<ServerSummary>('POST', '/profiles/test', { profile, password }),
    schemas: (id: string, filter?: string) => request<SchemaInfo[]>('GET', `${p(id)}/schemas${q({ filter })}`),
    objects: (id: string, schema: string, kind: ObjectKind, filter?: string) =>
      request<ObjectInfo[]>('GET', `${s(id, schema)}/objects${q({ kind, filter })}`),
    table: async (id: string, schema: string, table: string) =>
      (await request<TableInfo[]>('GET', `${s(id, schema)}/tables${q({ table })}`))[0] ?? null,
    sequences: (id: string, schema: string) => request<SequenceInfo[]>('GET', `${s(id, schema)}/sequences`),
    routines: (id: string, schema: string) => request<RoutineInfo[]>('GET', `${s(id, schema)}/routines`),
    synonyms: (id: string, schema: string) => request<SynonymInfo[]>('GET', `${s(id, schema)}/synonyms`),
    /** 清掉后端的元数据缓存；不给 schema 时清整个连接的。 */
    refresh: (id: string, schema: string | null) => request<null>('POST', `${p(id)}/refresh`, { schema }),
    openSession: (profileId: string) => request<SessionInfo>('POST', '/sessions', { profile_id: profileId }),
    closeSession: (id: number) => request<null>('DELETE', `/sessions/${id}?commit=false`),
    /** 会话的 WebSocket 地址。浏览器的 WebSocket 不能带请求头，令牌放在查询参数里。 */
    wsUrl: (sessionId: number, loc: { protocol: string; host: string } = window.location) =>
      `${loc.protocol === 'https:' ? 'wss' : 'ws'}://${loc.host}/api/sessions/${sessionId}/ws?token=${encodeURIComponent(token)}`,
  }
}
```

```ts
// 下次启动时恢复（M1 设计文档 1.1 节）。值都是字符串，结构化的值由使用方自己序列化。

import { create } from 'zustand'

export type SaveSetting = (key: string, value: string | null) => Promise<unknown>

interface SettingsState {
  values: Record<string, string>
  save: SaveSetting | null
  /** 启动时装入后端的设置，并指定以后怎么保存。 */
  init(values: Record<string, string>, save: SaveSetting): void
  /** 修改一项；`null` 删除。立即生效，后台保存，保存失败只在控制台记录（界面设置不值得打断用户）。 */
  set(key: string, value: string | null): void
}

export const useSettings = create<SettingsState>()((set, get) => ({
  values: {},
  save: null,
  init: (values, save) => set({ values, save }),
  set: (key, value) => {
    const values = { ...get().values }
    if (value === null) delete values[key]
    else values[key] = value
    set({ values })
    get()
      .save?.(key, value)
      .catch((e: unknown) => console.warn(`保存设置 ${key} 失败`, e))
  },
}))

/** 读取一项设置（在组件中用，值变化时组件会重新渲染）。 */

  return useSettings((s) => s.values[key])
```

```ts
import { create } from 'zustand'

import { type Api, ApiError } from '../../shared/api'

export type VaultMode = 'init' | 'unlock'

interface VaultState {
  /** 正在等用户输入主密码的请求。 */
  pending: { mode: VaultMode; resolve: (ok: boolean) => void } | null
  /** 弹出对话框，用户完成（true）或取消（false）后返回。 */
  ask(mode: VaultMode): Promise<boolean>
  finish(ok: boolean): void
}

export const useVault = create<VaultState>()((set, get) => ({
  pending: null,
  ask: (mode) =>
    new Promise<boolean>((resolve) => {
      get().pending?.resolve(false)
      set({ pending: { mode, resolve } })
    }),
  finish: (ok) => {
    get().pending?.resolve(ok)
    set({ pending: null })
  },
}))

export function isLocked(e: unknown): boolean {
  return e instanceof ApiError && e.body.kind === 'locked'
}

/** 执行 fn；遇到密码库锁定时请用户设置或输入主密码，成功后重试一次。用户取消时抛出原来的错误。 */
export async function withVault<T>(api: Pick<Api, 'secrets'>, fn: () => Promise<T>): Promise<T> {
  try {
    return await fn()
  } catch (e) {
    if (!isLocked(e)) throw e
    const status = await api.secrets()
    const ok = await useVault.getState().ask(status.vault_initialized ? 'unlock' : 'init')
    if (!ok) throw e
    return fn()
  }
}
```

```ts
// 对象树的节点结构（设计文档 7.3 节）：连接 → schema → 分类（表、视图……）→ 对象 →（表的）列。
// 懒加载：展开时才向后端取下一层。这里只放纯逻辑，单独测试。

import type { DriverId, ObjectKind, RoutineInfo } from '../../shared/api'

export type CategoryKind = ObjectKind | 'routines' | 'sequences' | 'synonyms'

export interface Category {
  kind: CategoryKind
  label: string
}

const ALL: Record<CategoryKind, string> = {
  tables: '表',
  views: '视图',
  materialized_views: '物化视图',
  routines: '函数和过程',
  sequences: '序列',
  synonyms: '同义词',
}

/** 各类数据库在对象树中显示的分类，与 dblens-dialect 中各方言的元数据模板对应。 */
export function categoriesFor(driver: DriverId): Category[] {
  const kinds: CategoryKind[] =
    driver === 'mysql'
      ? ['tables', 'views', 'routines']
      : driver === 'postgres'
        ? ['tables', 'views', 'materialized_views', 'routines', 'sequences']
        : ['tables', 'views', 'materialized_views', 'routines', 'sequences', 'synonyms']
  return kinds.map((kind) => ({ kind, label: ALL[kind] }))
}

/**
 * 节点的键。各段用 `\u0001` 连接（数据库对象名里不会出现），开头是节点类型：
 * - `c` 连接：c、profileId
 * - `s` schema：s、profileId、schema
 * - `g` 系统 schema 分组：g、profileId
 * - `k` 分类：k、profileId、schema、kind
 * - `o` 对象：o、profileId、schema、kind、name
 * - `l` 列：l、profileId、schema、table、column
 */
export type NodeKey =
  | { type: 'c'; profileId: string }
  | { type: 's'; profileId: string; schema: string }
  | { type: 'g'; profileId: string }
  | { type: 'k'; profileId: string; schema: string; kind: CategoryKind }
  | { type: 'o'; profileId: string; schema: string; kind: CategoryKind; name: string }
  | { type: 'l'; profileId: string; schema: string; table: string; column: string }

const SEP = '\u0001'

export function encodeKey(k: NodeKey): string {
  switch (k.type) {
    case 'c':
    case 'g':
      return [k.type, k.profileId].join(SEP)
    case 's':
      return [k.type, k.profileId, k.schema].join(SEP)
    case 'k':
      return [k.type, k.profileId, k.schema, k.kind].join(SEP)
    case 'o':
      return [k.type, k.profileId, k.schema, k.kind, k.name].join(SEP)
    case 'l':
      return [k.type, k.profileId, k.schema, k.table, k.column].join(SEP)
  }
}

export function decodeKey(s: string): NodeKey {
  const [type, profileId, a, b, c] = s.split(SEP)
  switch (type) {
    case 'c':
      return { type, profileId }
    case 'g':
      return { type, profileId }
    case 's':
      return { type, profileId, schema: a }
    case 'k':
      return { type, profileId, schema: a, kind: b as CategoryKind }
    case 'o':
      return { type, profileId, schema: a, kind: b as CategoryKind, name: c }
    case 'l':
      return { type, profileId, schema: a, table: b, column: c }
    default:
      throw new Error(`无法识别的节点键：${s}`)
  }
}

/** 过滤：名称或注释包含关键字（不区分大小写）。空关键字全部保留。 */
export function matches(filter: string, name: string, comment?: string | null): boolean {
  const f = filter.trim().toLowerCase()
  if (!f) return true
  return name.toLowerCase().includes(f) || (comment ?? '').toLowerCase().includes(f)
}

const ROUTINE_KIND: Record<RoutineInfo['kind'], string> = {
  procedure: '过程',
  function: '函数',
  package: '包',
  package_body: '包体',
}

export function routineKindLabel(kind: RoutineInfo['kind']): string {
  return ROUTINE_KIND[kind] ?? kind
}

/** 复制名称时用的限定名：schema.对象，列为 表.列。名字原样输出，不加引号。 */
export function qualifiedName(k: NodeKey): string {
  switch (k.type) {
    case 'o':
      return `${k.schema}.${k.name}`
    case 'l':
      return `${k.table}.${k.column}`
    case 's':
      return k.schema
    default:
      return ''
  }
}

/** child 是否在 parent 之下（不含 parent 自己）。刷新 parent 时，它下面已加载的内容都要丢掉。 */
export function isWithin(child: NodeKey, parent: NodeKey): boolean {
  if (child.profileId !== parent.profileId) return false
  switch (parent.type) {
    case 'c':
      return child.type !== 'c'
    case 'g':
      return child.type === 's'
    case 's':
      return (child.type === 'k' || child.type === 'o' || child.type === 'l') && child.schema === parent.schema
    case 'k':
      return (
        (child.type === 'o' && child.schema === parent.schema && child.kind === parent.kind) ||
        (child.type === 'l' && parent.kind === 'tables' && child.schema === parent.schema)
      )
    case 'o':
      return child.type === 'l' && child.schema === parent.schema && child.table === parent.name
    case 'l':
      return false
  }
}
```

```tsx
/** 按节点键取下一层。 */
async function loadChildren(api: Api, profiles: Profile[], k: NodeKey): Promise<Loaded['items']> {
  switch (k.type) {
    case 'c':
    case 'g': {
      const schemas = await api.schemas(k.profileId)

        items.push({ key: encodeKey({ type: 'g', profileId: k.profileId }), label: '系统', leaf: false })

        label: c.label,
        leaf: false,
      }))
    }
    case 'k': {

        key: encodeKey({ type: 'o', profileId: k.profileId, schema: k.schema, kind: k.kind, name }),
        label: name,
        comment,
        extra,
        leaf: k.kind !== 'tables',
```

```ts
// 桌面外壳的状态（最大化、置顶、自动检查更新）：启动时取一次，之后跟随 Rust 端推送的事件更新。浏览器模式为 null。

import { useEffect, useState } from 'react'

import { type ShellInfo, desktop } from '../shared/shell'

export function useShellInfo(): ShellInfo | null {
  const [info, setInfo] = useState<ShellInfo | null>(null)
  useEffect(() => {
    if (!desktop) return
    let unlisten: (() => void) | undefined
    let cancelled = false
    desktop.info().then((i) => !cancelled && setInfo(i), console.warn)
    desktop
      .onChange((i) => setInfo(i))
      .then((u) => {
        if (cancelled) u()
        else unlisten = u
      }, console.warn)
    return () => {
      cancelled = true
      unlisten?.()
    }
  }, [])
  return info
}
```

```tsx
// 应用入口：拿到令牌后读取设置，按主题配置 antd，挂上外壳和全局对话框。

import { App as AntApp, ConfigProvider, Result, Spin, theme as antdTheme } from 'antd'
import zhCN from 'antd/locale/zh_CN'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { useEffect, useMemo, useState } from 'react'

import ConnectionDialog from '../features/connections/ConnectionDialog'
import VaultDialog from '../features/connections/VaultDialog'
import { type Api, createApi } from '../shared/api'
import { useSetting, useSettings } from '../shared/settings'
import { THEME_KEY, parseThemePref, resolveTheme, useSystemDark } from '../shared/theme'
import SettingsDialog from './SettingsDialog'
import Shell from './Shell'
import { ApiContext } from './context'
import './shell.css'
import { SIDE_KEY, parseSide, useUi } from './ui'

function Themed() {
  const systemDark = useSystemDark()
  const theme = resolveTheme(parseThemePref(useSetting(THEME_KEY)), systemDark)
  useEffect(() => {
    document.documentElement.dataset.theme = theme
  }, [theme])
  const algorithm = [theme === 'dark' ? antdTheme.darkAlgorithm : antdTheme.defaultAlgorithm, antdTheme.compactAlgorithm]
  return (
    <ConfigProvider locale={zhCN} theme={{ algorithm, token: { fontSize: 12, borderRadius: 4 } }}>
      <AntApp style={{ height: '100%' }}>
        <Shell />
        <ConnectionDialog />
        <VaultDialog />
        <SettingsDialog />
      </AntApp>
    </ConfigProvider>
  )
}

/** 读取设置后再显示界面，避免主题和布局先按默认值闪一下。 */
function Boot({ api }: { api: Api }) {
  const [state, setState] = useState<'loading' | 'ready' | Error>('loading')
  useEffect(() => {
    api.settings().then(
      (values) => {
        useSettings.getState().init(values, api.putSetting)
        useUi.setState({ side: parseSide(values[SIDE_KEY]) })
        setState('ready')
      },
      (e: Error) => setState(e),
    )
  }, [api])
  if (state === 'loading') return <Spin fullscreen />
  if (state instanceof Error) return <Result status="error" title="无法连接 DBLens 服务" subTitle={state.message} />
  return <Themed />
}

export default function App({ token }: { token: string | null }) {
  const api = useMemo(() => (token ? createApi(token) : null), [token])
  const queryClient = useMemo(() => new QueryClient({ defaultOptions: { queries: { retry: false } } }), [])
  if (!api) {
    return (
      <Result
        status="warning"
        title="缺少访问令牌"
        subTitle="请使用 dblens-server 启动时打印的链接打开本页（链接末尾带 #token=…）。"
      />
    )
  }
  return (
    <ApiContext.Provider value={api}>
      <QueryClientProvider client={queryClient}>
        <Boot api={api} />
      </QueryClientProvider>
    </ApiContext.Provider>
  )
}
```

````markdown
## 要点

- **设置接口**：
  - `GET /api/settings`、`PUT /api/settings/{key}`，**只读写 `ui.` 开头的键**。
  - 同一张表里还有服务层自己的设置，如已确认的原生库目录 `native.*`。如果允许经设置接口读写它们，就能绕过确认库目录时"必须是绝对路径"的校验（实测中发现）。
- **面板布局**：react-resizable-panels 的 `useDefaultLayout` 接受任意 `getItem/setItem` 存储。传入 `shared/settings.ts` 的 `layoutStorage`，侧栏宽度就存进 `ui.layout.*`。
- **自绘标题栏**：
  - Windows、Linux 去掉系统标题栏（`decorations(false)`），系统菜单只在 macOS 上创建。
  - 页面经三个命令调用原生能力：
    - `shell_info`：读取状态；
    - `window_action`：最小化、最大化或还原、关闭、拖动、置顶、恢复默认位置、检查更新、关于、退出；
    - `set_auto_check_update`：开关启动时的自动检查。
  - 状态变化（最大化、置顶、自动检查）经事件 `dblens://shell` 推给页面。
  - Ctrl+Shift+T 仍是系统热键，切换后同样推送事件，标题栏按钮跟着变。
- **权限**：
  - `build.rs` 用 `AppManifest::commands` 为三个命令生成 `allow-*` 权限，`capabilities/main.json` 引用它们。
  - `local: false`、`remote.urls: ["http://127.0.0.1:*"]`：只有进程内接口服务提供的页面能调用。
- **浏览器模式**：没有 `__TAURI_INTERNALS__`，`shared/shell.ts` 的 `desktop` 为 null。
  - 标题栏只有菜单和标题；
  - 没有"窗口"菜单，"帮助"只有"关于"。
- **密码库**：任何接口返回 `locked` 时，`withVault` 先请用户设置或输入主密码，成功后重试一次。
- **对象树**：
  - 分类与各方言的元数据模板对应：MySQL 系没有物化视图和序列；Oracle、达梦有同义词。
  - 系统 schema 收在"系统"分组里。
  - "刷新"会先清后端缓存，再丢掉节点下面已加载和已展开的内容。

## 实测（Windows 11；浏览器模式 + 桌面版；5 个测试库）

- **浏览器模式**：
  - 新建 PG 连接：测试连接成功，保存后出现在树中，环境标记和颜色正确。
  - 编辑连接时正确带出已保存的配置，密码留空。
  - 对象树：
    - PG：schema → 表（注释、数量）→ 列（类型、非空、注释，主键标钥匙）；
    - MySQL：表、函数和过程；
    - Oracle：schema、同义词（含 db link）；
    - 达梦：schema 列表。
  - 过滤"员工"只留下匹配的表。
  - 主题和侧栏宽度保存后，刷新页面恢复。
  - 右键菜单项齐全。
- **桌面版**：
  - 没有系统标题栏，页面能调用三个命令；
  - 置顶按钮、菜单"窗口 → 窗口置顶"、Ctrl+Shift+T 都能切换，标题栏按钮随之变色；
  - 最大化 / 还原按钮、双击标题栏、拖动标题栏（移动 120×60 像素）、最小化、"恢复默认窗口位置和大小"都正常；
````
